1.3データ分析に使う主なパッケージ

Pythonでデータ分析をするときに使う、代表的なパッケージを紹介します。

1.3.1パッケージとは

Pythonでは、関連する機能のまとまりをパッケージとして配布しています。Python本体に最初から付いてくるものを標準ライブラリ、別途インストールして使うものをサードパーティ製パッケージと呼びます。サードパーティ製パッケージは、第2章で学ぶ pip などでインストールします。

Javaと比べると

標準ライブラリは JDK に含まれる java.util など、サードパーティ製パッケージは Maven で追加するライブラリにあたります。
