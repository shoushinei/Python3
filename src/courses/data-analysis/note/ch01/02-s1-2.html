1.2機械学習の位置づけと流れ

機械学習とは何か、どんな種類があり、どんな手順で進めるのかを説明します。

1.2.1機械学習とは

人間がルールを1つずつ書く代わりに、データからルール（パターン）をコンピュータに学ばせる方法を機械学習と呼びます。人間がルールを書いて判定する方法はルールベースと呼ばれ、機械学習と対比されます。

例えば迷惑メールの判定で考えます。ルールベースでは「件名に○○を含めば迷惑メール」というルールを人間が考えて書きます。機械学習では、大量の「迷惑メール／普通のメール」の例からコンピュータが判定基準を見つけます。

1.2.2データからモデルを作る

機械学習でデータから学習した結果をモデルと呼びます。モデルは「入力を受け取って、予測を返す関数」のようなものです。

目的変数（ラベル・正解）予測したい値。例：住宅価格、花の品種、迷惑メールかどうか。
説明変数（特徴量）予測の手がかりにする値。例：部屋の数、築年数、花びらの長さ。

このとき、目的変数と説明変数（特徴量）という言葉を区別して使います。

Javaと比べると

モデルは、引数（説明変数）から戻り値（目的変数の予測）を返すメソッドのようなものです。ただし、メソッドの中身を人間が書くのではなく、データから自動で決まるところが違います。

1.2.3機械学習のタスク

種類正解ラベル代表的なタスク例
教師あり学習あり回帰・分類住宅価格の予測、花の品種の判定
教師なし学習なしクラスタリング・次元削減顧客のグループ分け、特徴量の要約
強化学習なし（報酬で学ぶ）行動の最適化ゲームの攻略、ロボットの制御
教師あり学習：回帰と分類

教師あり学習は、正解（目的変数）が付いたデータから学ぶ方法です。目的変数の種類によって、回帰と分類の2つに分けられます。

回帰目的変数が連続値（数量）。例：広告費から売上金額を予測する。
分類目的変数が離散値（カテゴリ）。例：画像が犬か猫かを判定する。

ここで、回帰か分類かを決めるのは、説明変数ではなく目的変数の種類です。

教師なし学習：クラスタリングと次元削減

教師なし学習は、正解ラベルを使わずに、データそのものの構造を見つける方法です。

  • クラスタリング：似たデータ同士をグループ（クラスタ）にまとめる。k-means や、データの密度にもとづく DBSCAN などがある。
  • 次元削減：情報をなるべく失わずに、特徴量（次元）の数を減らす。主成分分析（PCA）など。
強化学習

強化学習は、ある環境の中で行動するエージェントが、試行錯誤しながら得られる報酬が最大になるように行動の仕方を学ぶ方法です。囲碁やゲームのAI、ロボットの制御などで使われます。

深層学習の位置づけ

深層学習は、ニューラルネットワークを何層も重ねた手法の名前で、上の3つのような学習の「種類」の名前ではありません。画像分類のような教師あり学習でよく使われますが、教師なし学習や強化学習と組み合わせて使われることもあります。

1.2.4機械学習の処理の手順

1データ収集分析に必要なデータを集める。
2前処理欠損値の処理、カテゴリの数値化、尺度をそろえる正規化など。
3データの分割学習用とテスト用に分ける。
4学習アルゴリズムを選び、学習用データでモデルを作る。
5評価テスト用データで性能を測る。必要に応じて設定を調整して4へ戻る。

この手順は、第4章の scikit-learn でそのままコードになります。今は「前処理 → 学習 → 評価」の順番を覚えておけば十分です。
