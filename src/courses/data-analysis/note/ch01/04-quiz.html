確認問題

Q1教師あり学習の説明として正しいものはどれか。

  1. 説明変数が連続値のときは回帰、離散値のときは分類と呼ぶ。
  2. 正解ラベルを使わずに、データを似たもの同士のグループにまとめる。
  3. 正解ラベル（目的変数）が付いたデータからモデルを学習する。
  4. エージェントが報酬を最大化するように行動を学ぶ。
回帰と分類は目的変数の種類で分けるので、Aは誤りです。Bは教師なし学習（クラスタリング）、Dは強化学習の説明です。

Q2次のうち、教師なし学習の代表的なタスクの組み合わせはどれか。

  1. 回帰と分類
  2. クラスタリングと次元削減
  3. 分類とクラスタリング
  4. 回帰と次元削減
教師なし学習の代表はクラスタリングと次元削減です。回帰と分類は教師あり学習のタスクです。

Q3Pythonに関する記述として誤っているものはどれか。

  1. コンパイルを必要としない動的なスクリプト言語である。
  2. データ分析以外に、Webシステムの構築などにも使われる。
  3. 標準ライブラリに加えて、外部のパッケージが豊富である。
  4. ブラウザで動く画面の開発では、JavaScriptより広く使われている。
ブラウザで動くフロントエンドの中心はJavaScriptです。Pythonは万能ではないので、得意な分野と不得意な分野を区別しておきましょう。

Q4前処理（データハンドリング）に関する記述として正しいものはどれか。

  1. 欠損値や表記の揺れを整える作業で、分析作業の大部分を占めるとも言われる。
  2. モデルの学習が終わった後に、結果をグラフにする作業である。
  3. 機械学習では不要で、統計処理のときだけ行う。
  4. 正解ラベルを人の手で付ける作業のことだけを指す。
前処理は、データを分析できる形に整える工程です。作業全体の8〜9割を占めるとも言われます。
