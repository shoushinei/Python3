4.4.1前処理

欠損値への対応

欠損値への対処法は、大きく分けて「除去する」か「補完する」かの2つです。除去は pandas の dropna、補完は scikit-learn の SimpleImputer でもできます。

import numpy as np

imp = SimpleImputer(strategy="mean")    # 平均値で補完（median / most_frequent も指定できる）
imp.fit(df)                             # 各列の平均値を学習
print(imp.transform(df))

特徴量の正規化

例えば「年齢」は2桁、「年収」は7桁というように、特徴量ごとに桁（オーダー）が大きく違うと、値の大きい特徴量ばかりが重視されやすくなります。特徴量の尺度をそろえる処理を正規化と呼びます。

4.4.2分類

分類とは

分類は、データがどのクラスに属するかを予測するタスクです。正解（クラスのラベル）が分かっている既知のデータを教師として学習する、教師あり学習の典型的なタスクです。

分類モデル構築の流れ
1データの分割手元のデータを学習データとテストデータに分ける。
2学習学習データで分類モデルを作る（fit）。
3予測と評価テストデータで予測（predict）し、未知のデータへの性能（汎化能力）を評価する。

分割には、sklearn.model_selection モジュールの train_test_split 関数を使います。ここでは scikit-learn に付属する Irisデータセットを使います。150件のアヤメについて、がく（sepal）と花びら（petal）の長さと幅の4つの特徴量と、3種類の品種が記録されています。

In
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split

iris = load_iris()
X, y = iris.data, iris.target
print(X.shape, y.shape)          # 150件 × 4特徴量
print(iris.feature_names)
print(iris.target_names)         # 3つの品種
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=0)
print(X_train.shape, X_test.shape)   # 8:2 に分割
Out 
(150, 4) (150,)
['sepal length (cm)', 'sepal width (cm)', 'petal length (cm)', 'petal width (cm)']
['setosa' 'versicolor' 'virginica']
(120, 4) (30, 4)
  • test_size=0.2 で、テスト用が2割、学習用が8割になります（0.3 なら3割と7割）。
  • random_state は、分割をランダムに行うときの乱数のシードです。固定すると毎回同じ分割になります。
  • 分割と学習・評価を何度も繰り返して評価を平均する方法を、交差検証と呼びます（→ 4.4.5）。
Javaと比べると

学習データとテストデータを分けるのは、単体テストで「実装に使ったデータとは別のデータで確かめる」のと同じ考え方です。学習に使ったデータで評価すると、答えを知っている問題で採点するようなもので、本当の実力（汎化能力）が分かりません。

サポートベクタマシン
  • クラスを分ける境界（決定境界）を、マージン（境界と、境界に最も近いデータとの距離）が最大になるように決める手法です。境界に最も近いデータをサポートベクタと呼びます。
  • マージンを大きくとると、境界が各クラスのデータから離れます。そのため、データが多少変わっても誤分類しにくい、汎化能力の高いモデルになります。
  • 直線や平面で分けられないデータも、カーネル法で高次元の空間に写すことで線形分離できるようになります。
  • 分類だけでなく、回帰や外れ値検出にも使えます。
覚え方

マージン ＝ 境界線の両側の「安全地帯」。安全地帯が広いほど、新しいデータが多少ずれても誤分類しにくいので、マージンは最大化します。安全地帯の端にいて境界を「支えている（support）」データがサポートベクタです。

In
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.svm import SVC

X, y = load_iris(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=0)
svc = SVC(kernel="rbf")       # kernel="linear" で線形のSVM
svc.fit(X_train, y_train)     # 学習
y_pred = svc.predict(X_test)  # 予測
print(y_pred[:10])
print("正解率", svc.score(X_test, y_test))
Out 
[2 1 0 2 0 2 0 1 1 1]
正解率 1.0

この手法をサポートベクタマシン（SVM）と呼びます。

決定木
  • 「花びらの幅は0.8cm以下か？」のような質問を繰り返して、データを分割していく手法です。結果が木のような形になります。
  • 木というデータ構造は、頂点であるノードと、ノード同士を結ぶエッジでできています。一番上のノードをルート、最下部にあって子ノードを持たないノードをリーフ（葉）と呼びます。
  • どこで分割するかは、分割によってどれだけ得をするかを表す情報利得で決めます。情報利得 ＝ 親ノードの不純度 − 子ノードの不純度です。不純度はノード内のクラスの混ざり具合で、ジニ不純度やエントロピーで測ります。
  • 主なハイパーパラメータは木の深さ max_depth です。深すぎると学習データに合わせすぎてしまいます（過学習）。

4.4.3回帰

回帰は、連続値の目的変数を予測するタスクです。最も基本的なのが、説明変数と目的変数の関係を直線（平面）で表す線形回帰（LinearRegression）です。

単回帰説明変数が1つ。y = a x + b
重回帰説明変数が2つ以上。y = a1x1 + a2x2 + … + b

説明変数の数で単回帰と重回帰を区別します。学習によって、係数（coef_）と切片（intercept_）が決まります。

覚え方

単 ＝ 説明変数が1つ（単独）、重 ＝ 説明変数が重なる（複数）。目的変数はどちらも1つです。coef_ は coefficient（係数）、intercept_ は切片（y軸と交わる点）の略です。末尾の _ は「学習して決まった値」の印です。

In
import numpy as np
from sklearn.linear_model import LinearRegression

X = np.array([[10], [20], [30], [40], [50]])   # 広告費（説明変数は1つ → 単回帰）
y = np.array([25, 41, 62, 79, 101])            # 売上
lr = LinearRegression()
lr.fit(X, y)
print("係数", lr.coef_, "切片", round(lr.intercept_, 2))
print(lr.predict(np.array([[60]])))            # 広告費60のときの予測
Out 
係数 [1.9] 切片 4.6
[118.6]

付属の load_diabetes（糖尿病の進行度と10個の特徴量）を使った例です。説明変数が10個あるので、重回帰になります。

In

  • predict(X_test) は、テスト用の説明変数から目的変数を予測します。

4.4.4次元削減

次元削減は、データが持つ情報をできるだけ損なわずに、説明変数（特徴量）の数を減らすタスクです。計算量を減らしたり、2次元・3次元に落としてグラフで確認できるようにしたりするために使います。

代表的な手法が主成分分析（PCA）です。

  • データの分散が最も大きくなる方向を探して新しい軸（第一主成分）とします。次に、それと直交する方向で分散が大きい軸を第二主成分とし、以下同様に続けます。
  • 元の次元以下の次元にデータを変換します。情報の多い主成分だけを残すことで、次元を減らせます。
  • 各主成分が元のデータの分散（情報）をどれだけ説明するかは、寄与率（explained_variance_ratio_）で確認します。少数の主成分で寄与率の合計が大きければ、少ない次元に削減しても情報はあまり失われません。
  • scikit-learn では、sklearn.decomposition モジュールの PCA クラスを使います。
覚え方

分散 ＝ 情報量と考えます。データが大きくばらつく向きほど、データの違いをよく表している（情報が多い）ので、分散が大きい方向を残します。PCA ＝ Principal Component Analysis（主成分分析）、モジュール名の decomposition ＝ 分解（データを成分に分解する）です。

In
from sklearn.datasets import load_wine
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

X, y = load_wine(return_X_y=True)          # ワイン178件 × 特徴量13個
X_std = StandardScaler().fit_transform(X)  # 尺度をそろえてから
pca = PCA(n_components=2)                  # 13次元 → 2次元
X_2d = pca.fit_transform(X_std)
print(X.shape, "→", X_2d.shape)
print(pca.explained_variance_ratio_.round(3))   # 各主成分の寄与率
Out 
(178, 13) → (178, 2)
[0.362 0.192]
In

4.4.5モデルの評価

混同行列

分類モデルの予測結果は、混同行列にまとめて評価します。ここでは「正例（陽性）か負例（陰性）か」の2クラスで考えます。

予測：正例予測：負例
実際：正例TP（真陽性：正しく正例と予測）FN（偽陰性：見逃し）
実際：負例FP（偽陽性：誤検出）TN（真陰性：正しく負例と予測）
評価指標
指標式意味・重視する場面
正解率（accuracy）(TP+TN) / (TP+FP+FN+TN)正例・負例を問わず、予測が当たった割合
適合率（precision）TP / (TP+FP)正例と予測したもののうち、本当に正例だった割合。正例と予測するときに、なるべく間違えたくない（誤検出を減らしたい）場合に重視する
再現率（recall）TP / (TP+FN)本当の正例のうち、正例と予測できた割合。見逃しを減らしたい場合（病気の検査など）に重視する
F値（F1）2 × 適合率 × 再現率 / (適合率 + 再現率)適合率と再現率の調和平均

適合率と再現率は、一般にトレードオフの関係にあります。片方を高くすると、もう片方は低くなりやすいので、両方のバランスを見る F値を使います。

予測:正予測:負実際:正TPFN実際:負FPTN
適合率 ＝ TP /（TP + FP）
「正と予測した列」の中で見る
予測:正予測:負実際:正TPFN実際:負FPTN
再現率 ＝ TP /（TP + FN）
「実際に正の行」の中で見る
予測:正予測:負実際:正TPFN実際:負FPTN
正解率 ＝（TP + TN）/ 全体
対角線（当たり）÷ 全部
覚え方
  • TP / FP などの読み方：後ろの P / N が「予測」、前の T / F が「当たったか」。FP ＝ 正（P）と予測したが外れ（F）＝ 誤検出、FN ＝ 負（N）と予測したが外れ ＝ 見逃し。
  • 適合率（precision ＝ 精密さ）：予測の側から見る。「正と言ったものは本当に正か」。迷惑メールフィルタで、普通のメールを誤って捨てたくないときに重視する。
  • 再現率（recall ＝ 思い出す、取りこぼさない）：実際の側から見る。「本当の正をどれだけ拾えたか」。病気の見逃しを避けたいときに重視する。
注意：分類と回帰で指標が違う

正解率・適合率・再現率・F値は、混同行列から計算する分類モデルの指標です。回帰モデルは、平均二乗誤差（MSE）や決定係数（R²）など、予測値と実際の値の差で評価します。

In
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier
from sklearn.metrics import confusion_matrix, accuracy_score, precision_score, recall_score, f1_score

X, y = load_breast_cancer(return_X_y=True)     # 2クラス（良性=1 / 悪性=0）
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=0)
clf = DecisionTreeClassifier(max_depth=3, random_state=0).fit(X_train, y_train)
y_pred = clf.predict(X_test)
print(confusion_matrix(y_test, y_pred))        # [[TN FP] [FN TP]] の並び
print("正解率", round(accuracy_score(y_test, y_pred), 3))
print("適合率", round(precision_score(y_test, y_pred), 3))

ROC曲線とAUC

判定のしきい値を変えながら、横軸に偽陽性率（FP / (FP+TN)）、縦軸に真陽性率（＝再現率）をとって描いた曲線をROC曲線と呼びます。曲線の下の面積がAUCで、1に近いほど良いモデルです。でたらめな予測では0.5になります。

In

4.4.6ハイパーパラメータの最適化

学習によって決まる値（回帰の係数など）をパラメータと呼びます。一方、決定木の深さ max_depth やSVMの C のように、学習の前に人が決める値をハイパーパラメータと呼びます。

候補の値の組み合わせをすべて試して、最も評価が良いものを選ぶ方法をグリッドサーチと呼びます。scikit-learn では GridSearchCV を使い、各候補を交差検証で評価します。候補を無作為に選んで試す RandomizedSearchCV もあります。

In
from sklearn.datasets import load_wine
from sklearn.model_selection import GridSearchCV, train_test_split
from sklearn.svm import SVC

X, y = load_wine(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=0)
param_grid = {"C": [0.1, 1, 10], "kernel": ["linear", "rbf"]}   # 3 × 2 = 6通りを試す
gs = GridSearchCV(SVC(), param_grid=param_grid, cv=5)          # 5分割交差検証で評価
gs.fit(X_train, y_train)
print(gs.best_params_)            # 最も良かった組み合わせ
print(round(gs.best_score_, 3))   # そのときの交差検証の平均スコア
print(round(gs.score(X_test, y_test), 3))   # 最良の設定で学習し直したモデルのテスト正解率
Out 
{'C': 0.1, 'kernel': 'linear'}
0.963
0.956
  • 最適値は、必ず param_grid で与えた候補の中から選ばれます。
  • cv=5 なら5分割、cv=10 なら10分割の交差検証です。
  • 最適化した後の predict は、最良のハイパーパラメータで学習し直したモデルで予測します。
覚え方

GridSearchCV ＝ Grid（格子）＋ Search（探索）＋ CV（Cross Validation ＝ 交差検証）。候補を縦横の格子に並べて全部の交点を試し、それぞれを交差検証で評価する、と名前がそのまま中身を説明しています。best_params_ が最良の組み合わせ、best_score_ がそのときのスコアです。

結果の再現性

決定木やランダムフォレストのように、アルゴリズム自体に乱数を使うモデルがあります。train_test_split の random_state だけを固定しても、モデル側の random_state を固定しなければ、実行するたびに結果（選ばれる最適値など）が変わることがあります。

In
from sklearn.datasets import load_wine
from sklearn.model_selection import GridSearchCV, train_test_split
from sklearn.tree import DecisionTreeClassifier

X, y = load_wine(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=0)
grid = {"max_depth": [2, 3, 4, 5, 6]}
free = []
for i in range(8):           # モデルの random_state を固定しない
    gs = GridSearchCV(DecisionTreeClassifier(), grid, cv=5).fit(X_train, y_train)
    free.append(gs.best_params_["max_depth"])
fixed = []
for i in range(8):           # モデルの random_state を固定する
    gs = GridSearchCV(DecisionTreeClassifier(random_state=0), grid, cv=5).fit(X_train, y_train)
    fixed.append(gs.best_params_["max_depth"])
print("固定しない:", free)
print("固定する  :", fixed)
Out 
固定しない: [3, 3, 4, 6, 5, 5, 3, 6]
固定する  : [3, 3, 3, 3, 3, 3, 3, 3]

固定しない方は、実行するたびに並びが変わる可能性があります。「▶ 実行」を何度か押して確かめてみましょう。

4.4.7クラスタリング

クラスタリングは、ある基準でデータ同士の類似性（距離など）を計算し、似たデータをクラスタ（グループ）にまとめるタスクです。教師なし学習の典型的なタスクです。

階層的クラスタリング
凝集型まず似ているデータ同士をまとめて小さなクラスタを作り、似ているクラスタ同士をさらにまとめる。最終的にすべてが1つのクラスタになるまで繰り返す。一般的によく使われるのはこちら。
分割型最初にすべてのデータが1つのクラスタに属すると考え、順にクラスタを分割していく。計算量が多くなるため、凝集型ほどは使われない。

階層的クラスタリングは、凝集型と分割型に分かれます。まとめていく過程は、デンドログラム（樹形図）で表せます。

覚え方

凝集型 ＝ ボトムアップ（1件ずつの小さなまとまりから、だんだん集まって1つになる）。分割型 ＝ トップダウン（全体の1つから、だんだん割っていく）。全体から割り方を考える分割型の方が計算が重く、一般には凝集型がよく使われます。scikit-learn のクラス名も AgglomerativeClustering（agglomerative ＝ 凝集する）です。

In
import numpy as np
from sklearn.cluster import AgglomerativeClustering

X = np.array([[1, 2], [1, 4], [1, 0], [10, 2], [10, 4], [10, 0]])
ac = AgglomerativeClustering(n_clusters=2)    # 凝集型
print(ac.fit_predict(X))
Out 
[1 1 1 0 0 0]
k-means
1中心をランダムに置くクラスタの数 k を決め、k 個のクラスタ中心をランダムに置く。
2近い中心に割り当て各データを、最も近いクラスタ中心のクラスタに入れる。
3中心を更新各クラスタのデータの平均の位置に中心を移す。
4収束まで繰り返す中心が動かなくなるまで2と3を繰り返す。

k-means を scikit-learn で行うには、sklearn.cluster モジュールの KMeans クラスを使います。

In
from sklearn.datasets import make_blobs
from sklearn.cluster import KMeans
import matplotlib.pyplot as plt

X, _ = make_blobs(n_samples=150, centers=3, random_state=3)   # 3つの塊があるデータを作る
km = KMeans(n_clusters=3, n_init=10, random_state=0)
labels = km.fit_predict(X)
print(labels[:10])
print(km.cluster_centers_.round(2))    # 求めたクラスタ中心
fig, ax = plt.subplots(figsize=(5, 3.5))
ax.scatter(X[:, 0], X[:, 1], c=labels)
ax.scatter(km.cluster_centers_[:, 0], km.cluster_centers_[:, 1], marker="*", s=300, c="red")
plt.show()
Out 
[2 1 2 0 0 0 2 2 2 2]
[[ 8.17  8.16]
 [-4.3   0.27]
 [ 0.83  4.12]]

クラスタの数 k は、人が事前に決めるハイパーパラメータです。k を変えながら、クラスタ内の距離の合計（inertia_）が下がりにくくなる点を探して k を決める方法を、エルボー法と呼びます。

覚え方

k-means ＝ k 個の mean（平均）。クラスタ中心を「所属するデータの平均の位置」に動かし続ける手法なので、この名前です。グラフが肘（elbow）のように折れ曲がる点で k を決めるのがエルボー法です。

このほか、データの密度にもとづいてクラスタを作る DBSCAN もあります。DBSCANは、クラスタの数を事前に決める必要がありません。

POINT
  • 前処理：エンコーディング（Label / One-hot）、正規化（StandardScaler＝平均0・標準偏差1、MinMaxScaler＝0〜1）。
  • 分類：既知のラベルで学習する。SVM はマージン最大化とカーネル法、決定木は情報利得、ランダムフォレストはブートストラップ＋多数決。
  • 回帰：説明変数1つなら単回帰、2つ以上なら重回帰。次元削減：PCA は分散が大きい方向を主成分にする（decomposition.PCA）。
  • 評価：適合率・再現率・F値・正解率は分類の指標。グリッドサーチは GridSearchCV で、交差検証で評価する。
  • クラスタリング：教師なし学習。凝集型がよく使われる。k-means は cluster.KMeans。
