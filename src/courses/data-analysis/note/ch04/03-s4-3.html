4.3Matplotlib 6問

グラフを描く Matplotlib で、描画の仕組み、グラフの種類と出力方法、スタイルの指定を説明します。

4.3.1Matplotlibの概要

Matplotlib はグラフを描くパッケージです。matplotlib.pyplot を plt という名前でimportして使います。Jupyterでは、%matplotlib inline を実行するとノートブック内にグラフが表示されます（JupyterLab では通常、指定しなくても表示されます）。

書き方は2通りありますが、主教材と試験はオブジェクト指向の書き方が中心です。

pyplot の関数で描くplt.plot(x, y) のように書く手軽な書き方。
オブジェクト指向で描くfig, ax = plt.subplots() で描画の土台を作り、ax.plot(...) のようにメソッドで描く。細かい設定がしやすい。

4.3.2描画オブジェクト

  • 描画オブジェクト（Figure）：グラフ全体を載せる1枚の紙。
  • サブプロット（Axes）：紙の上に置く、1つ1つのグラフ領域。1つの描画オブジェクトに複数置ける。
  • タイトルは、描画オブジェクト全体には fig.suptitle()、サブプロットごとには ax.set_title() で付けます。
fig.suptitle("全体のタイトル")
ax.set_title("A")
サブプロット
ax.set_title("B")
サブプロット
ax.set_title("C")
サブプロット
ax.set_title("D")
サブプロット
fig, axes = plt.subplots(2, 2)
実線の枠＝描画オブジェクト（Figure）、点線の枠＝サブプロット（Axes）
覚え方

suptitle ＝ super title（上位のタイトル）：描画オブジェクト全体に1つ。set_title：サブプロットそれぞれに「タイトルを set する」。

Javaと比べると

Swingで言えば、描画オブジェクト（Figure）は JFrame、サブプロット（Axes）はその中に並べる JPanel のような関係です。plt.subplots(2, 2) は GridLayout(2, 2) でパネルを4つ置くイメージです。

In

fig, axes = plt.subplots(2, 2, figsize=(6, 4))   # 2行2列のサブプロット
print(type(fig).__name__, axes.shape)

axes[0, 1].bar([1, 2, 3], [3, 1, 2])
axes[0, 1].set_title("bar")
axes[1, 0].scatter([1, 2, 3], [3, 1, 2])
axes[1, 0].set_title("scatter")
axes[1, 1].hist([1, 2, 2, 3, 3, 3])
axes[1, 1].set_title("hist")
fig.suptitle("Figure title")
fig.tight_layout()
plt.show()
Out

subplots() を引数なしで呼ぶと、サブプロットは1つです。fig = plt.figure() で描画オブジェクトを作り、ax = fig.add_subplot(2, 1, 1)（2行1列の1番目）のようにサブプロットを追加する書き方もあります。

4.3.3グラフの種類と出力方法

折れ線グラフ（plot）と凡例
In
import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(0, 2 * np.pi, 50)
fig, ax = plt.subplots()
ax.plot(x, np.sin(x), label="sin")
ax.plot(x, np.cos(x), label="cos", linestyle="--")
ax.set_xlabel("x")
ax.set_ylabel("y")
ax.legend(loc="best")             # label= の文字で凡例を表示
plt.show()
Out
  • 折れ線グラフは plot で描きます。1つのサブプロットに何本でも重ねられます。
  • legend で凡例を表示します。各線の名前は plot の label= で指定します。loc="best"（既定）にすると、データとの重なりが最も少ない位置に表示されます。loc="upper right" のように位置を指定することもできます。
  • 軸ラベルは set_xlabel / set_ylabel、表示範囲は set_xlim / set_ylim で指定します。
棒グラフ（bar）と積み上げ棒グラフ
In
import matplotlib.pyplot as plt

fig, ax = plt.subplots()
x = [1, 2, 3, 4]
y = [5, 8, 3, 6]
ax.bar(x, y, tick_label=["Mon", "Tue", "Wed", "Thu"])   # tick_label で目盛りにラベル
plt.show()
Out

棒グラフは bar で描きます（横向きは barh）。積み上げ棒グラフは、次のどちらかの方法で描きます。

  • 下の段を描いた後、上の段を bottom=（下の段の値）を指定して描く。
  • 先に「下の段＋上の段」の合計の高さで棒を描き、その上から下の段の棒を重ねて描く。
In
import matplotlib.pyplot as plt

x = [1, 2, 3]
lunch = [4, 6, 5]
dinner = [7, 3, 6]
labels = ["A", "B", "C"]
fig, axes = plt.subplots(1, 2, figsize=(8, 3))
# 方法1：bottom で上の段を積む
axes[0].bar(x, lunch, tick_label=labels, label="lunch")
axes[0].bar(x, dinner, bottom=lunch, label="dinner")
axes[0].legend()
# 方法2：合計を先に描き、下の段を重ねる
total = [a + b for a, b in zip(lunch, dinner)]   # 要素ごとの合計
axes[1].bar(x, total, tick_label=labels, label="dinner")
axes[1].bar(x, lunch, label="lunch")
axes[1].legend()
plt.show()
print(total)
Out 
[11, 9, 11]

2つのリストから要素を1つずつ組にして取り出すには、zip() を使います。[a + b for a, b in zip(lunch, dinner)] で、要素ごとの合計のリストが作れます。

覚え方

zip ＝ ファスナー。左右の歯を1つずつ噛み合わせるように、2つのリストの要素を1組ずつペアにします。積み上げ棒グラフの bottom は「この棒の底（bottom）をどこに置くか」です。

散布図（scatter）
In
import numpy as np

np.random.seed(0)
x = np.random.rand(50)
y = x + np.random.rand(50) * 0.5
fig, ax = plt.subplots()

Out

散布図は scatter で描きます。marker で点の形を変えられます。

ヒストグラム（hist）
In
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(1)
mu, sigma = 50, 10                          # 平均と標準偏差
x = np.random.normal(mu, sigma, 500)
fig, axes = plt.subplots(1, 2, figsize=(8, 3))
n, bins, patches = axes[0].hist(x, bins=20)   # 20個の階級に分ける
axes[1].hist(x, bins=20, orientation="horizontal")   # 横向き
plt.show()
print(len(n), len(bins))     # 度数は20個、階級の境界は21個
for i in range(3):
    print("{:.1f} - {:.1f} : {}".format(bins[i], bins[i + 1], n[i]))
Out 
20 21
22.1 - 25.0 : 3.0
25.0 - 27.9 : 4.0
27.9 - 30.8 : 9.0
  • ヒストグラムは hist で描きます。bins=20 でデータを20個の区間（階級）に分けます。
  • hist は (各区間の度数 n, 区間の境界 bins, 図形 patches) を返します。区間が20個なら境界は21個です。
  • orientation="horizontal" で横向きのヒストグラムになります。
  • 乱数のシードを固定しているので、何度実行しても同じグラフになります。
覚え方

bins ＝ 箱（ビン）の数。データを何個の箱に振り分けるか、です。境界の数は「箱の数 ＋ 1」になります（柵の間が n 区間なら、杭は n+1 本必要、という植木算と同じ）。

箱ひげ図（boxplot）
In
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(2)
data = [np.random.normal(0, s, 100) for s in (1, 2, 3)]
fig, ax = plt.subplots()
ax.boxplot(data, labels=["s=1", "s=2", "s=3"])
plt.show()
Out

目盛りのラベルを指定する引数 labels は、Matplotlib 3.9 以降 tick_labels という名前に変わりました（labels も当面は使えます）。

円グラフ（pie）
In
import matplotlib.pyplot as plt

labels = ["rice", "bread", "noodle", "other"]
x = [45, 30, 20, 5]
fig, axes = plt.subplots(1, 2, figsize=(8, 3.5))
axes[0].pie(x, labels=labels)                     # 既定：右（3時）から反時計回り
axes[0].set_title("default")
axes[1].pie(x, labels=labels, startangle=90, counterclock=False,
            shadow=True, autopct="%1.1f%%", explode=[0.1, 0, 0, 0])
axes[1].set_title("customized")
plt.show()
Out

円グラフは pie で描きます。主な引数は次のとおりです。

引数意味
labels各要素のラベル
startangle開始位置の角度。既定は0（右・3時の位置）、90 で真上（12時）から始まる
counterclock既定の True は反時計回り、False で時計回り
shadow=True影を付ける
autopct割合をパーセントで表示する。"%1.1f%%" は小数1桁（%% で % 記号）
explode要素を中心から切り離して強調する
覚え方
  • counterclock ＝ counter-clockwise（反時計回り）。True（既定）で反時計回り、False にすると時計回り。
  • startangle は角度：0°＝右（3時）、90°＝真上（12時）。時計の文字盤ではなく、数学の角度の向きです。
  • autopct ＝ auto percent。%1.1f は小数1桁の書式、後ろの %% で「%」記号を1つ表示します。
  • explode ＝ 爆発。扇形を外へ飛び出させます。

古い Matplotlib では、円グラフを真円にするために ax.axis("equal") でアスペクト比をそろえる必要がありました。現在の版（3.3 以降）では、pie を描くと自動で真円になります。

ファイルへの出力（savefig）

作成したグラフは savefig("ファイル名") でファイルに出力できます。拡張子によって形式が決まり、png・pdf・svg などが選べます。

In
import os
import matplotlib.pyplot as plt

fig, ax = plt.subplots()
ax.plot([1, 2, 3], [2, 1, 3])
fig.savefig("graph.png")
fig.savefig("graph.pdf")
plt.close(fig)
print(os.path.exists("graph.png"), os.path.exists("graph.pdf"))
Out

4.3.4スタイル

スタイルの適用

matplotlib.style（plt.style.use()）で、線の色や太さ、背景色などを含むグラフ全体の表示スタイルを切り替えられます。使えるスタイルの一覧は plt.style.available で確認できます。

色・線・テキスト
In
import matplotlib.pyplot as plt

plt.style.use("ggplot")           # スタイルを適用
fig, ax = plt.subplots()
ax.plot([1, 2, 3], [1, 3, 2], color="red", linewidth=6, linestyle=":")
ax.set_title("Title", family="monospace", size=18, weight="bold")
ax.text(1.2, 2.6, "text here", color="blue", size=12)   # (x, y) を左下にテキストを描く
plt.show()
print(len(plt.style.available) > 10)
Out 
True
  • 線の色は color="red"、幅は linewidth（ポイント単位）、種類は linestyle（"--" 破線、":" 点線など）で指定します。
  • タイトルなどの文字には、family（フォントファミリー、例："monospace"）、size、weight（太さ）を指定できます。
  • text(x, y, 文字列) で、座標 (x, y) を左下としてテキストを描けます。フォントの指定も同じ引数でできます。
フォント設定をまとめて指定する（fontdict）

同じフォント設定を何度も使うときは、設定を辞書（dict）にまとめて fontdict 引数に渡します。辞書なので、後から値を変更（上書き）することもできます。

Javaと比べると

fontdict は、設定を Map<String, Object> にまとめてメソッドに渡すイメージです。名前のとおり font の dict（辞書）を渡します。

In
import matplotlib.pyplot as plt

font = {"family": "monospace", "size": 14, "weight": "bold"}   # 辞書で作る
fig, ax = plt.subplots()
ax.plot([3, 1, 2])
ax.set_title("title", fontdict=font)
ax.set_xlabel("x label", fontdict=font)
plt.show()
Out

4.3.5pandasのオブジェクトからグラフ描画

DataFrame や Series には plot メソッドがあり、内部で Matplotlib を使ってグラフを描きます。kind= でグラフの種類（"line"、"bar"、"hist"、"scatter"、"pie" など）を選べます。

In
import pandas as pd
import matplotlib.pyplot as plt

df = pd.DataFrame({"A": [3, 5, 2, 6], "B": [1, 4, 4, 2]}, index=["Q1", "Q2", "Q3", "Q4"])
fig, axes = plt.subplots(1, 2, figsize=(8, 3))
df.plot(ax=axes[0], title="line")              # 既定は折れ線
df.plot(kind="bar", ax=axes[1], title="bar")   # kind で種類を指定
plt.show()
Out
POINT
  • 描画オブジェクト（Figure）の上にサブプロット（Axes）を置く。全体のタイトルは suptitle、サブプロットは set_title。
  • plot＝折れ線、bar＝棒、scatter＝散布図、hist＝ヒストグラム、boxplot＝箱ひげ図、pie＝円グラフ。
  • legend(loc="best") は重なりの少ない位置に凡例を出す。savefig は png・pdf・svg などで保存する。
  • スタイルは matplotlib.style、文字の設定はまとめて fontdict（辞書）に渡す。
