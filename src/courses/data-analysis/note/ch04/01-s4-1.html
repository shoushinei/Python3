4.1NumPy 6問

数値計算の土台となる NumPy で、配列（ndarray）の作り方・扱い方と、各種の計算機能を説明します。

4.1.1NumPyの概要

NumPy は、配列や行列を効率よく扱うためのサードパーティ製パッケージです。中身がC言語で書かれているので、Pythonのリストをfor文で回すよりはるかに高速に計算できます。慣習として np という名前でimportします。

  • 配列用の型 ndarray（N次元配列）が中心です。
  • 行列用の型 matrix もありますが、現在は非推奨で、行列も ndarray で扱うのが普通です。
  • リストと違い、1つの配列の要素はすべて同じデータ型になります。
Javaと比べると

ndarray は、要素の型がそろった Java の配列（int[] や double[][]）に近いものです。ただし、for文を書かなくても配列全体をまとめて計算できます。

4.1.2NumPyでデータを扱う

配列の作成と、型・形状の確認
In
import numpy as np

a = np.array([10, 20, 30, 40])
print(type(a))       # オブジェクトの型
print(a.dtype)       # 要素のデータ型

b = np.array([[1, 2], [3, 4], [5, 6]])
print(b.shape, b.ndim, b.size)   # 形状、次元数、要素の総数
c = np.array([1, 2.5, 3])
print(c.dtype)       # 小数が1つでもあれば全体が float64 になる
Out 
<class 'numpy.ndarray'>
int64
(4,)
(3, 2) 2 6
float64
  • type() でオブジェクトの型（numpy.ndarray）を、dtype で要素のデータ型を確認します。
  • shape で形状を確認します。shape は属性なので、カッコは付けません（資料によっては「shapeメソッド」と書かれていることもあります）。
  • 整数のリストから作ると int64、小数を含むと float64 になります（WindowsでNumPy 1.x を使っている場合、整数は int32 になることがあります）。
  • np.array([1, 2], dtype=np.float32) のように型を指定したり、a.astype(float) で型を変換したりできます。
形の変更：reshape・ravel・flatten
In
import numpy as np

a = np.arange(8)          # [0 1 2 3 4 5 6 7]
b = a.reshape(2, 4)       # 2行4列に変える
print(b)
print(a.reshape(4, -1))   # -1 は「残りから自動で決める」
print(b.ravel())          # 1次元に戻す
print(b.flatten())        # 1次元に戻す
Out 
[[0 1 2 3]
 [4 5 6 7]]
[[0 1]
 [2 3]
 [4 5]
 [6 7]]
[0 1 2 3 4 5 6 7]
[0 1 2 3 4 5 6 7]

reshape は次元（形）を変換します。ravel と flatten は、どちらも多次元配列を1次元にしますが、コピーを作るかどうかが違います。

ravel()できるだけ元の配列を参照する（ビュー）配列を返す。結果を書き換えると、元の配列も変わる。
flatten()必ずコピーを返す。結果を書き換えても、元の配列は変わらない。
覚え方

flatten ＝ 「平らに（flat）した新品」を作る → 新しく作るのでコピー。ravel ＝ 「ほどく」 → 元の配列をそのまま見ているだけ（ビュー）。

In
import numpy as np

m = np.array([[1, 2], [3, 4]])
r = m.ravel()
f = m.flatten()
r[0] = 100     # ravel の結果を書き換える
f[1] = 200     # flatten の結果を書き換える
print(m)       # ravel の変更だけが元の配列に伝わる
Out 
[[100   2]
 [  3   4]]
要素の取り出し：インデックスとスライス

インデックスは0から始まり、-1 は末尾を表します。スライス 開始:終了 は終了の位置を含みません。2次元配列は a[行, 列] のようにカンマで区切って指定します。

In
import numpy as np

a = np.array([[10, 20, 30], [40, 50, 60], [70, 80, 90]])
print(a[1, 2])        # 1行目の2列目
print(a[0])           # 0行目全体
print(a[:, 1])        # すべての行の1列目
print(a[1:, [0, 2]])  # 1行目以降（スライス）× 0列目と2列目（リスト）
print(a[-1, [0, 2]])  # 最後の行（整数）× 0列目と2列目
print(a[a > 55])      # 条件に合う要素だけ（ブールインデックス）
Out 
60
[10 20 30]
[20 50 80]
[[40 60]
 [70 90]]
[70 90]
[60 70 80 90]
注意：結果の次元に気をつける

行の指定がスライス（1: や -1:）なら結果は2次元のまま、整数（-1）なら1次元になります。上の例の a[1:, [0, 2]] はカッコが二重の2次元、a[-1, [0, 2]] は1次元です。列の位置に [0, 2] のようなリストを渡すと、その列だけを取り出せます（ファンシーインデックス）。

覚え方
  • arange ＝ array + range。Pythonの range と同じく、終点を含まない。指定するのは「間隔（step）」。
  • linspace ＝ linear space（直線を等分）。線の両端に点を打って等分するイメージなので、両端を含む。指定するのは「個数（num）」。点が num 個なら、間隔は (stop − start) ÷ (num − 1)。
  • eye ＝ I（アイ）。単位行列の記号 I と同じ発音。
  • full ＝ 指定した値で満タン（full）にする。

乱数
In
import numpy as np

print(np.random.normal(50, 10, 3))        # 平均50・標準偏差10の正規分布

  • np.random.seed(値) で乱数の種を固定すると、何度実行しても同じ乱数が出ます。実行結果の再現性を確保するために使います。

POINT
  • type は型、shape は形状、dtype は要素の型。reshape は形の変換、ravel はビュー、flatten はコピー。
  • スライスで取り出すと次元は保たれ、整数で取り出すと次元が1つ減る。
  • arange と randint の終点は含まない。linspace の終点は含む。eye は単位行列（float）。

4.1.3NumPyの各機能

ユニバーサルファンクション

配列に + 1 や * 10 をすると、for文を書かなくても全要素に同じ計算がされます。np.sqrt や np.log10 のように、配列の全要素に関数を適用する関数をユニバーサルファンクション（ufunc）と呼びます。

In
import numpy as np

a = np.array([1, 4, 9, 16])
print(a + 1, a * 10)       # 全要素に計算
print(np.sqrt(a))          # 平方根
print(np.log10(a * 25))    # 25, 100, 225, 400 の常用対数
print(np.exp([0, 1]).round(3), np.abs([-2, 3]))
Out 
[ 2  5 10 17] [ 10  40  90 160]
[1. 2. 3. 4.]
[1.39794001 2.         2.35218252 2.60205999]
[1.    2.718] [2 3]
ブロードキャスト

形の違う配列同士でも、小さい方を自動で引き延ばして計算してくれます。これをブロードキャストと呼びます。

In

m = np.array([[1, 2, 3], [4, 5, 6]])   # 2行3列
v = np.array([10, 20, 30])             # 3要素
print(m + v)        # v が各行に足される
print(m * 2)        # スカラーは全要素に
col = np.array([[100], [200]])         # 2行1列
print(m + col)      # col が各列に足される
Out 
[[11 22 33]
 [14 25 36]]
[[ 2  4  6]
 [ 8 10 12]]
[[101 102 103]
 [204 205 206]]

import numpy as np

print(b.T)                               # 転置（2行3列 → 3行2列）

  • concatenate で連結します。axis=0 は行が増える方向（縦）、axis=1 は列が増える方向（横）です。pandas でも同じ考え方です。
  • hstack は横（horizontal）、vstack は縦（vertical）に連結します。1次元配列同士の hstack は、単純に後ろにつなげる連結です。
  • .T は転置です。1×4 の配列を .T にすると 4×1 になります。
覚え方

hstack ＝ horizontal（水平＝横に並べる）、vstack ＝ vertical（垂直＝縦に積む）。.T は Transpose（転置）の T です。

In
import numpy as np

x = np.full((1, 4), 7).T          # 1×4 → 4×1
print(x.shape)
y = x.ravel()                      # 4×1 → 1次元の4要素
z = np.hstack([y, np.linspace(0, 1, 3)])   # 1次元同士の hstack
print(y, z, z.shape)
Out 
(4, 1)
[7 7 7 7] [7.  7.  7.  7.  0.  0.5 1. ] (7,)
ドット積（内積・行列積）

第3章の内積や行列の積は、np.dot(x, y) または演算子 @ で計算します。* は同じ位置の要素同士の掛け算（要素積）なので、区別しましょう。

Javaと比べると

Javaで内積を書くと for (int i = 0; i < a.length; i++) sum += a[i] * b[i]; のようなループになります。NumPyではこれを a @ b の1語で書けます。一方、a * b は「ループの中の a[i] * b[i] を並べただけ」（足し合わせない）と考えると区別しやすくなります。

In
import numpy as np

a = np.array([2, 1])
b = np.array([3, 4])
c = np.array([[1, 0], [2, 3]])
print(a * b)          # 要素積 → [6 4]
print(a @ b)          # 内積 → 2×3 + 1×4 = 10
print(np.dot(c, a))   # 行列×ベクトル → [1×2+0×1, 2×2+3×1] = [2 7]
print(c @ c)          # 行列積
Out 
[6 4]
10
[2 7]
[[1 0]
 [8 9]]
POINT
  • 配列とスカラーの演算や ufunc は全要素に作用する。形の違う配列はブロードキャストで計算される。
  • axis=0 は縦方向（行が増える／列ごとに集約）、axis=1 は横方向。
  • 内積・行列積は np.dot または @。* は要素積。
