4.2.1pandasの概要

pandas は、NumPyを基盤に、表形式のデータを扱いやすくしたパッケージです。慣習として pd という名前でimportします。データ型は次の2つです。

Series（1次元）ラベル（インデックス）付きの1列のデータ。
DataFrame（2次元）行ラベル（index）と列ラベル（columns）を持つ表。各列は Series。

Series は1次元、DataFrame は2次元のデータ型です。

Javaと比べると
  • Series は、順序を保つ LinkedHashMap<String, Integer> に近いものです（キー＝インデックス）。さらに、0, 1, 2… という位置でも取り出せます。
  • DataFrame は、データベースのテーブルや、Excelの1枚のシートのイメージです。Javaなら「列名 → 列データ」の Map を並べたもの、あるいは DTO の List を表にしたものと考えられます。

覚え方

iloc の i ＝ integer（整数の位置）、loc ＝ location（ラベルで場所を指す）。どちらも順番は「行, 列」で、表を左上から読む順と同じです。

Javaと比べると

loc は map.get("juice") のようにキーで取り出すイメージ、iloc は list.get(2) のように番号で取り出すイメージです。

  • どちらも「行, 列」の順で指定します。
  • loc のスライスは終わりのラベルを含みます。iloc のスライスは、Pythonのリストと同じく終わりを含みません。
  • iloc に文字列を渡したり、範囲外の番号を指定したりするとエラーになります。df["列名"] は列の取り出しで、行と列を同時には指定できません。

4.2.3データの整形

条件による抽出

比較の結果は True / False の Series になります。これを df[...] に渡すと、True の行だけが抽出されます。

In
import pandas as pd

df = pd.DataFrame({"price": [120, 80, 300, 150], "kind": ["fruit", "fruit", "drink", "drink"]},
                  index=["apple", "orange", "juice", "tea"])
mask = df["price"] > 100
print(mask)
print(df[mask])
print(df[(df["price"] > 100) & (df["kind"] == "drink")])

複数の条件は、and・or ではなく &（かつ）・|（または）でつなぎ、各条件をカッコで囲みます。

Javaと比べると

df[df["price"] > 100] は、list.stream().filter(x -> x.getPrice() > 100) と同じ「条件に合う行だけ残す」処理です。条件をつなぐ &・| は、Javaの &&・|| ではなくビット演算子の形なので、演算子の優先順位の都合で各条件をカッコで囲みます。

列の追加・更新と apply

新しい列名に代入すると列が追加され、既存の列名なら値が更新されます。apply(関数) を使うと、Series の各要素に関数を適用した結果を得られます。

Javaと比べると

apply(rank) は、stream().map(this::rank) と同じく「各要素を関数に通して、結果を並べる」処理です。

In
import pandas as pd

df = pd.DataFrame({"score": [88, 52, 71]}, index=["s1", "s2", "s3"])

def rank(x):
    if x >= 80:
        return "A"
    elif x >= 60:
        return "B"
    return "C"

df["bonus"] = df["score"] + 5             # 列の追加（ブロードキャスト）
df["rank"] = df["bonus"].apply(rank)      # 各要素に関数を適用
print(df)
top = df[df["bonus"] > 60]                # 条件で抽出
print(top)
print(top.iloc[1, 2])                     # 抽出後の位置で指定
Out

s1     88     93    A
s2     52     57    C
s3     71     76    B
    score  bonus rank
s1     88     93    A
s3     71     76    B

注意：抽出すると位置が詰め直される

条件で抽出した後の DataFrame では、iloc の位置は残った行だけで0から数え直されます。上の例では s2 が除かれたので、top.iloc[1] は元の3行目（s3）です。一方、loc のラベルは元のまま変わりません。

4.2.4時系列データ

pd.date_range() で、日付が並んだインデックス（DatetimeIndex）を作れます。開始日 start に加えて、個数 periods か、終了日 end のどちらかを指定します。

In
import pandas as pd

d1 = pd.date_range(start="2025-01-01", periods=90)       # 開始日から90日分
d2 = pd.date_range(start="2025-01-01", end="2025-03-31") # 開始日〜終了日
print(d1[0], d1[-1], len(d1))
print((d1 == d2).all())                                  # 同じ日付が並ぶ
print(pd.date_range("2025-01-01", periods=3, freq="W-SUN"))   # 毎週日曜日
Out 
2025-01-01 00:00:00 2025-03-31 00:00:00 90
True
DatetimeIndex(['2025-01-05', '2025-01-12', '2025-01-19'], dtype='datetime64[ns]', freq='W-SUN')

freq で間隔を指定します。"D"（毎日、既定）、"W-SUN"（日曜日で終わる週）、"ME"（月末）、"h"（毎時）などがあります。

覚え方

D ＝ Day、W ＝ Week、ME ＝ Month End、h ＝ hour。"W-SAT" は「Week ending on SATurday（土曜で終わる週）」と読みます。インデックスに付く日付は、その週の最後の日（土曜日）です。

日付をインデックスに持つDataFrameは、groupby(pd.Grouper(freq=...)) や resample(...) で、週ごと・月ごとに集計できます。

In
import numpy as np
import pandas as pd

np.random.seed(0)                                      # 再現性のためにシードを固定
dates = pd.date_range(start="2025-01-01", periods=90)
df = pd.DataFrame(np.random.randint(0, 100, 90), index=dates, columns=["visitors"])
print(df["visitors"].min(), df["visitors"].max())      # 0〜99（100は含まない）
week = df.groupby(pd.Grouper(freq="W-SUN")).sum()      # 日曜日で区切った週ごとの合計
print(week.head(3))
month = df.resample("ME").sum()                        # 月ごとの合計
print(month)
Out 
0 99
            visitors
2025-01-05       289
2025-01-12       394
2025-01-19       395
            visitors
2025-01-31      1762
2025-02-28      1146
2025-03-31      1397
  • "W-SUN" は日曜日で終わる週です。各行のインデックスはその週の日曜日の日付で、値は月曜日〜日曜日の合計です。2025-01-01 は水曜日なので、最初の行は水〜日の5日分だけの合計になります。
  • "W-SAT" なら土曜日で終わる週（日曜日〜土曜日）です。月ごとに集計すると、行数は含まれる月の数になります（上の例は1〜3月の3行）。

月末を表す freq は、pandas 2.2 から "ME" と書くようになりました。古い資料のように "M" と書いても同じ結果になりますが、警告が表示されます。

覚え方

In

print(df["y"].mode().tolist(), df["y"].median(), df["y"].count())
print(df["y"].std(), df["y"].var())   # 標準偏差と分散
print(df.corr())                     # 相関係数（−1〜1）

pandas の std()・var() は、既定で「個数」ではなく「個数−1」で割る計算（不偏分散）をします。そのため、「個数」で割る NumPy の np.std() とは値が少し違います。

POINT
  • Series は1次元、DataFrame は2次元。loc はラベル、iloc は位置。values で NumPy 配列に変換すると、ラベルはなくなる。
  • 読み書きは read_xxx / to_xxx（csv・excel・html・pickle）。
  • 欠損値の削除は dropna、補完は fillna（ffill・bfill・値を渡す）。
  • concat の axis=0 は行方向、axis=1 は列方向。std は標準偏差、var は分散、corr は相関係数。
