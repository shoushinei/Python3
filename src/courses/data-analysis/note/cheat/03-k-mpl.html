描画オブジェクトとグラフの種類

書き方・グラフ答え注意点
fig, ax = plt.subplots()描画オブジェクト1つとサブプロット1つを作る(2, 2) なら axes は2×2
全体のタイトルfig.suptitle()入れ替えに注意
サブプロットのタイトルax.set_title()
折れ線グラフplot
棒グラフbar（横棒は barh）積み上げは bottom=
散布図scatter
ヒストグラムhist
箱ひげ図boxplot
円グラフpie
ax.legend(loc="best")凡例を、データとの重なりが最小の位置に表示名前は plot の label=
fig.savefig("a.png")ファイルに出力（png・pdf・svg など）

引数

引数答え注意点
hist(x, bins=25)25個の区間に分ける。戻り値は (n, bins, patches)境界 bins は26個
orientation="horizontal"ヒストグラムを横向きにする
startangle=90円グラフを真上（12時）から始める既定0は右（3時）
counterclock=False時計回りに配置既定 True が反時計回り
shadow=True影を付ける
autopct="%1.1f%%"割合をパーセント表示（小数1桁）
explode扇形を切り離して強調する
color / linewidth / linestyle線の色 / 線の太さ / 線の種類
family="monospace"フォントファミリーを指定
fontdict=…フォント設定を辞書（dict）でまとめて渡す
ax.text(x, y, "文字")(x, y) を左下としてテキストを描く
plt.style.use("ggplot")グラフ全体のスタイルを適用（matplotlib.style）
tick_label=[…]棒グラフの目盛りにラベルを付ける
