ペア答え（違い）
ravel と flattenravel＝ビュー（参照）、flatten＝コピー
arange と linspacearange＝間隔指定・終点を含まない、linspace＝個数指定・終点を含む
axis=0 と axis=10＝行方向（縦。行が増える／縦に集約）、1＝列方向（横）
loc と ilocloc＝ラベル（スライスは終わりを含む）、iloc＝位置（含まない）
std と varstd＝標準偏差、var＝分散
ffill と bfillffill＝前の値で埋める、bfill＝後ろの値で埋める
suptitle と set_titlesuptitle＝描画オブジェクト全体、set_title＝サブプロット
scatter と histscatter＝散布図、hist＝ヒストグラム
StandardScaler と MinMaxScaler平均0・標準偏差1 ／ 最小0・最大1
適合率と再現率適合率＝予測が正のものの中の正解、再現率＝実際の正のうち拾えた割合
凝集型と分割型凝集型＝ボトムアップでよく使う、分割型＝トップダウンで計算量が多い
