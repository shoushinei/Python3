手法の特徴

手法・用語答え注意点
fit / predict / transform学習 / 予測 / 変換（fit_transform は両方）
分類既知のラベルを教師にする教師あり学習
サポートベクタマシンマージン最大化。カーネル法で高次元に写して線形分離。外れ値検出にも使える
決定木情報利得（親の不純度 − 子の不純度）で分割。子のないノードはリーフ
ランダムフォレストブートストラップで作った多数の決定木の多数決・平均（アンサンブル学習）
単回帰 / 重回帰説明変数が1つ / 2つ以上
次元削減説明変数（特徴量）の数を減らす
主成分分析分散が大きい方向を主成分にし、元の次元以下に変換寄与率で情報量を確認
ハイパーパラメータ学習前に人が決める値（max_depth、C、k など）
グリッドサーチ候補の全組み合わせを交差検証で評価し、最良を選ぶ結果は best_params_
k分割交差検証k個に分け、テスト用を入れ替えて k 回評価し平均cv=10 なら10分割
random_state乱数の種。固定しないと実行ごとに結果が変わりうる
凝集型 / 分割型小さくまとめて1つへ（ボトムアップ）/ 全体から分割（トップダウン、計算量が多い）よく使われるのは凝集型
k-meansランダムな中心から始め、割り当てと中心更新を収束まで繰り返す

評価指標の式

指標答え（式）重視する場面
正解率(TP + TN) / (TP + FP + FN + TN)全体の当たりの割合
適合率TP / (TP + FP)正の予測を間違えたくない
再現率TP / (TP + FN)見逃したくない
F値2 × 適合率 × 再現率 / (適合率 + 再現率)調和平均。適合率と再現率はトレードオフ
上の4つの指標が使えるモデル分類モデル（混同行列から計算）回帰は MSE や R² など
AUCROC曲線の下の面積（1に近いほど良い、ランダムは0.5）
