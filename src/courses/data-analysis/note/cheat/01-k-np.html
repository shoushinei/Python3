NumPy

属性・形の変更

書き方答え（何をする／何が返る）注意点
type(a)オブジェクトの型（numpy.ndarray）要素の型は dtype
a.dtype要素のデータ型（int64 / float64 など）小数が1つでもあれば float64
a.shape形状（各次元の要素数のタプル）属性なのでカッコなし
a.ndim / a.size次元数 / 要素の総数
a.reshape(2, -1)形を変える（-1 は自動計算）
a.ravel()1次元にする。ビュー（参照）を返す書き換えると元も変わる
a.flatten()1次元にする。コピーを返すravel と逆に覚えない
a.T転置（行と列を入れ替え）(1, 5) → (5, 1)
a.astype(float)データ型を変換する

配列を作る

書き方答え注意点
np.arange(1, 10, 3)[1 4 7]（間隔を指定）終点を含まない
np.linspace(0, 1, 5)[0. 0.25 0.5 0.75 1.]（個数を指定）終点を含む
np.zeros((2, 3)) / np.ones(3)全部0 / 全部1（float）
np.full((2, 2), 7)全部を指定値（7）で埋めた配列
np.eye(3)3×3 の単位行列（対角が1.0、他は0.0）要素は float
np.random.seed(0)乱数の種を固定する（再現性の確保）
np.random.rand(3)0以上1未満の一様乱数
np.random.randn(3)標準正規分布（平均0・標準偏差1）の乱数
np.random.randint(1, 7, 10)1〜6 の整数を10個high（7）は含まない
np.random.normal(50, 10, 5)平均50・標準偏差10の正規分布の乱数を5個

取り出し・計算・連結

書き方答え注意点
a[1, 2]1行目・2列目の要素0から数える
a[-1:, [0, 2]]最後の行（スライス）× 列0と2 → 2次元整数 a[-1, …] なら1次元
a[a > 3]条件に合う要素だけ（1次元）
a + 1、np.sqrt(a)全要素に計算（ユニバーサルファンクション）
形の違う配列同士の計算ブロードキャスト（小さい方を引き延ばす）
m.sum(axis=0)縦方向に集約 → 列ごとの結果指定した axis が消える
m.sum(axis=1)横方向に集約 → 行ごとの結果
np.diff(a)隣り合う要素の差（後 − 前）。要素数は1つ減る
np.concatenate([a, b], axis=1)列が増える方向（横）に連結axis=0 は行が増える（縦）
np.hstack / np.vstack横に連結 / 縦に連結h＝horizontal、v＝vertical
a @ b、np.dot(a, b)内積・行列積a * b は要素積
