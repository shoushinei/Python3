データ型と取り出し

書き方・用語答え注意点
Seriesラベル付きの1次元データ
DataFrame行ラベル・列ラベル付きの2次元データ（表）
df.loc["03", "A"]ラベル（名前）で「行, 列」を指定スライスは終わりを含む
df.iloc[2, 0]位置（0始まりの整数）で「行, 列」を指定文字列は渡せない
df["A"]A列（Series）を取り出すdf["A", "03"] は不可
df.values、df.to_numpy()NumPy配列に変換（ラベルは失われる）
df.head(n) / df.tail(n)先頭 n 行 / 末尾 n 行

整形・時系列・欠損値・連結

書き方答え注意点
df[df["A"] > 1]条件に合う行だけを抽出複数条件は & | ＋カッコ
s.apply(関数)各要素に関数を適用
df.sort_values("A")A列で並べ替え（ascending=False で降順）
df.groupby("k").sum()k の値ごとに集計
pd.date_range(start, periods=n)開始日から n 個の日付end= で終了日指定も可
freq="W-SAT"土曜日で終わる週（日〜土をまとめ、土曜の日付が付く）
freq="ME"（旧 "M"）月末ごと（月単位）
groupby(pd.Grouper(freq=…))、resample(…)日付インデックスを期間ごとに集計
df.isnull()欠損値かどうか（True/False）
df.dropna()欠損値を含む行を削除（axis=1 で列）
df.fillna(0)欠損値を0で補完
ffill()（旧 fillna(method='ffill')）1つ前（上）の値で補完
bfill()（旧 fillna(method='bfill')）1つ後（下）の値で補完
平均値・中央値で補完fillna(df.mean())、fillna(df.median())値として渡す
pd.concat([a, b])axis=0（既定）：行方向（縦）に連結axis=1 が列方向（横）
pd.merge(a, b, on="id")キー列で結合（SQLのJOIN）
