2.3JupyterLab 1問

データ分析で広く使われる、ブラウザ上の実行環境 JupyterLab について説明します。

2.3.1JupyterLabとは

JupyterLab とその前身の Jupyter Notebook は、オープンソースで開発されているWebアプリケーションです。データ分析・可視化・機械学習などに広く使われています。ブラウザ上で、コードとその実行結果、グラフ、説明文を1つのファイルにまとめながら作業できます。JupyterLab は Notebook の機能に加えて、タブやファイルブラウザなどを備えています。

2.3.2JupyterLabのインストール

(env) % pip install jupyterlab
(env) % jupyter lab        # ブラウザでJupyterLabが開く

2.3.3基本的な使い方

ノートブックとセル
  • 作成するファイルをノートブックと呼び、拡張子は .ipynb です。
  • ノートブックの中身はJSON形式のテキストで、コードや実行結果が記録されます。
  • 中身を見るには基本的にJupyterが必要ですが、GitHubなどはノートブックの表示に対応しているので、ブラウザで内容を確認できます。
  • ノートブックはセルの集まりです。コードを書くコードセルと、説明文を書くMarkdownセルがあります。
セルの実行と2つのモード
  • Shift+Enter でセルを実行し、次のセルに進みます。
  • セルの最後の式の値は、print しなくても表示されます。この教材の Out も同じ仕組みで表示しています。
  • セルの中を編集する編集モード（Enter）と、セル自体を操作するコマンドモード（Esc）があります。コマンドモードでは A で上に、B で下にセルを追加し、D D で削除、M でMarkdownセル、Y でコードセルに切り替えます。

2.3.4便利な使い方

マジックコマンド

マジックコマンドは、% または %% から始まるJupyter専用の特別なコマンドです。% は1行に、%% はセル全体に作用します。

コマンド働き
%timeit 式式を複数回繰り返し実行して実行時間を計測する
%%timeitセル全体を複数回実行して計測する
%time / %%time1回だけ実行して時間を計測する
%matplotlib inlineグラフをノートブック内に表示する
%run script.pyPythonファイルを実行する
%lsmagic使えるマジックコマンドの一覧を表示する
シェルコマンド

先頭に ! を付けると、OSのコマンド（シェルコマンド）を実行できます。

In
!pip list       # インストール済みパッケージの一覧
!ls             # ファイルの一覧（Windowsでは !dir）
補完とヘルプ

Tab キーで名前の補完ができます。np.arange? のように名前の後ろに ? を付けて実行すると、ヘルプが表示されます。

2.3.5第4章以降で使用する環境の準備

第4章で使うライブラリを、仮想環境にインストールしておきます。

(env) % pip install numpy pandas matplotlib scikit-learn
POINT
  • オープンソースのWebアプリケーション。ノートブックの拡張子は .ipynb、中身はJSON形式で、GitHubでも表示できる。
  • マジックコマンドは % / %% で始まる。%timeit は複数回試行して時間を計測する。
  • ! を付けるとシェルコマンド（例：!pip list）を実行できる。
