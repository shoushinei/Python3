2.2.1Pythonの文法

文法の考え方

Pythonは「シンプルで読みやすいコードが書けること」を設計思想として、文法が作られています。同じ動作をするプログラムは、誰が書いても似たコードになるように考えられています。

インデント

Pythonの大きな特徴は、コードのブロック構造を、カッコではなくインデント（字下げ）で表すことです。次のコードでは、for文の繰り返しの範囲は、インデントしている2〜7行目です。if-elif-else の各ブロックもインデントで表しています。

In
for i in range(10):
    if i % 5 == 0:
        print("ham")
    elif i % 3 == 0:
        print("eggs")
    else:
        print("spam")
print("Finish!")
Out

spam
spam
eggs
spam
ham
eggs
spam

eggs

コーディング規約

Pythonには、PEP 8（ペップエイト）という標準のコーディング規約があります。代表的なルールは次のとおりです。

  • 複数のモジュールをimportするときは、1行に1つずつ書く
  • インデントはスペース4つ
  • 1行は79文字以内
  • 関数名・変数名は小文字とアンダースコア（snake_case）、クラス名は CapWords
In
import sys, os   # PEP 8に違反した書き方

import sys       # PEP 8に準拠した書き方
import os

PEP 8に違反していないかは、pycodestyle というツールでチェックできます。

(env) % pip install pycodestyle
(env) % pycodestyle sample.py
sample.py:1:11: E401 multiple imports on one line

内包表記

「リストの各要素に処理をして、新しいリストを作る」処理を1行で書けるのがリスト内包表記です。

In
scores = [50, 72, 88]

# for文で書いた場合
bonus = []
for s in scores:
    bonus.append(s + 10)
print(bonus)

# リスト内包表記で書いた場合（結果は同じ）
bonus = [s + 10 for s in scores]
print(bonus)
Out 
[60, 82, 98]
[60, 82, 98]

書き方は [ 作る値の式 for 変数 in 取り出し元 ] です。for文の append の中身を先頭に持ってくる、と考えると覚えやすいでしょう。

  • 後ろに if 条件 を付けると、条件に合う要素だけを残せます。
  • [ ] で囲むとリスト、{ } で囲むと集合（set）、{キー: 値 for …} と書くと辞書になります。集合は順序を持たず、重複も消えます。
In
words = ["data", "AI", "python", "ml", "data"]
print([w.upper() for w in words if len(w) > 2])   # 3文字以上だけ大文字に
print({len(w) for w in words})                     # 集合内包表記（重複なし）
print({w: len(w) for w in words})                  # 辞書内包表記
Out 
['DATA', 'PYTHON', 'DATA']
{2, 4, 6}
{'data': 4, 'AI': 2, 'python': 6, 'ml': 2}

2.2.3標準ライブラリ

正規表現（re）

「こういう形の文字列」というパターンで検索・置換する仕組みを正規表現と呼びます。標準ライブラリの re モジュールを使います。

記号意味例
.任意の1文字a.c は abc、a1c に一致
?直前の文字が0回か1回colou?r は color、colour に一致
*直前の文字が0回以上ab* は a、ab、abb…
+直前の文字が1回以上ab+ は ab、abb…
[abc]カッコ内のどれか1文字gr[ae]y は gray、grey
[a-z]範囲内の1文字小文字1文字
(A|B)AまたはB（グループ）(cat|dog)s は cats、dogs
^ / $先頭 / 末尾^py は py で始まる
\d数字1文字\d+ は 2026

パターンは r'...'（raw文字列）で書きます。\ がPythonのエスケープとして解釈されず、そのまま re に渡ります。

In
import re

prog = re.compile(r"\d+")            # パターンを準備（何度も使うときに便利）
m = prog.search("abc123def45")       # 最初に一致した部分を探す
print(m)                             # Matchオブジェクト
print(m[0], m.group())               # 一致した文字列
print(prog.match("abc123"))          # match は先頭から一致するかを調べる
print(prog.findall("abc123def45"))   # 一致した部分をすべてリストで
print(re.sub(r"\d+", "#", "a1b22c")) # 一致した部分を置換
Out 
<re.Match object; span=(3, 6), match='123'>
123 123
None
['123', '45']
a#b#c
  • search は、文字列のどこかに一致する部分があれば Match オブジェクトを返します。なければ None を返します。
  • match は、文字列の先頭から一致するかどうかを調べます。
  • Match オブジェクトの [0] または group() で、一致した文字列全体を取り出せます。
  • findall は一致したすべての部分をリストで返し、sub は一致した部分を置換します。
  • re.IGNORECASE を指定すると、大文字と小文字を区別しません。

複数の記号を組み合わせたパターンは、左から部品に分けて読みます。

部品意味
colocolo（そのまま）
u?u があってもなくてもよい
rr（必須）
(s|ed|ful)?s / ed / ful のどれか。なくてもよい
In
import re

prog = re.compile(r"colou?r(s|ed|ful)?", re.IGNORECASE)
for s in ["color", "Colours", "a COLORFUL day", "coloured pen", "colr"]:
    ret = prog.search(s)
    if ret is None:
        print(s, "→ 一致なし")
    else:
        print(s, "→", ret[0])
Out 
color → color
Colours → Colours
a COLORFUL day → COLORFUL
coloured pen → coloured
colr → 一致なし

colr は、必須の o が足りないのでどこにも一致せず、None になります。a COLORFUL day は、search が途中の位置からでも探すことと、IGNORECASE で大文字も一致することから、COLORFUL の部分が見つかります。

ログ出力（logging）

logging は、ログ（プログラムの途中経過や異常の記録）を出力するモジュールです。ログレベルを指定でき、出力先のファイルや出力形式（フォーマット）も指定できます。バッチ処理の途中経過を残す用途などに使います。

ログレベル（重要度の低い順）用途
DEBUG開発中の詳しい情報
INFO想定どおりに動いていることの記録
WARNING想定外のことが起きた（何も設定しないときの既定レベル）
ERROR一部の処理ができなかった
CRITICALプログラムを続けられない重大な問題
In
import logging

logging.basicConfig(level=logging.INFO, format="%(levelname)s:%(message)s")
logging.debug("詳細")        # INFO より低いので出力されない
logging.info("処理を開始")
logging.warning("残りわずか")
Out 
INFO:処理を開始
WARNING:残りわずか

指定したレベル以上のログだけが出力されます。basicConfig(filename="app.log") とすると、ログをファイルに書き出せます。

オブジェクトの保存（pickle）

pickle は、Pythonのオブジェクトをシリアライズ（直列化）してファイルなどに保存し、あとで元のオブジェクトに戻すためのモジュールです。リストや辞書、学習済みのモデルなどの保存に使います。

In
import pickle

data = {"name": "iris", "scores": [0.9, 0.95]}
with open("data.pkl", "wb") as f:   # バイナリ書き込み "wb"
    pickle.dump(data, f)
with open("data.pkl", "rb") as f:   # バイナリ読み込み "rb"
    restored = pickle.load(f)
print(restored)
Out 
{'name': 'iris', 'scores': [0.9, 0.95]}

保存は dump、読み込みは load で、ファイルはバイナリモードで開きます。

パスの操作（pathlib）

pathlib は、ファイルのパスをオブジェクトとして扱うモジュールです。/ 演算子でパスをつなげられます。glob メソッドでは、ワイルドカード * を使ってファイルを検索できます。

In
from pathlib import Path

work = Path("sample_dir")
work.mkdir(exist_ok=True)
(work / "a.txt").write_text("A")
(work / "b.txt").write_text("B")
(work / "c.csv").write_text("C")
print(sorted(p.name for p in work.glob("*.txt")))
print((work / "a.txt").exists(), (work / "a.txt").suffix)
Out 
['a.txt', 'b.txt']
True .txt
日付と時刻（datetime）

datetime は日付と時刻を扱うモジュールです。日付どうしを引き算すると timedelta（期間）になり、経過日数を計算できます。

In
from datetime import date, datetime, timedelta

d1 = date(2026, 4, 1)
d2 = date(2026, 10, 29)
print((d2 - d1).days)                    # 経過日数
print(d1 + timedelta(days=30))           # 30日後
dt = datetime.strptime("2026/10/29 15:30", "%Y/%m/%d %H:%M")  # 文字列→日時
print(dt.strftime("%Y年%m月%d日"))        # 日時→文字列
Out 
211
2026-05-01
2026年10月29日

今日の日付は date.today()、現在の日時は datetime.now() で取得できます。

POINT
  • re：search はどこかに一致すれば Match、なければ None。? は0回か1回、| はどちらか、[ ] はどれか1文字。
  • logging：低い順に DEBUG < INFO < WARNING < ERROR < CRITICAL。既定は WARNING。
  • pickle：オブジェクトのシリアライズ（dump / load、バイナリモード）。
  • pathlib：パスのオブジェクト。glob でワイルドカード検索。datetime：日付の差は timedelta。
