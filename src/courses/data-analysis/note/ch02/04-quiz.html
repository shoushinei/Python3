確認問題

Q1venvに関する記述として正しいものはどれか。

  1. 仮想環境ごとに、異なるバージョンのPythonを自由に選べる。
  2. プロジェクトごとにインストールするパッケージを分けられる。
  3. Anaconda社が開発したサードパーティ製のツールである。
  4. macOS専用で、Windowsでは使えない。
venvは標準ライブラリで、OSを問わず使えます。仮想環境のPythonは、作成に使ったPythonと同じバージョンになります。

Q2次のコードの出力はどれか。

nums = [4, 7, 10, 13]
print([n // 2 for n in nums if n % 2 == 0])
  1. [3, 6]
  2. {2, 5}
  3. [2, 5]
  4. [2, 3, 5, 6]
if で偶数（4と10）だけを残し、それぞれを2で割った商（//）にします。[ ] で囲んでいるのでリストになります。

Q3re.compile(r"gr[ae]y(ish)?") のパターンで search したとき、None が返る文字列はどれか。

  1. "groy"
  2. "greyish"
  3. "a gray cat"
  4. "grey"
[ae] は a か e のどちらか1文字なので、o の groy には一致しません。(ish)? はなくてもよく、search は途中からでも一致を探します。

Q4loggingで basicConfig(level=logging.ERROR) と設定したとき、出力されるものの組み合わせはどれか。

  1. DEBUG と INFO
  2. INFO と WARNING と ERROR
  3. WARNING と ERROR
  4. ERROR と CRITICAL
指定したレベル以上が出力されます。ERROR以上は ERROR と CRITICAL です。
