3.2線形代数 2問

データをまとめて扱うための道具である、ベクトルと行列の演算を説明します。

3.2.1ベクトルとその演算

数を一列に並べたものをベクトルと呼びます。並んでいる数の個数を、ベクトルの次元（サイズ）と呼びます。データ分析では「1件のデータの特徴量を並べたもの」がベクトルです。

和・差・スカラー倍
  • 足し算・引き算は同じ位置の要素同士で行うので、次元が同じベクトル同士でしか計算できません。結果もベクトルです。
  • スカラー倍は、すべての要素に同じ数を掛けます。
(1, 2) + (3, 5) = (4, 7)　　3 × (1, 2) = (3, 6)
内積

同じ位置の要素同士を掛けて、すべて足した値を内積と呼びます。結果はベクトルではなく、1つの数（スカラー）になります。

(1, 2) · (3, 5) = 1×3 + 2×5 = 13
ノルム（大きさ・距離）
ユークリッド距離（L2ノルム）各要素を2乗して足し、平方根をとる。いわゆる直線距離。
‖(5, 12)‖ = √(25 + 144) = √169 = 13
マンハッタン距離（L1ノルム）各要素の絶対値を足す。碁盤の目の道を進むイメージ。
|5| + |12| = 17

原点からの距離（ベクトルの大きさ）をノルムと呼びます。ユークリッド距離とマンハッタン距離は、どちらもノルムの一種です。2つのベクトル間の距離は、差のベクトルのノルムで求めます。

In
import numpy as np

a = np.array([1, 2])
b = np.array([3, 5])
print(a + b, a - b, 3 * a)        # 和・差・スカラー倍
print(a @ b)                      # 内積（np.dot(a, b) でも同じ）
v = np.array([5, 12])
print(np.linalg.norm(v))          # ユークリッド距離（L2ノルム）
print(np.linalg.norm(v, ord=1))   # マンハッタン距離（L1ノルム）
c = np.array([1, 2, 3])
try:
    print(a + c)
except ValueError as e:
    print("次元が違うので計算できない")
Out

13
13.0
17.0

3.2.2行列とその演算

数を縦と横に並べたものを行列と呼びます。横の並びを行、縦の並びを列と呼び、行が m 個、列が n 個の行列を m×n 行列と呼びます。表形式のデータ（行＝データ1件、列＝特徴量）は、そのまま行列として扱えます。

特別な行列
  • 正方行列：行の数と列の数が同じ行列。
  • 単位行列：正方行列のうち、対角成分（左上から右下）がすべて1で、それ以外がすべて0の行列。記号は I または E。数の「1」のように、掛けても相手を変えません。
  • 転置：行と列を入れ替えたもの（AT）。
行列の計算ルール
計算計算できる条件結果の形
和・差行数と列数が両方同じ同じ形の行列
行列 × ベクトル行列の列数 ＝ ベクトルのサイズ行列の行数と同じサイズのベクトル
行列 × 行列左の列数 ＝ 右の行数(m×s) と (s×n) の積は m×n

行列の積は、左の行列の「行」と右の行列の「列」で内積をとって並べたものです。

2103 × 45 = 2×4 + 1×50×4 + 3×5 = 1315
注意

数の掛け算と違って、行列の積は順番を入れ替えると結果が変わることがあります（AB ≠ BA）。片方の順番では計算できないこともあります。

In
import numpy as np

A = np.array([[2, 1], [0, 3]])
B = np.array([[1, 1], [1, 0]])
v = np.array([4, 5])
print(A @ v)          # 行列×ベクトル → 行数(2)と同じサイズ
print(A @ B)
print(B @ A)          # 順番を変えると結果が違う
print(np.eye(2))      # 2×2の単位行列
print(A @ np.eye(2))  # 単位行列を掛けても変わらない
print(A.T)            # 転置

行列の積と次元削減

(m×s) の行列に (s×n) の行列を掛けると (m×n) の行列になります。データ分析では、m 件のデータが s 個の特徴量を持つ行列（m×s）に、s×n の行列を掛けることで、特徴量を n 個に変換できます。n を s より小さくすれば、説明変数の次元数を削減できます。これが第4章の次元削減（主成分分析）の土台になる考え方です。

In
import numpy as np

X = np.ones((100, 5))      # 100件 × 特徴量5個
W = np.ones((5, 2))        # 5 → 2 に変換する行列
print((X @ W).shape)       # 100件 × 特徴量2個
Out 
(100, 2)
