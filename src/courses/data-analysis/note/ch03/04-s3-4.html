3.4確率と統計 2問

世の中にあふれるデータをまとめるために、また手元のデータから未来の不確実さを少しでも減らすために、確率と統計の理論が役立ちます。

3.4.1統計の基礎

代表値

データ全体の特徴を1つの値で表したものを代表値と呼びます。次の7人のテストの点数で考えます。

45, 60, 60, 70, 75, 80, 100
代表値意味上のデータの場合
最小値 / 最大値最も小さい値 / 最も大きい値45 / 100
平均値（mean）合計 ÷ 個数（算術平均）490 ÷ 7 = 70
中央値（median）小さい順に並べて真ん中の値。個数が偶数なら、真ん中の2つの平均70
最頻値（mode）最も多く出てくる値60

例えば、5段階評価のアンケートで最も回答者が多かった評価は最頻値です。平均値は外れ値（極端な値）の影響を受けやすく、中央値は受けにくいという違いもあります。

分位数

データを小さい順に並べて、全体を区切る位置の値を分位数（パーセンタイル、クォンタイル）と呼びます。最もよく使われるのは4等分する四分位数です。1/4 の位置が第1四分位数（25パーセンタイル）、真ん中が第2四分位数（＝中央値）、3/4 の位置が第3四分位数（75パーセンタイル）です。

分散と標準偏差
  • 偏差：各データから平均値を引いた値。偏差をそのまま足すと必ず0になります。
  • 分散：偏差を2乗して平均した値。データの散らばりの大きさを表します。
  • 標準偏差：分散の平方根。元のデータと単位がそろうので、散らばりを直感的に表せます。
分散 σ² = 1n Σi=1n (xi − μ)²　　標準偏差 σ = √σ²
In
import numpy as np

x = np.array([45, 60, 60, 70, 75, 80, 100])
print("平均", np.mean(x), "中央値", np.median(x))
print("偏差", x - x.mean(), "合計", (x - x.mean()).sum())
print("分散", round(np.var(x), 2), "標準偏差", round(np.std(x), 2))
print("四分位数", np.percentile(x, [25, 50, 75]))
Out 
平均 70.0 中央値 70.0
偏差 [-25. -10. -10.   0.   5.  10.  30.] 合計 0.0
分散 264.29 標準偏差 16.26
四分位数 [60.  70.  77.5]

3.4.2データの可視化方法

  • ヒストグラム：値の範囲（階級）ごとのデータの個数（度数）を棒で表し、分布の形を見ます。
  • 箱ひげ図：最小値・第1四分位数・中央値・第3四分位数・最大値を箱とひげで表し、散らばりや外れ値を見ます。
In
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(0)
x = np.random.normal(60, 12, 300)      # 平均60、標準偏差12の点数データ
fig, axes = plt.subplots(1, 2, figsize=(8, 3))
axes[0].hist(x, bins=15)
axes[0].set_title("histogram")
axes[1].boxplot(x, vert=False)
axes[1].set_title("box plot")
plt.show()
Out

3.4.3データとその関係性

  • 散布図：2つの変数を x 軸と y 軸にとって点を打ち、関係を見ます。
  • 共分散：2つの変数の偏差の積の平均です。正なら同じ向きに、負なら逆向きに動く傾向があります。
  • 相関係数：共分散を、2つの標準偏差の積で割ったものです。−1〜1 の値をとります。1に近いほど「一方が増えると他方も増える」（正の相関）、−1に近いほど「一方が増えると他方は減る」（負の相関）関係です。0に近いと直線的な関係はほとんどありません。
In
import numpy as np

study = np.array([1, 2, 3, 4, 5])        # 勉強時間
score = np.array([52, 58, 65, 70, 80])   # 点数
games = np.array([5, 4, 4, 2, 1])        # ゲーム時間
print(np.corrcoef(study, score)[0, 1].round(3))   # 正の相関
print(np.corrcoef(study, games)[0, 1].round(3))   # 負の相関
Out 
0.994
-0.962

3.4.4確率

  • サイコロを振るような行為を試行、「偶数の目が出る」のような結果のまとまりを事象と呼びます。
  • 事象 A の確率 P(A) は、起こりうるすべての場合のうち A が起こる割合です。
  • 条件付き確率 P(A|B)：「Bが起きた」と分かっているときに、Aが起きる確率です。

例：6面体のサイコロで「偶数の目が出た」と教えられたとき、それが6である確率は 1/3 です。候補が2・4・6の3つに絞られるからです。何も知らないときの確率 1/6 とは違う値になります。

条件付き確率はベイズの定理の基本になっています。

P(A|B) = P(B|A) P(A)P(B)

3.4.5確率分布

  • 確率変数：サイコロの出目のように、確率的に値が決まる変数です。
  • 確率分布：確率変数の各値に、どれだけの確率が割り当てられているかを表したものです。
  • 期待値：「値 × その値が出る確率」の合計で、平均的に期待できる値を表します。
E[X] = Σ xi P(xi)

n 面体のサイコロ（1〜n の目が同じ確率）の期待値は (1 + 2 + … + n) / n = (n + 1) / 2 です。6面体なら 3.5、8面体なら 4.5 です。

In
import numpy as np

face = np.arange(1, 9)                 # 8面体サイコロの目
print("期待値", np.sum(face * (1 / 8)))
np.random.seed(1)
rolls = np.random.randint(1, 9, 100000)   # 10万回振ってみる
print("実際の平均", rolls.mean().round(2))
Out 
期待値 4.5
実際の平均 4.49

3.4.6確率と関数

確率変数を引数にとって、その確率（または確率の密度）を返す関数には2種類あります。

確率質量関数確率変数が離散的（とびとびの値）な場合。各値の確率をそのまま返す。例：サイコロの目、コインの表の回数。
確率密度関数確率変数が連続的な場合。グラフの面積（積分）が確率になる。例：身長、測定誤差。

確率質量関数と確率密度関数は、確率変数が離散か連続かで使い分けます。

代表的な連続の確率分布が正規分布です。平均 μ を中心に左右対称な釣り鐘型で、形は平均 μ と標準偏差 σ で決まります。正規分布は確率密度関数で表されます。平均0・標準偏差1の正規分布を標準正規分布と呼びます。離散の代表例には、コイン投げで表が出る回数のような二項分布があります。

In
import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(-4, 4, 801)
pdf = np.exp(-x ** 2 / 2) / np.sqrt(2 * np.pi)   # 標準正規分布の確率密度関数
fig, ax = plt.subplots(figsize=(5, 3))
ax.plot(x, pdf)
ax.fill_between(x, pdf, where=(x >= -1) & (x <= 1), alpha=0.3)
ax.set_title("standard normal distribution")
plt.show()
mask = (x >= -1) & (x <= 1)
dx = x[1] - x[0]
print("−1〜1 の面積（約）", round(float(np.sum(pdf[mask]) * dx), 2))
Out 
−1〜1 の面積（約） 0.69

標準正規分布では、平均±1標準偏差の範囲に、全体の約68%が入ります。

3.4.7確率と情報量

「めったに起きないことが起きた」と知るほど、得られる情報は大きいと考えます。確率 p の事象が起きたと知ったときの情報量は −log p で表します。情報量の期待値をエントロピーと呼び、データの「乱雑さ（不純さ）」を表します。第4章の決定木では、データの混ざり具合（不純度）を測るのにエントロピーなどを使います。

In
import numpy as np

def entropy(ps):
    ps = np.array(ps)
    return -np.sum(ps * np.log2(ps))

print(entropy([0.5, 0.5]))     # 半々に混ざっている → 大きい
print(entropy([0.9, 0.1]).round(3))   # ほぼ一方に偏っている → 小さい
Out 
1.0
0.469
