3.1.1数式と記号

Σ（シグマ）と Π（パイ）
Σ：足し算の繰り返し（総和）ギリシャ文字シグマの大文字
Σi=1n xi = x1 + x2 + … + xn
Π：掛け算の繰り返し（総乗）ギリシャ文字パイの大文字
Πi=1n xi = x1 × x2 × … × xn

Σは「for文で足していく」処理、Πは「for文で掛けていく」処理です。記号の下の i=1 が開始、上の n が終了を表します。

In
import numpy as np

x = np.array([2, 3, 4])
print(np.sum(x))    # Σ  2 + 3 + 4
print(np.prod(x))   # Π  2 × 3 × 4
Out 
9
24

3.1.2数学記号

  • 添字：xi は「i番目のx」。プログラムの x[i] にあたります。
  • 円周率 π：直径1の円の円周の長さ。π = 3.14159…
  • ネイピア数 e：自然対数の底。e = 2.71828…
  • 階乗 n!：1からnまでの整数を掛けたもの。4! = 4×3×2×1 = 24。1! = 1、0! = 1 と決まっています。
  • 絶対値 |x|：0からの距離。|−3| = 3
  • 平方根 √x：2乗すると x になる正の数。√49 = 7
In
import numpy as np
import math

print(np.pi, np.e)
print(math.factorial(4), math.factorial(0))
print(np.abs(-3), np.sqrt(49))
Out 
3.141592653589793 2.718281828459045
24 1
3 7.0

3.1.3関数の基本

1次関数・2次関数

入力 x を受け取って、値 y を1つ返す決まりが関数 y = f(x) です。y = 2x + 1 は直線になる1次関数、y = x² は放物線になる2次関数です。

指数関数と対数関数
  • 指数関数：入力が別の数の肩に乗る関数。y = ax（a を底と呼ぶ）。底がネイピア数のときは ex、または exp(x) と書きます。
  • 対数関数：入力が底の何乗にあたるかを返す関数で、指数関数の逆です。y = loga x。例：log2 8 = 3（2の3乗が8だから）。
  • 底が e の対数を自然対数と呼び、log x や ln x と書きます。底が10の対数は常用対数です。
  • どんな底でも log 1 = 0 です（a0 = 1 だから）。
In
import numpy as np

print(np.exp(2))          # e の2乗
print(np.log(np.e ** 3))  # 自然対数 → 3
print(np.log2(8))         # 底2の対数
print(np.log10(0.01))     # 常用対数 → -2
print(np.log(1))          # log 1 = 0
Out

シグモイド関数

指数関数を応用した関数です。どんな入力も0〜1の間の値に変換するので、確率のように扱えます。深層学習の基本となるニューラルネットワークや、ロジスティック回帰で使われます。

σ(x) = 11 + e−x
In
import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(-6, 6, 100)
y = 1 / (1 + np.exp(-x))
fig, ax = plt.subplots(figsize=(5, 3))
ax.plot(x, y)
ax.set_title("sigmoid")
ax.grid(True)
plt.show()
Out

このように描ける関数をシグモイド関数と呼びます。x = 0 のとき 0.5 で、x が大きくなると1に、小さくなると0に近づきます。

三角関数
関数読み日本語名代表的な値
sinサイン正弦sin 0° = 0、sin 90° = 1
cosコサイン余弦cos 0° = 1、cos 90° = 0
tanタンジェント正接tan 0° = 0、tan 45° = 1

これらの三角関数のうち、sin のグラフを正弦曲線、cos のグラフを余弦曲線と呼びます。NumPy の np.sin などは、角度をラジアンで受け取ります（180° = π ラジアン）。

In
import numpy as np

print(np.sin(np.pi / 2))          # sin 90°
print(np.cos(np.pi))              # cos 180°
print(np.tan(np.radians(60)))     # tan 60° = √3
Out 
1.0
