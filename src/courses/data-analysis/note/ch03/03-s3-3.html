3.3基礎解析 1問

微分と積分の意味、簡単な計算、偏微分を説明します。機械学習の「学習」の仕組みを理解する土台です。

3.3.1微分と積分の意味

微分 ＝ 傾き関数のある点での傾き（変化の割合）を求める。
積分 ＝ 面積グラフと x 軸に囲まれた部分の面積を求める。微分の逆の計算。

微分した関数を f′(x) や df/dx と書きます。積分には、範囲を決めない不定積分と、範囲を決めた定積分があります。

3.3.2簡単な関数の微分と積分

微分の公式：(xn)′ = n xn−1　（定数を微分すると0）
積分の公式：∫ xn dx = 1n + 1 xn+1 + C　（C は積分定数）
  • 微分の例：f(x) = 4x³ + 5x のとき f′(x) = 12x² + 5
  • 積分の例：∫ 9x² dx = 9 × x³/3 + C = 3x³ + C
  • 定積分の例：∫02 3x² dx = [x³]02 = 8 − 0 = 8
POINT：検算のコツ

積分した結果を微分すると、元の関数に戻ります。3x³ を微分すると 9x² に戻るので、上の積分は正しいと確かめられます。係数の割り算（÷(n+1)）を忘れていないかを、この方法で確認しましょう。

3.3.3微分と関数の値

グラフが谷の底や山の頂上になる点では、傾き（微分の値）が0になります。機械学習では、予測の誤差を関数で表し、誤差が最小になる点を探します。そのため、微分して傾きが0になる点を探すことが、学習の基本的な考え方になります。

例：f(x) = x² − 6x + 10 を微分すると f′(x) = 2x − 6 です。これが0になる x = 3 で、f(x) は最小値 1 をとります。

3.3.4偏微分

変数が2つ以上ある関数（多変数関数）で、1つの変数だけに注目し、ほかの変数を定数とみなして微分するのが偏微分です。記号は ∂（ラウンド）を使い、どの変数で微分したかを明示します。

f(x, y) = 2x² + xy のとき　∂f/∂x = 4x + y　　∂f/∂y = x
