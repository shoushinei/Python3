確認問題

Q1ベクトル (6, 8) の原点からのユークリッド距離とマンハッタン距離の組み合わせはどれか。

  1. ユークリッド 14、マンハッタン 10
  2. ユークリッド 100、マンハッタン 14
  3. ユークリッド 10、マンハッタン 14
  4. ユークリッド 10、マンハッタン 48
ユークリッド距離は √(36+64) = 10、マンハッタン距離は 6+8 = 14 です。

Q23×2 の行列 A と 2×4 の行列 B がある。正しいものはどれか。

  1. AB は計算できず、BA は 4×3 の行列になる。
  2. AB は 3×4 の行列になり、BA は計算できない。
  3. AB も BA も 3×4 の行列になる。
  4. A + B は 3×4 の行列になる。
AB は左の列数2と右の行数2が一致するので、3×4 になります。BA は左の列数4と右の行数3が合わないので計算できません。和は形が同じでないと計算できません。

Q3f(x) = 3x² + 4x を微分したものはどれか。

  1. 6x + 4
  2. x³ + 2x²
  3. 6x
  4. 3x + 4
(x²)′ = 2x、(x)′ = 1 なので 3×2x + 4×1 = 6x + 4 です。B は積分（不定積分）の結果です。

Q4データ 2, 4, 4, 6 の分散はどれか。

  1. 0
  2. 4
  3. √2
  4. 2
平均は4、偏差は −2, 0, 0, 2 です。2乗すると 4, 0, 0, 4 で合計8、これを個数4で割ると分散は2です。標準偏差は √2 です。

Q5確率分布に関する記述として正しいものはどれか。

  1. サイコロの目のような離散的な確率変数には、確率密度関数を使う。
  2. 標準正規分布は、平均1・標準偏差0の正規分布である。
  3. 正規分布は平均を中心に左右対称な分布で、確率密度関数で表される。
  4. 期待値は、確率変数がとりうる値のうち最も出やすい値である。
離散的な確率変数には確率質量関数を使います。標準正規分布は平均0・標準偏差1です。期待値は「値×確率」の合計です。

Q6単位行列の説明として正しいものはどれか。

  1. すべての要素が1の行列
  2. 対角成分がすべて1で、それ以外がすべて0の正方行列
  3. 対角成分がすべて0で、それ以外がすべて1の正方行列
  4. 行数が1の行列
単位行列は、対角成分が1、残りが0の正方行列です。掛けても相手の行列を変えません。
