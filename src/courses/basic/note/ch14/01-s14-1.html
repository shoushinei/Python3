14.1タブ補完とヒストリ編集

  • インタープリタの起動時に、変数名とモジュール名の補完が自動で有効になります。Tab キーを押すと補完機能が呼ばれます。
  • 補完の対象は、Pythonの文の名前、現在のローカル変数、使えるモジュール名です。
  • string.a のようにドットを含む式では、最後の . までの式を評価し、その結果のオブジェクトの属性から補完候補を出します。このとき、__getattr__() メソッドを持つオブジェクトでは、アプリケーションで定義したコードが実行されることがあります。
  • 入力の履歴は、ユーザーのディレクトリの .python_history というファイルに保存されます。次に対話モードを起動したときにも、前回の履歴を呼び出せます。
>>> import string
>>> string.a      ← ここで Tab キーを押すと
string.ascii_letters    string.ascii_lowercase    string.ascii_uppercase

これらの機能は、GNU readline ライブラリを使って実現されています（2.1 で触れた行編集の機能）。
