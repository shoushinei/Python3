確認問題

Q1対話モードの入力履歴が保存されるファイルはどれか。

  1. .pythonrc
  2. .python_history
  3. history.py
  4. .bash_history
履歴はユーザーディレクトリの .python_history に保存されます。

Q2対話環境に関する説明として正しいものはどれか。

  1. タブ補完を使うには、起動後に毎回設定を有効にする必要がある。
  2. タブ補完の対象はモジュール名だけである。
  3. 標準のインタープリタより高機能な対話環境として IPython がある。
  4. 入力履歴はインタープリタを終了すると消える。
補完は起動時に自動で有効になり、文の名前・ローカル変数・モジュール名が対象です。履歴は .python_history に保存されます。
