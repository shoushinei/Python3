12.3pipによるパッケージ管理

pip というプログラムで、パッケージのインストール・アップグレード・削除ができます。pip は既定で PyPI（Python Package Index）からパッケージをインストールします。PyPI はWebブラウザで検索することもできます。

コマンド働き
python -m pip install novasパッケージの最新版をインストールする
python -m pip install requests==2.6.0== でバージョンを指定してインストールする。同じコマンドをもう一度実行しても、すでにインストール済みなので何もしない
python -m pip install --upgrade requestsパッケージを最新版にアップグレードする
python -m pip uninstall requestsパッケージを削除する（パッケージ名は複数指定できる）
python -m pip show requests特定のパッケージの情報（名前・バージョン・概要・場所・依存関係など）を表示する
python -m pip list仮想環境にインストールされているすべてのパッケージを表示する
python -m pip freezelist と同じような一覧を、pip install が読める形式（名前==バージョン）で出力する
python -m pip install -r requirements.txtファイルに書かれたパッケージをまとめてインストールする
(tutorial-env) % python -m pip install requests==2.6.0
Collecting requests==2.6.0
  Using cached requests-2.6.0-py2.py3-none-any.whl
Installing collected packages: requests
Successfully installed requests-2.6.0
(tutorial-env) % python -m pip install requests==2.6.0
Requirement already satisfied: requests==2.6.0 in ...
requirements.txt

pip freeze の出力を requirements.txt というファイルに保存しておくのが一般的な慣習です。このファイルをバージョン管理に入れてアプリケーションと一緒に配布すれば、利用者は install -r で必要なパッケージをまとめてインストールできます。

(tutorial-env) % python -m pip freeze > requirements.txt
(tutorial-env) % cat requirements.txt
novas==3.1.1.3
numpy==1.9.2
requests==2.7.0
(tutorial-env) % python -m pip install -r requirements.txt
注意：list と freeze と show

show は1つのパッケージの詳しい情報、list は全パッケージの一覧（人が見る形式）、freeze は全パッケージの一覧（install -r で読める形式）です。アップグレードは install --upgrade（-U）で、pip upgrade というサブコマンドはありません。

POINT
  • 仮想環境 ＝ 特定バージョンのPython＋追加パッケージを含む自己完結したディレクトリツリー。アプリごとの要求の衝突を解決する。
  • python -m venv 名前。venv は実行したPythonのバージョンを使う。置き場所は .venv が一般的。
  • 有効化：Windows は 名前\Scripts\activate、Unix は source 名前/bin/activate。無効化は deactivate。
  • pip は PyPI から。install（==で版指定）、install --upgrade、uninstall、show（1つの詳細）、list（一覧）、freeze（install用の形式）、install -r requirements.txt。
