12.2仮想環境の生成

仮想環境の作成と管理には、venv モジュールを使います。venv は、そのコマンドを実行したPythonのバージョン（--version で表示されるもの）をインストールします。

% python -m venv tutorial-env       # tutorial-env という仮想環境を作る
  • tutorial-env ディレクトリがなければ作り、その中にPythonインタープリタのコピーと、さまざまな補助ファイルを入れたディレクトリを作ります。
  • 仮想環境の置き場所としては、.venv というディレクトリ名がよく使われます。シェルでは隠しディレクトリになって邪魔にならず、環境変数の定義ファイル .env とも区別できるからです。
有効化と無効化
OS有効化のコマンド
Windowstutorial-env\Scripts\activate
Unix・macOS（bash）source tutorial-env/bin/activate
csh・fish シェルactivate.csh・activate.fish を使う
% source ~/envs/tutorial-env/bin/activate
(tutorial-env) % python               # 仮想環境のPythonが起動する
(tutorial-env) % deactivate           # 無効化
  • 有効化すると、シェルのプロンプトに仮想環境の名前が表示されます。
  • 環境変数も変更され、python と打つと仮想環境の（特定のバージョンの）Pythonが起動するようになります。
  • 無効化するには deactivate と入力します。
