確認問題

Q1インストール済みのパッケージを、pip install -r で読み込める形式で出力するコマンドはどれか。

  1. python -m pip list
  2. python -m pip show
  3. python -m pip freeze
  4. python -m pip export
freeze は「名前==バージョン」の形式で出力します。list は人が見るための一覧、show は1つのパッケージの詳細です。

Q2インストール済みのパッケージ requests を最新版に更新するコマンドはどれか。

  1. python -m pip install --upgrade requests
  2. python -m pip upgrade requests
  3. python -m pip update requests
  4. python -m pip install requests==latest
アップグレードは install --upgrade（-U）です。upgrade や update というサブコマンドはありません。

Q3仮想環境に関する説明として誤っているものはどれか。

  1. 特定のバージョンのPythonと追加パッケージを含む、自己完結したディレクトリツリーである。
  2. Windowsでは tutorial-env\Scripts\activate で有効化する。
  3. 有効化すると、シェルのプロンプトに仮想環境の名前が表示される。
  4. venv は、コマンドを実行したPythonとは別に、最新バージョンのPythonを自動でダウンロードしてインストールする。
venv は、そのコマンドを実行したPythonのバージョンを使います。

Q4パッケージ requests のバージョンや依存関係などの詳しい情報を表示するコマンドはどれか。

  1. python -m pip list requests
  2. python -m pip show requests
  3. python -m pip info requests
  4. python -m pip freeze requests
1つのパッケージの詳細を表示するのは pip show です。
