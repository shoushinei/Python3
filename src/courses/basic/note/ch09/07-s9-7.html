9.7残り物あれこれ

名前付きのデータをまとめるだけの、Pascal の record や C の struct のような型が欲しいときは、dataclasses を使うのが慣用的です。

In
from dataclasses import dataclass

@dataclass
class Employee:
    name: str
    dept: str
    salary: int

john = Employee('john', 'computer lab', 1000)
print(john.dept, john.salary)
print(john)
Out 
computer lab 1000
Employee(name='john', dept='computer lab', salary=1000)

空のクラスを作って、後から属性を代入する方法もあります。また、インスタンスのメソッドオブジェクトにも属性があり、m.__self__ はメソッドが属するインスタンス、m.__func__ はメソッドに対応する関数オブジェクトです。

In
class MyClass:
    def f(self):
        return 'hello'
x = MyClass()
m = x.f
print(m.__self__ is x, m.__func__ is MyClass.f)
Out 
True True
