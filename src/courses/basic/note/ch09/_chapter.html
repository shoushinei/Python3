CHAPTER9

クラス

名前空間とスコープ（global / nonlocal）、クラスオブジェクト・インスタンス・メソッドオブジェクト、クラス変数とインスタンス変数、継承、プライベート変数、イテレータ、ジェネレータを学びます。

出題 2問（5.0%）
この章の目標
  • global / nonlocal を使ったスコープの例の出力を答えられる
  • x.f() と MyClass.f(x) の関係、クラス変数の共有の落とし穴を説明できる
  • 名前マングリング、多重継承の探索順、isinstance / issubclass を判定できる
  • イテレータ（iter・next・StopIteration）、ジェネレータ（yield）、ジェネレータ式を読める
