9.3はじめてのクラス

9.3.1クラス定義の構文

class クラス名: の後ろに文を書きます。関数定義と同じく、クラス定義も実行されてはじめて効果を持ちます（if 文の中に書くこともできます）。クラス定義に入ると新しい名前空間が作られてローカルスコープとして使われ、正常に終わるとクラスオブジェクトが作られます。

9.3.2クラスオブジェクト

クラスオブジェクトでできることは、属性の参照とインスタンス化の2つです。

In
class MyClass:
    """A simple example class"""
    i = 12345

    def f(self):
        return 'hello world'

print(MyClass.i)          # 属性の参照（整数）
print(MyClass.f)          # 属性の参照（関数オブジェクト）
print(MyClass.__doc__)    # docstring も属性
x = MyClass()             # インスタンス化（関数のように呼ぶ）
print(x.f())
Out 
12345
<function MyClass.f at 0x7f14caeb5e40>
A simple example class
hello world

インスタンス化すると、特殊メソッド __init__() が自動的に呼ばれます。__init__ に引数を付けると、インスタンス化のときに渡した引数がそのまま渡されます。

In
class Complex:
    def __init__(self, realpart, imagpart):
        self.r = realpart
        self.i = imagpart

x = Complex(3.0, -4.5)
print(x.r, x.i)
Out 
3.0 -4.5

9.3.3インスタンスオブジェクト

インスタンスオブジェクトでできるのは属性の参照だけです。属性には、データ属性とメソッドの2種類があります。

  • データ属性（インスタンス変数）は宣言する必要がなく、最初に代入したときに作られます。
  • メソッドは、オブジェクトに属する関数です。x.f はメソッドオブジェクト、MyClass.f は関数オブジェクトで、同じものではありません。
In
class MyClass:
    i = 12345
    def f(self):
        return 'hello world'

x = MyClass()
x.counter = 1                 # 宣言なしで、代入すれば作られる
while x.counter < 10:
    x.counter = x.counter * 2
print(x.counter)
del x.counter                 # 削除もできる
print(type(x.f).__name__, type(MyClass.f).__name__)
Out 
16
method function

9.3.4メソッドオブジェクト

In
class MyClass:
    def f(self):
        return 'hello world'

x = MyClass()
xf = x.f                      # メソッドオブジェクトを保存しておき
print(xf())                   # あとで呼べる
print(x.f() == MyClass.f(x))  # x.f() は MyClass.f(x) と同じ
Out 
hello world
True

メソッドの特別なところは、インスタンスオブジェクトが関数の第1引数として渡されることです。x.f() は MyClass.f(x) と同じです。n 個の引数でメソッドを呼ぶと、先頭にインスタンスを挿入した n+1 個の引数で関数を呼ぶことになります。

9.3.5クラス変数とインスタンス変数

クラス変数は、そのクラスの全インスタンスで共有される属性とメソッドです。インスタンス変数は、インスタンスごとに固有のデータです。

In
class Dog:
    kind = 'canine'           # クラス変数：全インスタンスで共有

    def __init__(self, name):
        self.name = name      # インスタンス変数：インスタンスごと

d = Dog('Fido')
e = Dog('Buddy')
print(d.kind, e.kind)
print(d.name, e.name)
Out 
canine canine
Fido Buddy
注意：ミュータブルなクラス変数は共有される

クラス変数にリストや辞書を使うと、全インスタンスで1つのリストを共有してしまい、思わぬ結果になります。

In
class Dog:
    tricks = []               # 間違い：全インスタンスで共有される

    def __init__(self, name):
        self.name = name

    def add_trick(self, trick):
        self.tricks.append(trick)

d = Dog('Fido')
e = Dog('Buddy')
d.add_trick('roll over')
e.add_trick('play dead')
print(d.tricks)               # Fido の芸に Buddy の芸まで入っている
Out 
['roll over', 'play dead']
In
class Dog:
    def __init__(self, name):
        self.name = name
        self.tricks = []      # 正しい：インスタンスごとに新しいリストを作る

    def add_trick(self, trick):
        self.tricks.append(trick)

d = Dog('Fido')
e = Dog('Buddy')
d.add_trick('roll over')
e.add_trick('play dead')
print(d.tricks, e.tricks)
Out 
['roll over'] ['play dead']
Javaと比べると

クラス変数は Javaの static フィールド、インスタンス変数は普通のフィールドにあたります。ただしPythonでは、インスタンス変数をクラスの中で宣言せず、__init__ の中で self.名前 = 値 と代入して作ります。
