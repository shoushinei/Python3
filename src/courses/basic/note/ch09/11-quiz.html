確認問題

Q1次のコードの出力はどれか。

x = "global"
def outer():
    x = "outer"
    def inner():
        nonlocal x
        x = "inner"
    inner()
    print(x)
outer()
print(x)
  1. outer（改行）global
  2. inner（改行）global
  3. inner（改行）inner
  4. outer（改行）inner
nonlocal x は外側の関数 outer の x を書き換えます。モジュールの x は "global" のままです。

Q2次のコードの出力はどれか。

class A:
    items = []
    def add(self, v):
        self.items.append(v)
a, b = A(), A()
a.add(1); b.add(2)
print(a.items)
  1. [1]
  2. [2]
  3. []
  4. [1, 2]
items はクラス変数なので、全インスタンスで同じリストを共有します。

Q3クラス Spam の中で self.__eggs = 1 と代入した。インスタンス s から外部でこの値を参照できる書き方はどれか。

  1. s._Spam__eggs
  2. s.__eggs
  3. s.Spam.__eggs
  4. 参照する方法はない
名前マングリングで __eggs は _Spam__eggs に置き換えられます。完全なプライベートではないので、この名前なら参照できます。

Q4次のコードの出力はどれか。

def gen():
    yield 1
    yield 2
g = gen()
print(next(g), next(g), list(g))
  1. 1 2 [1, 2]
  2. 1 1 [1, 2]
  3. 1 2 []
  4. StopIteration
next を2回呼ぶと 1、2 が返り、ジェネレータは使い切られます。その後の list(g) は空のリストです（StopIteration は list の中で処理されます）。

Q5クラスとメソッドの説明として正しいものはどれか。

  1. メソッドの第1引数には、必ず self という名前を付けなければならない。
  2. x.f() は、MyClass.f(x) と同じ意味である。
  3. インスタンス変数は、クラス定義の中で宣言しないと使えない。
  4. 同じ名前のクラス属性とインスタンス属性があると、クラス属性が優先される。
self は慣習です。インスタンス変数は代入したときに作られ、インスタンス属性が優先されます。
