確認問題

Q1print(-7 // 2, -7 % 2, 7 / 7) の出力はどれか。

  1. -3 -1 1
  2. -4 1 1.0
  3. -3 1 1.0
  4. -4 -1 1
-3.5 を小さい方へ切り捨てて -4、余りは -7 − (-4 × 2) = 1 です。/ は常に float なので 1.0 です。

Q2word = 'Python' のとき、エラーになるものはどれか。

  1. word[10:]
  2. word[-6]
  3. word[6]
  4. word[2:100]
インデックスは0〜5（-6〜-1）なので word[6] は IndexError です。スライスは範囲外でもエラーになりません。

Q3次のうち、SyntaxError になるものはどれか。

  1. prefix = 'Py'; prefix 'thon'
  2. 'Py' 'thon'
  3. 3 * 'un' + 'ium'
  4. ('Py' 'thon')
自動連結はリテラル同士だけです。変数とリテラルを並べると SyntaxError になります。

Q4次のコードの出力はどれか。

a = [1, 2, 3]
b = a
c = a[:]
b.append(4)
print(len(a), len(c))
  1. 3 3
  2. 4 4
  3. 3 4
  4. 4 3
b は a と同じリストを指すので、a も4要素になります。c はスライスで作ったコピーなので3要素のままです。

Q5次のコードの出力はどれか。

a, b = 1, 2
a, b = b, a + b
print(a, b)
  1. 2 4
  2. 2 3
  3. 1 3
  4. 3 3
右辺の b（2）と a + b（3）が先に計算されてから、a と b に代入されます。

Q6letters = ['a','b','c','d'] に letters[1:3] = [] を実行した後の letters はどれか。

  1. ['a', [], 'd']
  2. []
  3. ['a', 'd']
  4. ['b', 'c']
スライスに空リストを代入すると、その範囲（インデックス1と2）が削除されます。
