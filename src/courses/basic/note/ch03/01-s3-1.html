3.1Pythonを電卓として使う

対話モードで式を入力すると、その値が表示されます。この教材の Out も同じ仕組みで、最後の式の値を表示しています。

代入（=）しても、対話モードでは何も表示されません。値を代入していない変数を使うと NameError になります。

対話モードの変数 _

対話モードでは、最後に表示された式の値が変数 _（アンダースコア）に入ります。電卓のように計算を続けるのに便利です。_ は読み取り専用として扱い、自分で値を代入しないようにします（代入すると、組み込みの _ を隠す別のローカル変数ができてしまいます）。

>>> tax = 12.5 / 100
>>> price = 100.50
>>> price * tax
12.5625
>>> price + _
113.0625
>>> round(_, 2)
113.06

int・float のほかに、Decimal・Fraction や、虚数部に j を付けて書く複素数（例：3+5j）も扱えます。

3.1.2文字列

引用符とエスケープ
In
print('spam eggs', "spam eggs")
print('doesn\'t', "doesn't")      # \' でエスケープ、または " で囲む
print('"Yes," they said.')
s = 'First line.\nSecond line.'   # \n は改行
s
Out 
spam eggs spam eggs
doesn't doesn't
"Yes," they said.
'First line.\nSecond line.'
In
s = 'First line.\nSecond line.'
print(s)          # print すると \n が改行になり、外側の引用符も付かない
Out 
First line.
Second line.

対話モードで式として表示すると、引用符付きで、エスケープもそのまま表示されます（repr の表示）。print() すると、引用符が取れて特殊文字が解釈されます。

raw文字列
In
print('C:\some\name')    # \n が改行として解釈されてしまう
print(r'C:\some\name')   # r を付けると \ をそのままの文字として扱う
Out 
SyntaxWarning: invalid escape sequence '\s'
C:\some
ame
C:\some\name

Python 3.12 以降では、\s のような意味のないエスケープを書くと、上のように SyntaxWarning（警告）が表示されます。実行自体は続きます。

先頭に r を付けたraw文字列では、\ がエスケープとして解釈されません。ただし、raw文字列の末尾に奇数個の \ を置くことはできません。

三重引用符
In
print("""\
Usage: thingy [OPTIONS]
     -h                        Display this usage message
""")
Out 
Usage: thingy [OPTIONS]
     -h                        Display this usage message

"""…""" や '''…''' で囲むと、複数行の文字列を書けます。行末の改行も文字列に含まれます。行末に \ を置くと、その改行は含まれません（上の例では、最初の改行が入っていません）。

連結と繰り返し
In
print(3 * 'un' + 'ium')        # * で繰り返し、+ で連結
print('Py' 'thon')             # 隣り合った文字列リテラルは自動で連結される
text = ('Put several strings within parentheses '
        'to have them joined together.')
print(text)
prefix = 'Py'
print(prefix + 'thon')         # 変数との連結には + が必要
Out 
unununium
Python
Put several strings within parentheses to have them joined together.
Python
注意

自動で連結されるのは、文字列リテラル同士だけです。prefix 'thon' のように変数と並べたり、('un' * 3) 'ium' のように式と並べたりすると SyntaxError になります。

インデックスとスライス
In
word = 'Python'
print(word[0], word[5], word[-1], word[-2], word[-6])
print(word[0:2], word[2:5])      # 開始は含み、終了は含まない
print(word[:2], word[4:], word[-2:])
print(word[:2] + word[2:])       # s[:i] + s[i:] は常に s と等しい
Out

Py tho
Py on on
Python
Python
正のインデックス012345
負のインデックス-6-5-4-3-2-1

スライスの位置は、文字と文字の「間」を指す番号と考えると分かりやすくなります。-0 は 0 と同じなので、負のインデックスは -1 から始まります。

In
word = 'Python'
print(repr(word[4:42]), repr(word[42:]))   # スライスは範囲外でもエラーにならない
try:
    word[42]                                # インデックスは範囲外だとエラー
except IndexError as e:
    print("IndexError:", e)
try:
    word[0] = 'J'                           # 文字列は変更できない（イミュータブル）
except TypeError as e:
    print("TypeError:", e)
print('J' + word[1:], len(word))
Out 
'on' ''
IndexError: string index out of range
TypeError: 'str' object does not support item assignment
Jython 6
  • 範囲外のインデックスは IndexError、範囲外のスライスはエラーにならず、ある分だけ（なければ空文字列）を返します。
  • 文字列はイミュータブル（変更不可）です。要素に代入すると TypeError になります。変えたいときは新しい文字列を作ります。
  • len() は文字列の長さを返します。

3.1.3リスト

In
squares = [1, 4, 9, 16, 25]
print(squares[0], squares[-1], squares[-3:])
print(squares + [36, 49])          # 連結すると新しいリスト
cubes = [1, 8, 27, 65, 125]        # 4 ** 3 は 64 なのに 65 になっている
cubes[3] = 64                      # リストは変更できる（ミュータブル）
cubes.append(216)                  # 末尾に追加
print(cubes)
Out 
1 25 [9, 16, 25]
[1, 4, 9, 16, 25, 36, 49]
[1, 8, 27, 64, 125, 216]

リストは、文字列と違ってミュータブル（変更可能）です。インデックスとスライスの規則は文字列と同じで、スライスは新しいリスト（浅いコピー）を返します。squares[:] はリスト全体のコピーです。

代入はコピーではない
In
rgb = ["Red", "Green", "Blue"]
rgba = rgb                 # 同じリストに別の名前を付けただけ
print(id(rgb) == id(rgba))
rgba.append("Alph")
print(rgb)                 # rgb 側から見ても変わっている
correct_rgba = rgba[:]     # スライスでコピーを作る
correct_rgba[-1] = "Alpha"
print(correct_rgba, rgba)
Out 
True
['Red', 'Green', 'Blue', 'Alph']
['Red', 'Green', 'Blue', 'Alpha'] ['Red', 'Green', 'Blue', 'Alph']
Javaと比べると

Javaで List<String> b = a; としても、同じリストを指す参照が2つになるだけなのと同じです。コピーしたいときは、スライス a[:] や a.copy()（Javaの new ArrayList<>(a)）を使います。

スライスへの代入と入れ子
In
letters = ['a', 'b', 'c', 'd', 'e', 'f', 'g']
letters[2:5] = ['C', 'D', 'E']     # 一部を置き換え
print(letters)
letters[2:5] = []                  # 一部を削除
print(letters)
letters[:] = []                    # 全部を削除（空にする）
print(letters, len(letters))
a = ['a', 'b', 'c']
n = [1, 2, 3]
x = [a, n]                         # リストの中にリスト
print(x, x[0], x[0][1])
Out 
['a', 'b', 'C', 'D', 'E', 'f', 'g']
['a', 'b', 'f', 'g']
[] 0
[['a', 'b', 'c'], [1, 2, 3]] ['a', 'b', 'c'] b
