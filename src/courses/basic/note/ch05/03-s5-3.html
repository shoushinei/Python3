5.3タプルとシーケンス

リストや文字列のように、インデックスやスライスが使えるデータ型をシーケンス型と呼びます。タプルもその1つです。
In
t = 12345, 54321, 'hello!'      # カッコなしでもタプルになる（タプルのパック）
print(t[0], t)
u = t, (1, 2, 3, 4, 5)          # タプルは入れ子にできる
print(u)
try:
    t[0] = 88888                # タプルは変更できない
except TypeError as e:
    print("TypeError:", e)
v = ([1, 2, 3], [3, 2, 1])      # ただし、ミュータブルなオブジェクトを入れることはできる
v[0].append(4)
print(v)
Out 
12345 (12345, 54321, 'hello!')
((12345, 54321, 'hello!'), (1, 2, 3, 4, 5))
TypeError: 'tuple' object does not support item assignment
([1, 2, 3, 4], [3, 2, 1])
  • タプルは、カンマで区切った値の並びです。出力では必ずカッコで囲まれます。入力ではカッコは省略できますが、大きな式の一部なら必要です。
  • タプルはイミュータブル（要素に代入できない）ですが、中にリストのようなミュータブルなオブジェクトを入れることはできます。
  • 使い分け：タプルは違う種類の要素を入れ、アンパックやインデックスで取り出すことが多い。リストは同じ種類の要素を入れ、for で回すことが多い。
空のタプルと、要素が1つのタプル
In
empty = ()
singleton = 'hello',          # 末尾のカンマが必要
print(len(empty), len(singleton), singleton)
not_tuple = ('hello')         # カンマがないので、ただの文字列
print(type(not_tuple), type(('hello',)))
Out 
0 1 ('hello',)
<class 'str'> <class 'tuple'>
注意：1要素のタプル

要素が1つのタプルは、値の後ろにカンマを付けて 'hello', や ('hello',) と書きます。('hello') はカッコで囲んだだけの文字列です。空のタプルは () です。

シーケンスのアンパック
In
t = 12345, 54321, 'hello!'
x, y, z = t                   # アンパック
print(x, y, z)
try:
    a, b = t                  # 左辺の変数の数と、要素の数は一致させる
except ValueError as e:
    print("ValueError:", e)
Out 
12345 54321 hello!
ValueError: too many values to unpack (expected 2)

右辺のどんなシーケンスでも、シーケンスのアンパックができます。左辺の変数の数は、シーケンスの要素数と同じでなければなりません。多重代入（a, b = 0, 1）は、タプルのパックとアンパックを組み合わせたものです。
