確認問題

Q1次のコードの出力はどれか。

a = [1, 2, 3]
a.insert(1, 9)
x = a.pop()
print(a, x)
  1. [9, 1, 2] 3
  2. [1, 9, 2] 3
  3. [1, 9, 2, 3] None
  4. [1, 2, 3] 9
insert(1, 9) で位置1の前に9が入り [1, 9, 2, 3]。引数なしの pop() は末尾の3を取り出して返します。

Q2次のコードの出力はどれか。

a = [3, 1, 2]
print(a.sort(), sorted(a, reverse=True))
  1. [1, 2, 3] [3, 2, 1]
  2. [1, 2, 3] None
  3. None None
  4. None [3, 2, 1]
sort() はその場で並べ替えて None を返します。sorted() は新しいリストを返します。

Q3キューとして要素を先頭から効率よく取り出すのに適したものはどれか。

  1. collections.deque の popleft()
  2. list の pop()
  3. list の remove(0)
  4. set の pop()
リストの先頭からの削除は、残りの要素をずらすので遅くなります。deque は両端の追加・削除が高速です。

Q4[(x, y) for x in 'ab' for y in [1, 2]] の結果はどれか。

  1. [('a', 1), ('b', 2)]
  2. [('a', 1), ('b', 1), ('a', 2), ('b', 2)]
  3. [('a', 1), ('a', 2), ('b', 1), ('b', 2)]
  4. SyntaxError
左の for（x）が外側のループです。x='a' のときに y が 1, 2 と回り、次に x='b' で回ります。

Q5m = [[1, 2], [3, 4]] のとき、list(zip(*m)) の結果はどれか。

  1. [[1, 3], [2, 4]]
  2. [(1, 3), (2, 4)]
  3. [(1, 2), (3, 4)]
  4. [1, 2, 3, 4]
zip(*m) は zip([1, 2], [3, 4]) と同じで、同じ位置の要素をタプルにします。結果はタプルのリストです。

Q6次のうち、要素が1つのタプルになるものはどれか。

  1. t = (5)
  2. t = [5]
  3. t = 5,
  4. t = tuple(5)
1要素のタプルは末尾のカンマで作ります。(5) はただの整数、tuple(5) は整数がイテラブルでないので TypeError です。

Q7a = {1, 2, 3}、b = {2, 3, 4} のとき、a ^ b の結果はどれか。

  1. {1, 4}
  2. {2, 3}
  3. {1}
  4. {1, 2, 3, 4}
^ は対称差で、どちらか一方だけにある要素です。{2, 3} は &（積）、{1} は a - b、{1, 2, 3, 4} は |（和）です。

Q8辞書のキーにできないものはどれか。

  1. 'name'
  2. 3.14
  3. (1, 'a')
  4. [1, 2]
キーにできるのはイミュータブルな型です。リストは変更できるのでキーにできません（TypeError）。

Q9次のコードの出力はどれか。

print('' or 'B' or 'C', 0 and 5, 3 and 5)
  1. True False True
  2. B 0 5
  3. B False 5
  4. C 0 3
or は最初の真の値、and は最初の偽の値（全部真なら最後の値）を返します。True / False には変換されません。

Q10次の比較のうち、結果が False になるものはどれか。

  1. (1, 2) < (1, 2, -1)
  2. 'Pascal' < 'Python'
  3. [1, 3] < [1, 2, 9]
  4. (1, 2, 3) == (1.0, 2.0, 3.0)
[1, 3] と [1, 2, 9] は2番目の要素 3 > 2 で決まるので、[1, 3] の方が大きく False です。長さは関係ありません。

Q11次のコードの出力はどれか。

for i, c in enumerate('ab', 1):
    print(i, c, end=' ')
  1. 1 a 2 b
  2. 0 a 1 b
  3. a 1 b 2
  4. (1, 'a') (2, 'b')
enumerate の第2引数は開始番号です。位置と値の組がアンパックされて i と c に入ります。

Q12del 文に関する説明として正しいものはどれか。

  1. del a[0] は削除した値を返す。
  2. del a[:] を実行すると変数 a 自体が消える。
  3. del は値を指定して要素を削除する。
  4. del a を実行した後に a を参照すると NameError になる。
del は位置やスライスで削除し、値を返しません。del a[:] は中身を空にするだけで、変数は残ります。del a は変数そのものを削除します。
