5.4集合（set）

集合は、重複しない要素を、順序なしで集めたものです。要素が含まれるかの判定や、重複の除去に使います。和・積・差・対称差の演算ができます。

In
basket = {'apple', 'orange', 'apple', 'pear', 'orange', 'banana'}
print(sorted(basket))          # 重複は除かれる（表示順は決まっていないので sorted で並べた）
print('orange' in basket, 'crabgrass' in basket)
a = set('abracadabra')
b = set('alacazam')
print(sorted(a))               # a に含まれる文字
print(sorted(a - b))           # 差：a にあって b にない
print(sorted(a | b))           # 和：a か b のどちらかにある
print(sorted(a & b))           # 積：a と b の両方にある
print(sorted(a ^ b))           # 対称差：どちらか一方だけにある
Out 
['apple', 'banana', 'orange', 'pear']
True False
['a', 'b', 'c', 'd', 'r']
['b', 'd', 'r']
['a', 'b', 'c', 'd', 'l', 'm', 'r', 'z']
['a', 'c']
['b', 'd', 'l', 'm', 'r', 'z']
演算子名前意味
a - b差a にあって b にない
a | b和a か b の少なくとも一方にある
a & b積（共通部分）a と b の両方にある
a ^ b対称差a と b のどちらか一方だけにある
注意：空の集合は set()

集合は波カッコ {} か set() で作ります。ただし、空の集合は set() で作ります。{} は空の辞書になります。

In
print(type({}), type(set()))
print(sorted({x for x in 'abracadabra' if x not in 'abc'}))   # 集合内包
Out 
<class 'dict'> <class 'set'>
['d', 'r']

集合を print したときの要素の並び順は決まっておらず、実行環境や実行のたびに変わることがあります。この教材では結果を確かめやすいように sorted() で並べています。
