5.7条件についての補足

while や if の条件には、比較だけでなく、いろいろな演算子が使えます。
  • in / not in：値がシーケンス（やコンテナ）に含まれるかを調べる。
  • is / is not：2つが同じオブジェクトかどうかを調べる（値が等しいかは ==）。
  • 比較演算子はすべて同じ優先順位で、数値演算子より低い。
  • 比較は連鎖できる：a < b == c は「a が b より小さく、かつ b と c が等しい」。
  • ブール演算子 and・or・not は比較演算子より優先順位が低く、その中では not が最も高く、or が最も低い。A and not B or C は (A and (not B)) or C と同じ。
In
a, b, c = 1, 2, 2
print(a < b == c)             # (a < b) and (b == c)
print(1 < 2 > 1.5)            # 連鎖は左右の比較を and でつないだもの
x = [1, 2]
y = [1, 2]
print(x == y, x is y)         # 値は等しいが、別のオブジェクト
print(True and not False or False)
Out 
True
True
True False
True
and / or は「最後に評価した値」を返す

and と or は短絡演算子です。左から順に評価し、結果が決まった時点で評価をやめます。真偽値として使うのではなく値として使うと、最後に評価した引数の値がそのまま返ります（True / False に変換されません）。

In
string1, string2, string3 = '', 'Trondheim', 'Hammer Dance'
non_null = string1 or string2 or string3
print(non_null)            # 最初の「真」の値
print(0 or [] or 'x')      # 真の値が見つかるまで進む
print('' or 0)             # 全部偽なら最後の値
print(1 and 'yes')         # and は全部真なら最後の値
print(0 and 'yes')         # 最初の「偽」の値
Out 
Trondheim
x
0
yes
0
式返す値
x or yx が真なら x、偽なら y
x and yx が偽なら x、真なら y

CやJavaと違い、Pythonでは式の中での代入は、セイウチ演算子 := を使って明示的に書く必要があります（if (n = len(a)) > 10 のような書き方はできません）。これにより、== のつもりで = と書くミスを防げます。

In
a = list(range(12))
if (n := len(a)) > 10:
    print(f"List is too long ({n} elements, expected <= 10)")
Out 
List is too long (12 elements, expected <= 10)

Javaの a || b は必ず boolean を返しますが、Pythonの a or b はa か b のどちらかそのものを返します。name = input_name or "anonymous" のように、デフォルト値を決めるのによく使われます。
