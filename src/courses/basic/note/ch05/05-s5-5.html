5.5ディクショナリ

ディクショナリ（辞書）は、キーと値の組を集めたもので、キーで値を取り出します。キーは辞書の中で重複しません。

  • キーにできるのはイミュータブルな型です。文字列・数値はいつでもキーにできます。タプルは、中身がすべてイミュータブルならキーにできます。
  • リストはキーにできません（append やスライス代入で変更できてしまうため）。
In
tel = {'jack': 4098, 'sape': 4139}
tel['guido'] = 4127          # 追加
print(tel)
print(tel['jack'])
del tel['sape']              # 削除
tel['irv'] = 4127
print(tel)
print(list(tel))             # キーのリスト（挿入した順）
print(sorted(tel))           # キーを並べ替えたリスト
print('guido' in tel, 'jack' not in tel)
tel['jack'] = 1              # 既存のキーに代入すると上書き
print(tel)
try:
    tel['nobody']
except KeyError as e:
    print("KeyError:", e)
Out 
{'jack': 4098, 'sape': 4139, 'guido': 4127}
4098
{'jack': 4098, 'guido': 4127, 'irv': 4127}
['jack', 'guido', 'irv']
['guido', 'irv', 'jack']
True False
{'jack': 1, 'guido': 4127, 'irv': 4127}
KeyError: 'nobody'
  • すでにあるキーに値を入れると、古い値は上書きされます。存在しないキーを取り出すと KeyError です。
  • list(d) はキーを挿入した順に並べたリスト、sorted(d) はキーを並べ替えたリストを返します。
  • キーがあるかは in で調べます。
辞書の作り方
In
print(dict([('sape', 4139), ('guido', 4127), ('jack', 4098)]))   # キーと値の組の並びから
print({x: x ** 2 for x in (2, 4, 6)})                             # 辞書内包
print(dict(sape=4139, guido=4127, jack=4098))                     # キーが文字列ならキーワード引数で
try:
    {[1, 2]: 'list'}
except TypeError as e:
    print("TypeError:", e)
print({(1, 2): 'tuple'})
Out 
{'sape': 4139, 'guido': 4127, 'jack': 4098}
{2: 4, 4: 16, 6: 36}
{'sape': 4139, 'guido': 4127, 'jack': 4098}
TypeError: unhashable type: 'list'
{(1, 2): 'tuple'}
