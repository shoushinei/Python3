5.8シーケンスの比較、その他の型の比較

同じ型のシーケンス同士は、辞書式順序で比べます。

  1. まず先頭の要素同士を比べ、違えばそれで大小が決まる。
  2. 同じなら次の要素同士を比べる。これを、どちらかのシーケンスが終わるまで続ける。
  3. 要素自体が同じ型のシーケンスなら、その中も辞書式に比べる（再帰的）。
  4. 全部同じなら、2つは等しい。片方がもう片方の先頭部分と同じなら、短い方が小さい。
  5. 文字列は、各文字の Unicode のコードポイントの大小で比べる。
In
print((1, 2, 3) < (1, 2, 4))
print([1, 2, 3] < [1, 2, 4])
print('ABC' < 'C' < 'Pascal' < 'Python')
print((1, 2, 3, 4) < (1, 2, 4))
print((1, 2) < (1, 2, -1))
print((1, 2, 3) == (1.0, 2.0, 3.0))
print((1, 2, ('aa', 'ab')) < (1, 2, ('abc', 'a'), 4))

True
  • 'Pascal' < 'Python'：2文字目の 'a'（97）と 'y'（121）で決まる。大文字は小文字より小さい（'A' は65、'a' は97）。
  • (1, 2) < (1, 2, -1)：先頭部分が同じなので、短い方が小さい。後ろの要素が負の数でも関係ない。
  • ('aa', 'ab') < ('abc', 'a')：'aa' と 'abc' の2文字目 'a' < 'b' で決まる。

違う型のオブジェクト同士を < や > で比べられるのは、適切な比較メソッドがある場合だけです。数値の型が違う場合（0 == 0.0 など）は値で比べられますが、それ以外は、勝手な順序を付けずに TypeError になります。

In
print(1 < 'a')
Out 
1行目: TypeError: '<' not supported between instances of 'int' and 'str'
POINT
  • append は1つ、extend は要素を全部。insert(i, x) は i の前。remove は値、pop は位置（省略時は末尾）で、pop だけ値を返す。sort・reverse などは None を返す。
  • スタックは append と pop、キューは deque の append と popleft。
  • リスト内包の for・if の順番は入れ子ループと同じ。タプルを作るならカッコ必須。zip(*matrix) はタプルのリスト。
  • del は位置・スライスで消し、値を返さない。del a の後は NameError。
  • 1要素のタプルは 'a',。空の集合は set()、{} は辞書。差 -、和 |、積 &、対称差 ^。辞書のキーはイミュータブルな型だけ（リスト不可）。
  • items はキーと値、enumerate は位置と値、zip は組、reversed は逆順、sorted は新しいリスト。
  • or / and は最後に評価した値を返す。not > and > or。比較は連鎖できる。シーケンスは辞書式で比べ、短い方が小さい。
