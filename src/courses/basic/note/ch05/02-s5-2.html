5.2del文

del文は、値ではなくインデックスやスライスを指定して要素を削除します。pop() と違って、値を返しません。

In
a = [-1, 1, 66.25, 333, 333, 1234.5]
del a[0]
print(a)
del a[2:4]
print(a)
del a[:]           # 全要素を削除（空のリストが残る）
print(a)
del a              # 変数そのものを削除
try:
    print(a)
except NameError as e:
    print("NameError:", e)
Out 
[1, 66.25, 333, 333, 1234.5]
[1, 66.25, 1234.5]
[]
NameError: name 'a' is not defined

del a で変数そのものを削除すると、その後 a を参照したときに（別の値を代入するまで）NameError になります。
