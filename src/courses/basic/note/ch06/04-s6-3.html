6.3dir()関数

組み込み関数 dir() は、モジュールが定義している名前を、並べ替えた文字列のリストで返します。

In
import sys; sys.path.insert(0, ".")
import fibo
print([n for n in dir(fibo) if not n.startswith("__")])
print(type(dir(fibo)), dir(fibo) == sorted(dir(fibo)))
Out 
['fib', 'fib2']
<class 'list'> True
  • 引数なしの dir() は、現在定義している名前（変数・モジュール・関数など）を返します。
  • ただし、組み込み関数や組み込み変数の名前は含まれません。それらは標準モジュール builtins に定義されているので、dir(builtins) で見られます。
In
a = [1, 2, 3]
print(sorted(n for n in dir() if not n.startswith("__")))
import builtins
print('print' in dir(builtins), 'len' in dir(builtins))
Out 
['a']
True True
