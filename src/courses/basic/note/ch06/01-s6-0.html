6.0モジュールとは

定義を書いたファイルをモジュールと呼び、ファイル名は「モジュール名＋.py」です。モジュールの中では、モジュール名がグローバル変数 __name__ に文字列で入っています。

次の内容の fibo.py を作ります（この教材では、コードの中でファイルを作っています）。この章のコードを「▶ 実行」で試すときは、このファイルを作るコードから順に実行してください。

In
code = '''\
def fib(n):    # n までのフィボナッチ数列を出力
    a, b = 0, 1
    while a < n:
        print(a, end=' ')
        a, b = b, a+b
    print()

def fib2(n):   # n までのフィボナッチ数列をリストで返す
    result = []
    a, b = 0, 1
    while a < n:
        result.append(a)
        a, b = b, a+b
    return result
'''
with open("fibo.py", "w") as f:
    f.write(code)
In
import sys; sys.path.insert(0, ".")    # この教材の実行環境用の準備
import fibo                              # モジュール名 fibo だけが使えるようになる
fibo.fib(1000)
print(fibo.fib2(100))
print(fibo.__name__)
fib = fibo.fib                           # よく使うならローカルな名前に
fib(500)

import fibo で現在のシンボル表に入るのは、モジュール名 fibo だけです。fib を直接呼ぶことはできず、fibo.fib のように「モジュール名.名前」で使います。
