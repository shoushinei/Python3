確認問題

Q1本番今日の日付を得るコード from ＿＿＿ import date → print(date.today()) の空欄に入るものはどれか。

  1. date
  2. datetime
  3. time
  4. calendar
date クラスは datetime モジュールにあります。from の後ろにはモジュール名を書きます。

Q2from fibo import fib を実行した後の説明として正しいものはどれか。

  1. fibo.fib(10) と fib(10) の両方が使える。
  2. fibo モジュールの全ての名前が使える。
  3. fib(10) は使えるが、fibo.fib(10) は NameError になる。
  4. fib は使えず、fibo.fib(10) と書く必要がある。
from … import では、モジュール名 fibo そのものは定義されません。

Q3モジュールの検索について正しいものはどれか。

  1. まず組み込みモジュールを探し、なければ sys.path のディレクトリを探す。
  2. 標準ライブラリのディレクトリは、スクリプトのあるディレクトリより先に検索される。
  3. 環境変数 PYTHONPATH は検索に使われない。
  4. sys.path は変更できない。
スクリプトのあるディレクトリが標準ライブラリより先に検索されます。PYTHONPATH も検索パスに含まれ、sys.path は普通のリストとして変更できます。

Q4コンパイル済みファイルについて正しいものはどれか。

  1. .pyc ファイルから読み込むと、プログラムの実行速度が上がる。
  2. -O オプションは docstring だけを除去する。
  3. コマンドラインから直接実行したスクリプトのコンパイル結果も __pycache__ に保存される。
  4. -OO オプションは assert 文と __doc__ 文字列を除去する。
-O は assert のみ、-OO は assert と docstring を除去します。.pyc で速くなるのは読み込みだけで、直接実行したスクリプトのキャッシュは保存されません。

Q5from sound.effects import * の説明として正しいものはどれか。

  1. effects ディレクトリ内のすべてのサブモジュールが必ずインポートされる。
  2. __init__.py に __all__ があれば、そこに列挙されたモジュールがインポートされる。
  3. __init__.py がなくても、ディレクトリはパッケージとして扱われる。
  4. 相対インポートの書き方である。
__all__ があればその一覧、なければサブモジュールは自動ではインポートされません。
