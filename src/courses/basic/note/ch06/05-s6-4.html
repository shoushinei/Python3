6.4パッケージ

パッケージは、A.B のような「ドット付きのモジュール名」でモジュールを整理する仕組みです。A.B は、パッケージ A のサブモジュール B を表します。

sound/                          トップレベルのパッケージ
      __init__.py               sound パッケージを初期化する
      formats/                  ファイル形式の変換用サブパッケージ
              __init__.py
              wavread.py
              ...
      effects/                  音響効果用サブパッケージ
              __init__.py
              echo.py
              surround.py
              ...
      filters/                  フィルタ用サブパッケージ
              __init__.py
              equalizer.py
              ...

__init__.py は、ディレクトリをパッケージとして扱わせるために必要なファイルです。中身は空でもよく、パッケージの初期化コードを書いたり、__all__ を設定したりもできます。

import の書き方使い方
import sound.effects.echosound.effects.echo.echofilter(…)（フルネームで参照）
from sound.effects import echoecho.echofilter(…)
from sound.effects.echo import echofilterechofilter(…)
  • from package import item の item は、サブモジュール・サブパッケージ・パッケージ内で定義された関数やクラスなど、どれでもかまいません。まずパッケージ内で定義された名前か調べ、なければモジュールとみなして読み込みます。見つからなければ ImportError です。
  • import item.subitem.subsubitem の形では、最後以外はすべてパッケージでなければなりません。最後はモジュールかパッケージで、クラス・関数・変数は指定できません。

6.4.1パッケージから * をインポート

from sound.effects import * としたとき、

  • パッケージの __init__.py に __all__ というリストが定義されていれば、そこに書かれたモジュール名がインポートされます。
  • __all__ がなければ、サブモジュールは自動ではインポートされません。インポートされるのは、パッケージ自体（__init__.py を実行）と、そこで定義された名前だけです。
In
import os, sys
sys.path.insert(0, ".")
os.makedirs("sound/effects", exist_ok=True)
open("sound/__init__.py", "w").close()
with open("sound/effects/__init__.py", "w") as f:
    f.write('__all__ = ["echo"]\n')            # * のときは echo だけ
with open("sound/effects/echo.py", "w") as f:
    f.write('def echofilter(): return "echo!"\n')
with open("sound/effects/surround.py", "w") as f:
    f.write('def surround(): return "surround!"\n')
from sound.effects import *
print(echo.echofilter())
print("surround" in dir())                     # __all__ にないので入らない
Out 
echo!
False

チュートリアルは、from package import 特定のサブモジュール と書くのが推奨の書き方だとしています。

6.4.2パッケージ内の相互参照

  • 絶対インポート：from sound.effects import echo
  • 相対インポート：先頭のドットで、現在のパッケージと親パッケージを表します。
In
# sound/effects/surround.py の中で
from . import echo                  # 同じパッケージ（effects）の echo
from .. import formats              # 親パッケージ（sound）の formats
from ..filters import equalizer     # 親パッケージの filters の中の equalizer

相対インポートは、現在のモジュール名をもとに解決されます。メインモジュールの名前は常に "__main__" なので、メインモジュールとして使うモジュールでは、必ず絶対インポートを使います。

6.4.3複数のディレクトリにまたがるパッケージ

パッケージには __path__ という特別な属性があります。__init__.py のあるディレクトリ名を入れたリストで、これを変更すると、パッケージに含まれるモジュールやサブパッケージを探す場所を広げられます。めったに使いません。

POINT
  • import fibo なら fibo.fib、from fibo import fib なら fib（fibo は使えない）。from … import * は _ で始まる名前以外を全部。as で別名。
  • from の後ろはモジュール（パッケージ）名、import の後ろはその中の名前。date は datetime モジュールの中。
  • モジュールは1セッション1回だけ読み込まれる（reload は importlib.reload）。スクリプト実行時は __name__ == "__main__"。
  • 検索順：組み込みモジュール → sys.path（スクリプトのディレクトリ → PYTHONPATH → デフォルト）。
  • __pycache__ に .pyc。-O は assert を除去、-OO は assert と docstring を除去。実行は速くならない。
  • dir() は並べ替えたリスト。引数なしは現在の名前（組み込みは含まない → dir(builtins)）。
  • __init__.py でパッケージに。* は __all__ のモジュールだけ。相対インポートは . と ..、メインモジュールでは使えない。
