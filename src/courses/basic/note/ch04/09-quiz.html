確認問題

Q1本番次のコードの出力はどれか。

for c in "abc":
    print(c)
  1. abc
  2. a b c
  3. a（改行）b（改行）c
  4. ['a', 'b', 'c']
文字列を for で回すと1文字ずつ取り出され、print が毎回改行するので、1文字ずつ別の行に出力されます。

Q2list(range(10, 0, -3)) の結果はどれか。

  1. [10, 7, 4, 1, -2]
  2. [10, 7, 4, 1]
  3. [10, 7, 4]
  4. []
10 から -3 ずつ、0 を含まない手前まで進むので [10, 7, 4, 1] です。

Q3次のコードの出力はどれか。

for n in [3, 5, 8]:
    if n % 2 == 0:
        print("even")
        break
else:
    print("done")
  1. even
  2. done
  3. even（改行）done
  4. 何も出力されない
8 で break するので、ループの else は実行されません。

Q4次のコードの出力はどれか。

def add(x, items=[]):
    items.append(x)
    return items

add(1)
print(add(2))
  1. [2]
  2. [1]
  3. [2, 1]
  4. [1, 2]
デフォルト値のリストは定義時に1つだけ作られ、呼び出しのたびに同じリストが使われるので、値がたまっていきます。

Q5def f(a, b, /, c, *, d): と定義された関数の呼び出しで、正しいものはどれか。

  1. f(1, b=2, c=3, d=4)
  2. f(1, 2, 3, 4)
  3. f(1, 2, c=3, d=4)
  4. f(a=1, b=2, c=3, d=4)
a と b は位置専用、d はキーワード専用、c はどちらでもよいので、C だけが正しい呼び出しです。

Q6次のコードの出力はどれか。

def show(*args, **kwargs):
    print(args, kwargs)

show(1, 2, x=3)
  1. [1, 2] {'x': 3}
  2. (1, 2) {'x': 3}
  3. (1, 2, 3) {}
  4. (1, 2) ('x', 3)
*args は余った位置引数をタプルで、**kwargs は余ったキーワード引数を辞書で受け取ります。

Q7次のコードの出力はどれか。

x = 10
def f(y=x):
    return y
x = 20
print(f())
  1. 10
  2. 20
  3. None
  4. NameError
デフォルト値は def が実行された時点の x（10）で決まります。

Q8関数注釈に関する説明として正しいものはどれか。

  1. 注釈と違う型の値を渡すと TypeError になる。
  2. 注釈は関数の __doc__ 属性に保存される。
  3. 戻り値の注釈は def f() : -> int のように書く。
  4. 注釈は __annotations__ 属性に辞書として保存され、実行には影響しない。
注釈は __annotations__ に入るだけで、型のチェックはしません。戻り値は def f() -> int: と書きます。

Q9docstring の書き方として、チュートリアルが勧めているものはどれか。

  1. 1行目に関数名と引数の型を書く。
  2. 要約の直後の2行目から詳しい説明を書き始める。
  3. 1行目は大文字で始めピリオドで終わる簡潔な要約にし、続きがあれば2行目は空行にする。
  4. docstring は関数の最後の行に書く。
1行目は簡潔な要約、2行目は空行、3行目以降に説明です。
