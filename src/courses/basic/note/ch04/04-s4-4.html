4.4break文とcontinue文、ループにおけるelse節

  • break：最も内側の for / while ループを抜けます。
  • continue：残りの処理を飛ばして、ループの次の回に進みます。
  • ループの else 節：ループが最後まで回り切ったとき（for なら要素を使い切ったとき、while なら条件が偽になったとき）に実行されます。break で抜けたときは実行されません。
In
for n in range(2, 10):
    for x in range(2, n):
        if n % x == 0:
            print(n, 'equals', x, '*', n // x)
            break
    else:
        # 約数が見つからずに内側のループが終わった
        print(n, 'is a prime number')
Out 
2 is a prime number
3 is a prime number
4 equals 2 * 2
5 is a prime number
6 equals 2 * 3
7 is a prime number
8 equals 2 * 4
9 equals 3 * 3

この else は、if ではなく内側の for に属しています（インデントの位置に注目）。ループの else は、if の else よりも、try文の else（例外が起きなかったときに実行）に近いものです。

In
for num in range(2, 10):
    if num % 2 == 0:
        print("Found an even number", num)
        continue
    print("Found an odd number", num)
Out 
Found an even number 2
Found an odd number 3
Found an even number 4
Found an odd number 5
Found an even number 6
Found an odd number 7
Found an even number 8
Found an odd number 9
注意

ループが1回も回らなかった場合（例：for x in []:）も、「最後まで回り切った」扱いなので else は実行されます。
