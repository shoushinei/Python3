4.7さらに関数定義について

引数の受け取り方の4つの仕組みです。組み合わせた問題がよく出ます。

4.7.1引数のデフォルト値

In
def ask_ok(prompt, retries=4, reminder='Please try again!'):
    while True:
        ok = input(prompt)
        if ok in ('y', 'ye', 'yes'):      # in はシーケンスに値が含まれるか調べる
            return True
        if ok in ('n', 'no', 'nop', 'nope'):
            return False
        retries = retries - 1
        if retries &lt; 0:
            raise ValueError('invalid user response')
        print(reminder)

# 呼び出し方は3通り
# ask_ok('Do you really want to quit?')
# ask_ok('OK to overwrite the file?', 2)
# ask_ok('OK to overwrite the file?', 2, 'Come on, only yes or no!')
デフォルト値は「定義したとき」に評価される
In
i = 5

def f(arg=i):      # この時点の i（5）がデフォルト値になる
    print(arg)

i = 6
f()
Out 
5
デフォルト値は1回だけしか評価されない
In
def f(a, L=[]):    # この [] は関数を定義したときに1つだけ作られる
    L.append(a)
    return L

print(f(1))
print(f(2))
print(f(3))
Out 
[1]
[1, 2]
[1, 2, 3]
注意：ミュータブルなデフォルト値

デフォルト値がリストや辞書のようなミュータブルなオブジェクトだと、呼び出しのたびに同じオブジェクトが使われ、値がたまっていきます。呼び出しごとに新しいリストにしたいときは、None をデフォルトにして、関数の中で作ります。

In
def f(a, L=None):
    if L is None:
        L = []
    L.append(a)
    return L

print(f(1), f(2), f(3))
Out 
[1] [2] [3]

4.7.2キーワード引数

In
def parrot(voltage, state='a stiff', action='voom', type='Norwegian Blue'):
    print("-- This parrot wouldn't", action, end=' ')
    print("if you put", voltage, "volts through it.")
    print("-- Lovely plumage, the", type)
    print("-- It's", state, "!")

parrot(1000)                                          # 位置引数1つ
parrot(voltage=1000)                                  # キーワード引数1つ
parrot(action='VOOOOOM', voltage=1000000)             # キーワード引数は順番自由
parrot('a thousand', state='pushing up the daisies')  # 位置1つ＋キーワード1つ
Out 
-- This parrot wouldn't voom if you put 1000 volts through it.
-- Lovely plumage, the Norwegian Blue
-- It's a stiff !
-- This parrot wouldn't voom if you put 1000 volts through it.
-- Lovely plumage, the Norwegian Blue
-- It's a stiff !
-- This parrot wouldn't VOOOOOM if you put 1000000 volts through it.
-- Lovely plumage, the Norwegian Blue
-- It's a stiff !
-- This parrot wouldn't voom if you put a thousand volts through it.
-- Lovely plumage, the Norwegian Blue
-- It's pushing up the daisies !

名前=値 の形で渡すのがキーワード引数です。次の呼び出しはすべてエラーになります。

呼び出しエラーの理由
parrot()必須の引数 voltage がない
parrot(voltage=5.0, 'dead')キーワード引数の後ろに位置引数がある（SyntaxError）
parrot(110, voltage=220)同じ引数に値が2回渡されている
parrot(actor='John Cleese')存在しないキーワード
In
def parrot(voltage, state='a stiff', action='voom', type='Norwegian Blue'):
    pass

parrot(110, voltage=220)
Out 
4行目: TypeError: parrot() got multiple values for argument 'voltage'
*name と **name

仮引数に *name を書くと、余った位置引数がタプルで入り、**name を書くと、余ったキーワード引数が辞書で入ります。*name は **name より前に書く必要があります。

In
def cheeseshop(kind, *arguments, **keywords):
    print("-- Do you have any", kind, "?")
    print("-- I'm sorry, we're all out of", kind)
    for arg in arguments:
        print(arg)
    print("-" * 40)
    for kw in keywords:
        print(kw, ":", keywords[kw])

cheeseshop("Limburger", "It's very runny, sir.",
           "It's really very, VERY runny, sir.",
           shopkeeper="Michael Palin",
           client="John Cleese",
           sketch="Cheese Shop Sketch")
Out 
-- Do you have any Limburger ?
-- I'm sorry, we're all out of Limburger
It's very runny, sir.
It's really very, VERY runny, sir.
----------------------------------------
shopkeeper : Michael Palin
client : John Cleese
sketch : Cheese Shop Sketch

キーワード引数は、呼び出しで渡した順番どおりに辞書に入ります。

4.7.3特殊引数

仮引数のリストに / と * を書くと、引数の渡し方を制限できます。

def f(pos1, pos2, /, pos_or_kwd, *, kwd1, kwd2):
位置渡し方
/ より前位置専用（キーワードでは渡せない）
/ と * の間位置でもキーワードでもよい
* より後キーワード専用（位置では渡せない）
In
def standard_arg(arg):
    print(arg)

def pos_only_arg(arg, /):
    print(arg)

def kwd_only_arg(*, arg):
    print(arg)

def combined_example(pos_only, /, standard, *, kwd_only):
    print(pos_only, standard, kwd_only)

standard_arg(2); standard_arg(arg=2)
pos_only_arg(1)
kwd_only_arg(arg=3)
combined_example(1, 2, kwd_only=3)
combined_example(1, standard=2, kwd_only=3)
for call in ["pos_only_arg(arg=1)", "kwd_only_arg(3)", "combined_example(1, 2, 3)",
             "combined_example(pos_only=1, standard=2, kwd_only=3)"]:
    try:
        eval(call)
    except TypeError as e:
        print("TypeError:", e)
Out 
2
2
1
3
1 2 3
1 2 3
TypeError: pos_only_arg() got some positional-only arguments passed as keyword arguments: 'arg'
TypeError: kwd_only_arg() takes 0 positional arguments but 1 was given
TypeError: combined_example() takes 2 positional arguments but 3 were given
TypeError: combined_example() got some positional-only arguments passed as keyword arguments: 'pos_only'

位置専用にすると、仮引数の名前を **kwds のキーとしても使えるようになります。

In
def foo(name, /, **kwds):
    return 'name' in kwds

print(foo(1, **{'name': 2}))   # / がないと「name に値が2つ」で TypeError になる
Out 
True

4.7.4任意引数のリスト

*args の後ろに書いた仮引数は、キーワード専用になります。

In
def concat(*args, sep="/"):
    return sep.join(args)

print(concat("earth", "mars", "venus"))
print(concat("earth", "mars", "venus", sep="."))
Out 
earth/mars/venus
earth.mars.venus

4.7.5引数リストのアンパック

すでにリストやタプルになっている値を、ばらばらの位置引数として渡すには *、辞書をキーワード引数として渡すには ** を付けて呼び出します。

In
print(list(range(3, 6)))
args = [3, 6]
print(list(range(*args)))      # range(3, 6) と同じ

def parrot(voltage, state='a stiff', action='voom'):
    print("-- This parrot wouldn't", action, end=' ')
    print("if you put", voltage, "volts through it.", end=' ')
    print("E's", state, "!")

d = {"voltage": "four million", "state": "bleedin' demised", "action": "VOOM"}
parrot(**d)
Out 
[3, 4, 5]
[3, 4, 5]
-- This parrot wouldn't VOOM if you put four million volts through it. E's bleedin' demised !
注意：* と ** の2つの意味

定義の側（def f(*args, **kw)）では「まとめて受け取る」、呼び出しの側（f(*lst, **dic)）では「ばらして渡す」という逆の意味になります。

4.7.6lambda（ラムダ）式

lambda 引数: 式 で、小さな無名関数を作れます。本体は1つの式だけで、その値が戻り値になります。外側のスコープの変数も参照できます。

In
def make_incrementor(n):
    return lambda x: x + n

f = make_incrementor(42)
print(f(0), f(1))
pairs = [(1, 'one'), (2, 'two'), (3, 'three'), (4, 'four')]
pairs.sort(key=lambda pair: pair[1])     # 2番目の要素（文字列）で並べ替え
print(pairs)
Out 
42 43
[(4, 'four'), (1, 'one'), (3, 'three'), (2, 'two')]
Javaと比べると

Javaのラムダ式 x -> x + n とほぼ同じです。sort(key=lambda pair: pair[1]) は list.sort(Comparator.comparing(p -> p.get(1))) にあたります。

4.7.7ドキュメンテーション文字列（docstring）

  • 1行目は、目的を簡潔にまとめた要約にします。大文字で始め、ピリオドで終えます。名前や型は書きません（ほかの方法で分かるため）。
  • 続きがある場合は、2行目を空行にして、要約と説明を分けます。
  • 3行目以降に、呼び出し方や副作用などの説明を書きます。
  • docstring は関数の __doc__ 属性で参照できます。
In
def my_function():
    """Do nothing, but document it.

    No, really, it doesn't do anything.
    """
    pass

print(my_function.__doc__)
Out 
Do nothing, but document it.

No, really, it doesn't do anything.

4.7.8関数注釈（関数アノテーション）

引数や戻り値に、型などの情報を付けておけます。引数: 注釈、戻り値は ) -> 注釈: と書きます。注釈は関数の __annotations__ 属性に辞書として保存されるだけで、実行には何の影響もありません（型が違う値を渡してもエラーにはなりません）。

In
def f(ham: str, eggs: str = 'eggs') -> str:
    print("Annotations:", f.__annotations__)
    print("Arguments:", ham, eggs)
    return ham + ' and ' + eggs

f('spam')
Out 
Annotations: {'ham': <class 'str'>, 'eggs': <class 'str'>, 'return': <class 'str'>}
Arguments: spam eggs
'spam and eggs'
In
def g(x: int) -> int:
    return x * 2

print(g("ab"))      # 注釈は int でも、str を渡せてしまう
Out 
abab
