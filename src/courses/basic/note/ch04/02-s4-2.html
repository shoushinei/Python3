4.2for文

Pythonの for文は、数値の範囲ではなく、リストや文字列などのシーケンスの要素を、並んでいる順に1つずつ取り出して回します。
In
words = ['cat', 'window', 'defenestrate']
for w in words:
    print(w, len(w))
Out 
cat 3
window 6
defenestrate 12
本番で出た論点：文字列を for で回す

文字列もシーケンスなので、for で回すと1文字ずつ取り出されます。print() は毎回最後に改行するので、1文字ずつ別の行に出力されます。

In
for ch in "Python":
    print(ch)
Out 
P
y
t
h
o
n

同じ行に続けて出したいときは、end で改行を別の文字に変えます。

In
for ch in "Python":
    print(ch, end="")     # 改行しない → 1行に続けて出る
print()                   # 最後に改行だけ出す
for ch in "Python":
    print(ch, end="-")
Out 
Python
P-y-t-h-o-n-
Javaと比べると

for ch in "Python": は、Javaの for (char ch : "Python".toCharArray()) System.out.println(ch); と同じです。print は println（改行あり）、print(…, end="") は print（改行なし）にあたります。

回している最中にコレクションを変更しない

ループの中で、回しているコレクション自体を変更すると、うまく動かないことがあります。コピーを回すか、新しいコレクションを作るのが確実です。

In
users = {'Hans': 'active', 'Éléonore': 'inactive', '景太郎': 'active'}
# 方法1：コピーを回しながら、元の辞書を変更する
for user, status in users.copy().items():
    if status == 'inactive':
        del users[user]
print(users)
# 方法2：新しいコレクションを作る
users = {'Hans': 'active', 'Éléonore': 'inactive', '景太郎': 'active'}
active_users = {}
for user, status in users.items():
    if status == 'active':
        active_users[user] = status
print(active_users)
Out 
{'Hans': 'active', '景太郎': 'active'}
{'Hans': 'active', '景太郎': 'active'}
