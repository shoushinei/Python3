In
x = 42
if x < 0:
    x = 0
    print('Negative changed to zero')
elif x == 0:
    print('Zero')
elif x == 1:
    print('Single')
else:
    print('More')
Out 
More

elif は「else if」の略で、いくつ並べてもかまいません。elif も else も省略できます。if … elif … elif … の並びは、他の言語の switch文・case文の代わりになります。上から順に調べて、最初に当てはまったブロックだけが実行されます。
