リストのメソッド（5.1）

問い答えメモ
append(x) / extend(it)末尾に1つ追加 / 要素を全部追加戻り値 None
insert(i, x)位置 i の前に挿入
remove(x)値 x の最初の要素を削除（なければ ValueError）
pop() / pop(i)末尾 / 位置 i を削除して返す値を返すのは pop
clear()全部削除（del a[:]）
index(x) / count(x)最初の位置 / 出現回数
sort() / reverse()その場で並べ替え / 逆順（戻り値 None）新しいリストは sorted()
copy()浅いコピー（a[:]）
スタック / キューappend と pop ／ deque の append と popleft
