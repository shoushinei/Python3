10.9データ圧縮

一般的なデータの保存形式や圧縮形式を扱うモジュールとして、zlib・gzip・bz2・lzma・zipfile・tarfile があります。

In
import zlib
s = b'witch which has which witches wrist watch'
print(len(s))
t = zlib.compress(s)          # 圧縮
print(len(t))
print(zlib.decompress(t))     # 展開
print(zlib.crc32(s))          # チェックサム
Out 
41
37
b'witch which has which witches wrist watch'
226805979
