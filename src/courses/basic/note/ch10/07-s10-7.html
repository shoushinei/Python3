10.7インターネットへのアクセス

インターネットにアクセスしたり、インターネットのプロトコルを扱ったりするモジュールが数多くあります。最も簡単なのは、URL からデータを取得する urllib.request と、メールを送信する smtplib です。

In
from urllib.request import urlopen
with urlopen('http://worldtimeapi.org/api/timezone/etc/UTC.txt') as response:
    for line in response:
        line = line.decode()             # bytes を str に変換
        if line.startswith('datetime'):
            print(line.rstrip())

import smtplib
server = smtplib.SMTP('localhost')       # localhost でメールサーバーが動いている必要がある
server.sendmail('soothsayer@example.org', 'jcaesar@example.org',
"""To: jcaesar@example.org
From: soothsayer@example.org

Beware the Ides of March.
""")
server.quit()
