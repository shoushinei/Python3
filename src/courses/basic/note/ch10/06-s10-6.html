data = [2.75, 1.75, 1.25, 0.25, 0.5, 1.25, 3.5]
print(statistics.mean(data))     # 平均
print(statistics.median(data))   # 中央値
print(statistics.variance(data)) # 分散（標本分散）

import random
random.seed(1)                           # 例を再現するためにシードを固定
print(random.choice(['apple', 'pear', 'banana']))
print(random.sample(range(100), 10))     # 重複なしで10個を選ぶ
print(random.random())                   # 0以上1未満の float
print(random.randrange(6))               # range(6) から1つ選んだ整数

モジュール関数動き
mathcos・log など浮動小数点数の数学関数（Cライブラリの関数へのアクセス）
log(x, base)底を指定した対数
randomchoice(seq)シーケンスから1つ選ぶ
sample(population, k)重複なしで k 個選ぶ
random()0.0以上1.0未満の float
randrange(6)range(6) から選んだ整数（0〜5）
statisticsmean・median・variance平均・中央値・分散などの基本的な統計量

より本格的な数値計算には、SciPy プロジェクトなどがあります。
