10.8日付と時間

datetime モジュールは、日付と時刻を扱うクラスを提供します。日付と時刻の計算ができ、出力の書式設定や、タイムゾーンを考慮したオブジェクトも扱えます。

In
from datetime import date               # datetime モジュールの date クラス
now = date(2026, 10, 31)                # 実際には date.today() で今日の日付
print(now)
print(now.strftime("%m-%d-%y. %d %b %Y is a %A on the %d day of %B."))
birthday = date(1964, 7, 31)
age = now - birthday                    # 日付の引き算 → timedelta
print(type(age).__name__, age.days)
Out 
2026-10-31
10-31-26. 31 Oct 2026 is a Saturday on the 31 day of October.
timedelta 22737
本番で出た論点

date クラスは datetime モジュールの中にあります。from datetime import date とすれば date.today()、import datetime とすれば datetime.date.today() と書きます（→ 6.1）。
