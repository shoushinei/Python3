10.3コマンドライン引数

コマンドライン引数は、sys モジュールの argv 属性にリストで入っています（→ 2.1.1）。python demo.py one two three と実行すると、sys.argv は ['demo.py', 'one', 'two', 'three'] です。

より高度なコマンドライン処理には argparse モジュールを使います。

In
import argparse

parser = argparse.ArgumentParser(
    prog='top',
    description='Show top lines from each file')
parser.add_argument('filenames', nargs='+')                  # 1つ以上の位置引数
parser.add_argument('-l', '--lines', type=int, default=10)   # オプション引数
args = parser.parse_args()
print(args)
% python top.py --lines=5 alpha.txt beta.txt
Namespace(filenames=['alpha.txt', 'beta.txt'], lines=5)

args.lines は 5、args.filenames は ['alpha.txt', 'beta.txt'] になります。--lines を省略すると、default=10 が使われます。
