10.10パフォーマンス計測

同じ問題を解く方法同士の性能を比べるには、timeit モジュールを使います。例えば、2つの変数の値を入れ替えるのに、従来の方法とタプルのパック・アンパックのどちらが速いかを比べます。

In
from timeit import Timer
Timer('t=a; a=b; b=t', 'a=1; b=2').timeit()   # 一時変数を使う方法
Timer('a,b = b,a', 'a=1; b=2').timeit()        # タプルのパックとアンパック（こちらが速い）

Timer(計測する文, 準備の文).timeit() は、計測する文を（既定で100万回）実行した時間を秒で返します。timeit は細かいコード片の計測向けで、大きなコードのどこに時間がかかっているかを調べるには profile と pstats モジュールを使います。
