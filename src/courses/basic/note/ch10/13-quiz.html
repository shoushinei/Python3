確認問題

Q1本番チュートリアルが from os import * ではなく import os を使うよう勧めている理由はどれか。

  1. from os import * は、os モジュールの関数を1つもインポートしないから。
  2. os.open() が、動作の大きく異なる組み込み関数 open() を隠してしまうから。
  3. import os の方が、実行速度が2倍以上速くなるから。
  4. from os import * は、Windowsでは SyntaxError になるから。
from os import * をすると os.open が open という名前で入り、組み込みの open() を隠してしまいます。

Q2モジュールと機能の組み合わせとして誤っているものはどれか。

  1. shutil ― ファイルのコピーや移動
  2. glob ― ワイルドカードによるファイル名のリスト
  3. statistics ― 平均・中央値・分散
  4. smtplib ― URL からデータを取得
URL からのデータ取得は urllib.request です。smtplib はメールの送信に使います。

Q3random.sample(range(10), 3) の説明として正しいものはどれか。

  1. 0〜9 から重複なしで3つを選んだリストを返す。
  2. 0〜9 から重複ありで3つを選んだリストを返す。
  3. 0〜3 の整数を1つ返す。
  4. 0以上10未満の float を3つ返す。
sample は重複なしで k 個を選びます。

Q4docstring に書いた使用例を実際に実行して、結果を検証するモジュールはどれか。

  1. unittest
  2. timeit
  3. doctest
  4. pstats
doctest は docstring の中のテストを検証します。unittest は別のファイルで管理する包括的なテストです。

Q5標準出力をファイルにリダイレクトしていても、警告メッセージを端末に表示したいときに使うものはどれか。

  1. sys.stdout.write()
  2. sys.stderr.write()
  3. sys.exit()
  4. sys.argv
stderr（標準エラー出力）は、stdout をリダイレクトしていても画面に表示されます。
