10.12電池付きであること

Pythonは「電池付き（batteries included）」、つまり標準ライブラリだけで多くのことができる、という考え方をしています。

モジュールできること
xmlrpc.client / xmlrpc.serverリモートプロシージャコール（RPC）
emailメールメッセージ（MIME などを含む）の管理。実際の送受信はしない
jsonJSON 形式の読み書き
csvCSV 形式の読み書き
xml.etree.ElementTree・xml.dom・xml.saxXML の処理
sqlite3SQLite データベースのラッパー
gettext・locale・codecs国際化（多言語対応）
POINT
  • import os を使い、from os import * は避ける（os.open が組み込みの open を隠すため）。dir() と help() で調べる。ファイル管理は shutil。
  • glob.glob('*.py') はリスト。sys.argv はリスト、高度な処理は argparse。警告は sys.stderr、終了は sys.exit()。
  • re.findall / re.sub。単純なら文字列メソッド。math・random（choice・sample・random・randrange）・statistics（mean・median・variance）。
  • urllib.request で取得、smtplib で送信。date は datetime モジュール、日付の差は timedelta。
  • 圧縮は zlib・gzip・bz2・lzma・zipfile・tarfile。計測は timeit、大きなコードは profile・pstats。
  • doctest は docstring のテスト（testmod）、unittest は別ファイルで包括的なテスト。
