10.2ファイルのワイルドカード

glob モジュールは、ワイルドカードで検索したファイル名のリストを返す関数を持っています。

In
import glob, os
os.makedirs('globdemo', exist_ok=True)
for name in ['primes.py', 'quote.py', 'utils.py', 'notes.txt']:
    open(os.path.join('globdemo', name), 'w').close()
print(sorted(glob.glob('globdemo/*.py')))
Out 
['globdemo/primes.py', 'globdemo/quote.py', 'globdemo/utils.py']
