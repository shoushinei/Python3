確認問題

Q1本番リスト data を JSON 形式でファイルオブジェクト f に書き込むコードとして正しいものはどれか。

  1. json.dumps(data, f)
  2. json.dump(f, data)
  3. json.dump(data, f)
  4. f.write(json.load(data))
ファイルに書き込むのは json.dump(データ, ファイル) です。dumps は文字列を返す関数です。

Q2print(json.dumps({"a": True})) の出力はどれか（json は import 済み）。

  1. {'a': True}
  2. {"a": true}
  3. {"a": True}
  4. None
JSON では文字列はダブルクォート、真偽値は小文字の true になります。dumps は文字列を返します。

Q3x = 'abc' のとき、print(f'{x!r:>7}|') の出力はどれか。

  1. 'abc'|
  2. abc|
  3. 'abc' |
  4. abc|
!r で repr が適用され 'abc'（5文字）になり、>7 で幅7の右寄せになるので、左に空白2つが入ります。

Q4print('-42'.zfill(6), 'python'.rjust(3)) の出力はどれか。

  1. 000-42 pyt
  2. -00042 pyt
  3. 000-42 python
  4. -00042 python
zfill は符号の後ろに0を詰めます。rjust は文字列の方が長いとき、切り詰めずにそのまま返します。

Q5ファイル操作の説明として正しいものはどれか。

  1. open() のモードを省略すると書き込みモードになる。
  2. f.readline() は行末の改行文字を取り除いて返す。
  3. f.write() は書き込んだ文字数を返す。
  4. モード 'a' で開くと、既存の内容が消えてから書き込まれる。
モードの既定は 'r'、readline() は改行文字を残します。中身が消えるのは 'w'、'a' は末尾に追記します。

Q6print('{1}-{0}-{name}'.format('a', 'b', name='c')) の出力はどれか。

  1. a-b-c
  2. b-a-c
  3. b-a-name
  4. IndexError
{1} は2番目の位置引数 'b'、{0} は 'a'、{name} はキーワード引数 'c' です。
