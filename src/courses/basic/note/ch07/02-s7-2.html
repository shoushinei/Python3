7.2ファイルの読み書き

open(ファイル名, モード, encoding=None) はファイルオブジェクトを返します。

モード意味
'r'読み込み専用（省略したときの既定）
'w'書き込み専用。同じ名前のファイルがあると中身は消える
'a'追記。書き込んだデータは末尾に追加される
'r+'読み書き両用
'b' を付ける（'rb' など）バイナリモード。データは bytes として読み書きされる
  • モードを省略するとテキストモードです。テキストモードでは、encoding を指定しないとプラットフォーム依存の文字コードになるので、encoding="utf-8" を指定するのが勧められています。
  • テキストモードでは、読み込み時に行末の改行コード（Windowsなら \r\n）が \n に、書き込み時に \n がプラットフォームの改行コードに変換されます。JPEG や EXE のようなバイナリのファイルを壊さないように、バイナリのファイルはバイナリモードで扱います。
with 文を使う
In
with open('workfile', 'w', encoding="utf-8") as f:
    f.write('This is the first line of the file.\n')
    f.write('Second line of the file\n')
print(f.closed)                  # with を抜けると自動で閉じられる
try:
    f.read()
except ValueError as e:
    print("ValueError:", e)
Out 
True
ValueError: I/O operation on closed file.

with を使うと、処理が終わったとき（途中で例外が起きても）ファイルが正しく閉じられます。with を使わないときは、必ず f.close() を呼びます（閉じないと、データが書き込まれ切らないことがあります）。閉じたファイルを操作すると ValueError です。

7.2.1ファイルオブジェクトのメソッド

In
with open('workfile', 'w', encoding="utf-8") as f:
    f.write('This is the first line of the file.\nSecond line of the file\n')
with open('workfile', encoding="utf-8") as f:
    print(repr(f.read()))        # 全部を1つの文字列で
    print(repr(f.read()))        # ファイルの終わりでは空文字列
with open('workfile', encoding="utf-8") as f:
    print(repr(f.readline()))    # 1行ずつ。末尾の改行文字は残る
    print(repr(f.readline()))
    print(repr(f.readline()))    # 終わりなら空文字列
Out 
'This is the first line of the file.\nSecond line of the file\n'
''
'This is the first line of the file.\n'
'Second line of the file\n'
''
メソッド動き
f.read(size)最大 size 文字（バイナリなら size バイト）を読む。省略や負の数なら全部。ファイルの終わりでは ''（空文字列）
f.readline()1行を読む。末尾の改行文字 \n は残る（最終行に改行がなければ付かない）。'' ならファイルの終わり、'\n' なら空行
for line in f:1行ずつ回す。メモリ効率がよく、速く、コードも簡単
list(f) / f.readlines()全行をリストで返す
f.write(文字列)書き込み、書き込んだ文字数を返す。文字列以外は str() などで変換が必要（バイナリモードなら bytes）
f.tell()現在の位置を返す（バイナリモードでは先頭からのバイト数。テキストモードでは意味の分からない数値）
f.seek(offset, whence)位置を変える。whence が 0なら先頭（既定）、1なら現在位置、2なら末尾から offset だけ移動
In
with open('workfile', 'w', encoding="utf-8") as f:
    print(f.write('This is a test\n'))       # 書き込んだ文字数
    value = ('the answer', 42)
    print(f.write(str(value)))               # タプルは文字列に変換してから
with open('workfile', encoding="utf-8") as f:
    for line in f:
        print(line, end='')                  # line の末尾には \n が付いている
print()
with open('workfile', 'wb+') as f:           # バイナリモード（読み書き）
    f.write(b'0123456789abcdef')
    f.seek(5)                                # 6バイト目へ
    print(f.read(1))
    f.seek(-3, 2)                            # 末尾から3バイト前へ
    print(f.read(1), f.tell())
Out 
15
18
This is a test
('the answer', 42)
b'5'
b'd' 14

テキストモードでは、先頭からの seek だけが許されます（例外として seek(0, 2) で末尾へ移動はできる）。有効な offset は f.tell() が返した値か 0 だけです。

7.2.2構造のあるデータを jsonで保存する

リストや辞書のような構造のあるデータを、文字列に変換してファイルに保存するには、標準モジュール json を使います。データを文字列にすることをシリアライズ、文字列からデータに戻すことをデシリアライズと呼びます。

本番で出た論点：json.dump

4つの関数の違いは、相手が「文字列」か「ファイル」かです。名前の最後の s は string（文字列）の s と覚えます。

関数動き
json.dumps(x)x を JSON の文字列にして返す
json.dump(x, f)x を JSON にして、テキストファイル f に書き込む
json.loads(s)JSON の文字列 s からデータに戻す
json.load(f)テキストファイル f を読んで、データに戻す
In
import json
x = [1, 'simple', 'list']
s = json.dumps(x)                # 文字列になる
print(s, type(s))
with open('data.json', 'w', encoding="utf-8") as f:
    json.dump(x, f)              # ファイルに書き込む（戻り値は None）
with open('data.json', encoding="utf-8") as f:
    y = json.load(f)             # ファイルから読み込む
print(y, type(y))
print(json.loads('{"a": 1, "b": [true, null]}'))   # true→True、null→None
Out 
[1, "simple", "list"] <class 'str'>
[1, 'simple', 'list'] <class 'list'>
{'a': 1, 'b': [True, None]}
  • dump の引数の順番は json.dump(データ, ファイル) です。
  • JSON ファイルは UTF-8 でエンコードしなければならないので、encoding="utf-8" を指定して開きます。
  • 自分で作ったクラスのインスタンスをシリアライズするには、少し追加の作業が必要です。
注意：json と pickle

pickle も直列化のモジュールですが、どんなPythonオブジェクトでも扱える代わりに、Python専用で他の言語とは共有できず、信頼できないデータを pickle で読み込むと危険（任意のコードを実行されうる）です。json は他の言語ともデータを交換できる、テキストの形式です。

Javaと比べると

json.dumps / json.loads は、Jackson の writeValueAsString / readValue(String, …) にあたります。Spring Boot の REST API がやり取りしている、あの JSON 形式です。

POINT
  • str() は人向け、repr() はインタープリタ向け。文字列では repr に引用符が付く。
  • f文字列：{x:10} は最小幅、{x:.3f} は小数3桁、{x!r} は repr、{x=} は「x=値」。
  • format：{0}{1} は位置、{name} は名前、**dict で展開。rjust は切り詰めない、zfill は符号を理解して0を詰める。
  • open の既定は 'r'、'w' は中身を消す、'a' は追記、'b' はバイナリ。with なら自動で閉じる。閉じたファイルの操作は ValueError。
  • read() は全部、終わりは ''。readline() は改行文字を残す。write() は文字数を返す。seek の whence は 0/1/2。
  • dumps / loads は文字列、dump / load はファイル。json.dump(データ, ファイル)。
