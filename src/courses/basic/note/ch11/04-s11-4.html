11.4マルチスレッド

スレッドを使うと、順番に依存しない処理を切り離して、同時に進められます。threading モジュールを使います。

In
import threading, zipfile

with open('mydata.txt', 'w') as f:
    f.write('data ' * 100)

class AsyncZip(threading.Thread):
    def __init__(self, infile, outfile):
        threading.Thread.__init__(self)
        self.infile = infile
        self.outfile = outfile

    def run(self):                       # スレッドで実行する処理
        f = zipfile.ZipFile(self.outfile, 'w', zipfile.ZIP_DEFLATED)
        f.write(self.infile)
        f.close()
        print('Finished background zip of:', self.infile)

background = AsyncZip('mydata.txt', 'myarchive.zip')
background.start()                       # スレッドを開始
print('The main program continues to run in foreground.')
background.join()                        # バックグラウンドの処理が終わるのを待つ
print('Main program waited until background was done.')
Out 
The main program continues to run in foreground.
Finished background zip of: mydata.txt
Main program waited until background was done.

上の2行目と3行目の出力順は、スレッドの進み具合によって入れ替わることがあります。

  • start() でスレッドを開始すると run() が実行され、join() でそのスレッドの終了を待ちます。
  • 複数のスレッドでデータを共有するときの調整が難しい点です。threading には、ロック・イベント・条件変数・セマフォなどの同期の仕組みがあります。
  • 推奨されるのは、リソースへのアクセスを1つのスレッドに集中させ、queue モジュールでほかのスレッドからの要求を渡す方法です。Queue オブジェクトを使うと、設計しやすく、読みやすく、信頼性の高いプログラムになります。
