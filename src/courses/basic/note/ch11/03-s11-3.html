11.3バイナリデータレコードの処理

struct モジュールの pack()・unpack() で、可変長のバイナリレコードを扱えます。書式文字の "H" は2バイト、"I" は4バイトの符号なし整数、"<" は標準サイズのリトルエンディアンを表します。

In
import struct
data = struct.pack('<IIH', 1, 2, 3)      # 4 + 4 + 2 = 10 バイト
print(len(data), data)
print(struct.unpack('<IIH', data))
Out 
10 b'\x01\x00\x00\x00\x02\x00\x00\x00\x03\x00'
(1, 2, 3)
