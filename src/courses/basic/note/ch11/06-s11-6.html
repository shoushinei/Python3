11.6弱参照

Pythonは自動でメモリを管理します（多くのオブジェクトは参照カウント、循環参照はガベージコレクションで解放）。最後の参照がなくなると、すぐにメモリが解放されます。

weakref モジュールの弱参照を使うと、オブジェクトへの参照を作らずに、オブジェクトを追跡できます。オブジェクトが不要になると、弱参照の表からも自動で取り除かれます。キャッシュなどに使います。

In
import weakref, gc

class A:
    def __init__(self, value):
        self.value = value
    def __repr__(self):
        return str(self.value)

a = A(10)                        # 参照を作る
d = weakref.WeakValueDictionary()
d['primary'] = a                 # 参照は作らない
print(d['primary'])
del a                            # 参照を削除
gc.collect()                     # ガベージコレクションを実行
try:
    d['primary']                 # 自動的に取り除かれている
except KeyError as e:
    print("KeyError:", e)
Out 
10
KeyError: 'primary'
