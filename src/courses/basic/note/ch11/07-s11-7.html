11.7リスト操作のツール

モジュール用途
array同じ型の数値だけを、コンパクトに保存するリスト風のオブジェクト（'H' なら1要素2バイト。普通のリストの int は1要素16バイト）
collections.deque左端での追加・取り出しが速い（その代わり中央の参照は遅い）。キューや幅優先探索に向く
bisectソート済みのリストを、並び順を保ったまま操作する
heapq普通のリストでヒープを実現する。最も小さい値が常に位置0にある
In
from array import array
a = array('H', [4000, 10, 700, 22222])
print(sum(a), a[1:3])
from collections import deque
d = deque(["task1", "task2", "task3"])
d.append("task4")
print("Handling", d.popleft())
import bisect
scores = [(100, 'perl'), (200, 'tcl'), (400, 'lua'), (500, 'python')]
bisect.insort(scores, (300, 'ruby'))         # 並び順を保ったまま挿入
print(scores)
from heapq import heapify, heappop, heappush
data = [1, 3, 5, 7, 9, 2, 4, 6, 8, 0]
heapify(data)                                # ヒープの順に並べ替える
heappush(data, -5)                           # 新しい要素を追加
print([heappop(data) for i in range(3)])     # 小さい順に3つ取り出す
Out
