確認問題

Q1Template('$a and $b').safe_substitute(a='X') の結果はどれか（Template は import 済み）。

  1. 'X and '
  2. KeyError
  3. 'X and $b'
  4. 'X and None'
safe_substitute は、値がないプレースホルダをそのまま残します。substitute なら KeyError です。

Q2次のコードの出力はどれか。

from heapq import heapify, heappop
data = [5, 1, 4, 2]
heapify(data)
print(heappop(data), heappop(data))
  1. 1 2
  2. 5 4
  3. 5 1
  4. 1 4
ヒープでは最も小さい値が位置0にあり、heappop は小さい順に取り出します。

Q3モジュールと用途の組み合わせとして誤っているものはどれか。

  1. textwrap ― 文章を指定した幅に整形する
  2. bisect ― ソート済みリストを順序を保って操作する
  3. weakref ― 参照を作らずにオブジェクトを追跡する
  4. reprlib ― 出力を改行・インデントして見やすくする
改行・インデントで見やすく表示するのは pprint です。reprlib は大きなコンテナを省略して表示します。

Q4logging モジュールの既定の動作として正しいものはどれか。

  1. すべてのレベルのメッセージを標準出力に出す。
  2. debug と info のメッセージは出力せず、出力は標準エラー出力に送る。
  3. ログは必ずファイルに書き込まれる。
  4. critical 以外は出力しない。
既定では warning 以上が標準エラー出力に送られます。
