11.2テンプレート

string モジュールの Template クラスを使うと、利用者が編集しやすい、簡単な書式のテンプレートを作れます。

  • 置き換える場所（プレースホルダ）は $ と識別子で書きます。後ろに英数字が続くときは ${village}folk のように波カッコで囲みます。$$ と書くと $ そのものになります。
  • substitute() は、値が足りないと KeyError。safe_substitute() は、値がないプレースホルダをそのまま残す。
  • Template を継承して delimiter を変えると、$ 以外の区切り文字を使えます。
In
from string import Template
t = Template('${village}folk send $$10 to $cause.')
print(t.substitute(village='Nottingham', cause='the ditch fund'))
t = Template('Return the $item to $owner.')
d = dict(item='unladen swallow')
try:
    t.substitute(d)
except KeyError as e:
    print("KeyError:", e)
print(t.safe_substitute(d))
Out 
Nottinghamfolk send $10 to the ditch fund.
KeyError: 'owner'
Return the unladen swallow to $owner.
In
import time, os.path
from string import Template
photofiles = ['img_1074.jpg', 'img_1076.jpg', 'img_1077.jpg']

class BatchRename(Template):
    delimiter = '%'                  # 区切り文字を % に変える

fmt = 'Ashley_%n%f'                  # %n は連番、%f は元のファイル名
t = BatchRename(fmt)
for i, filename in enumerate(photofiles):
    base, ext = os.path.splitext(filename)
    newname = t.substitute(d='', n=i, f=ext)
    print(f'{filename} --> {newname}')
Out 
img_1074.jpg --> Ashley_0.jpg
img_1076.jpg --> Ashley_1.jpg
img_1077.jpg --> Ashley_2.jpg

テンプレートは、プログラムの処理と、出力の書式の詳細を分けるのに役立ちます。
