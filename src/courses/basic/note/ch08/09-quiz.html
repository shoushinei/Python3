確認問題

Q1次のコードの出力はどれか。

try:
    print("A")
    x = 1 / 0
    print("B")
except ZeroDivisionError:
    print("C")
else:
    print("D")
finally:
    print("E")
  1. A B C E
  2. A C D E
  3. A C E
  4. A B D E
1/0 で例外が起きるので B は飛ばされ、C が実行されます。例外が起きたので else は実行されず、finally の E は必ず実行されます（実際の出力は1行ずつ）。

Q2次の関数 f() の戻り値はどれか。

def f():
    try:
        return 1
    finally:
        return 2
  1. 2
  2. 1
  3. (1, 2)
  4. None
try と finally の両方に return があると、finally の return の値が戻り値になります。

Q3次のコードの出力はどれか。

try:
    raise KeyError("k")
except LookupError:
    print("lookup")
except KeyError:
    print("key")
  1. key
  2. lookup（改行）key
  3. KeyError で停止する
  4. lookup
KeyError は LookupError の派生クラスなので、先に書かれた except LookupError で捕まります。実行される except は1つだけです。

Q4例外に関する説明として正しいものはどれか。

  1. else 節は、例外が起きたときに実行される。
  2. 複数の例外を1つの except 節で処理するには、例外をタプルで並べる。
  3. ZeroDivisionError などの標準の例外名は予約語である。
  4. ユーザー定義例外は、object クラスから直接派生させる。
else は例外が起きなかったときに実行されます。標準の例外名は予約語ではなく組み込みの識別子で、ユーザー定義例外は Exception から派生させます。

Q5例外を処理している except 節の中で、別の例外を送出したとき、元の例外を表示させないための書き方はどれか。

  1. raise RuntimeError from exc
  2. raise
  3. raise RuntimeError from None
  4. raise None
from None で自動の連鎖を無効にできます。from exc は原因を明示した連鎖、引数なしの raise は今の例外の再送出です。

Q6try: raise Exception('a', 1) に対する except Exception as e: print(e.args) の出力はどれか。

  1. ('a', 1)
  2. ['a', 1]
  3. a 1
  4. Exception('a', 1)
例外を作ったときの引数は args 属性にタプルで入ります。
