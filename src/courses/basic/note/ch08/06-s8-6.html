8.6ユーザー定義例外

新しい例外クラスを作れば、自分で例外に名前を付けられます。例外クラスは、直接・間接に Exception クラスから派生させます。

In
class InsufficientFundsError(Exception):
    """残高不足を表す例外"""
    def __init__(self, balance, amount):
        super().__init__(balance, amount)
        self.balance = balance
        self.amount = amount

try:
    raise InsufficientFundsError(100, 300)
except InsufficientFundsError as e:
    print("残高", e.balance, "円に対して", e.amount, "円を引き出そうとした")
    print(isinstance(e, Exception))
Out 
残高 100 円に対して 300 円を引き出そうとした
True
  • 例外クラスは、普通のクラスと同じように何でもできますが、エラーの情報を取り出すための属性をいくつか持つだけの、簡単なものにしておくのが普通です。
  • 標準の例外と同じく、名前は 「Error」で終わるようにするのが一般的です。
