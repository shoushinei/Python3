8.4例外の送出

In
try:
    raise NameError('HiThere')       # 例外を送出する
except NameError:
    print('An exception flew by!')
try:
    raise ValueError                 # クラスを渡すと、引数なしでインスタンス化される
except ValueError as e:
    print(type(e).__name__, repr(e))
Out 
An exception flew by!
ValueError ValueError()
  • raise 文で例外を発生させられます。引数は例外のインスタンスか例外クラス（Exception から派生したクラス）です。
  • クラスを渡すと、引数なしで暗黙にインスタンスが作られます。raise ValueError は raise ValueError() の省略形です。
  • except 節の中で、引数なしの raise と書くと、今処理している例外をもう一度送出します。
In
try:
    raise NameError('HiThere')
except NameError:
    print('An exception flew by!')
    raise
Out 
An exception flew by!
