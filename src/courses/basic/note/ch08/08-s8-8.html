8.8オブジェクトに定義済のクリーンアップ動作

ファイルのように、使い終わったら後始末が必要なオブジェクトには、あらかじめクリーンアップ動作が定義されています。with 文を使うと、処理の途中で問題が起きても、確実に後始末（ファイルを閉じる）が行われます。

In
for line in open("myfile.txt"):       # 実行後もファイルが開いたままになる
    print(line, end="")

with open("myfile.txt") as f:         # ブロックを抜けると、必ずファイルが閉じられる
    for line in f:
        print(line, end="")
Javaと比べると

with 文は、Javaの try-with-resources（try (var r = new FileReader(…)) { … }）と同じ役割です。

POINT
  • 構文エラーは実行前、例外は実行中。標準の例外名は予約語ではない。
  • try で例外 → 残りは飛ばして、一致する except を1つだけ実行。複数はタプル。基底クラスでも捕まる（先に書くと派生クラスに届かない）。
  • else は例外がなかったときだけ、except より後ろ。finally は必ず実行。
  • raise クラス は引数なしでインスタンス化。except 内の raise は再送出。from で明示的に連鎖、from None で連鎖を止める。
  • ユーザー定義例外は Exception から派生、名前は Error で終える。
  • finally に return があればその値が優先。with は確実に後始末をする。
