8.7クリーンアップ動作の定義

finally 節は、例外が起きても起きなくても、必ず最後に実行されます。外部のリソース（ファイルやネットワーク接続）を解放するのに使います。

In
def divide(x, y):
    try:
        result = x / y
    except ZeroDivisionError:
        print("division by zero!")
    else:
        print("result is", result)
    finally:
        print("executing finally clause")

divide(2, 1)
divide(2, 0)
try:
    divide("2", "1")
except TypeError as e:
    print("TypeError:", e)
Out 
result is 2.0
executing finally clause
division by zero!
executing finally clause
executing finally clause
TypeError: unsupported operand type(s) for /: 'str' and 'str'

3つ目の呼び出しの TypeError は except 節で処理されないので、finally 節を実行した後で、もう一度送出されます。

状況finally の動き
例外が except で処理されないfinally を実行した後で例外が再送出される
except 節や else 節の中で例外が起きたfinally を実行した後で、その例外が再送出される
try 節で break・continue・return を実行それが実行される直前に finally が実行される
finally 節に break・continue・return がある例外は再送出されない
try と finally の両方に return があるfinally の return の値が戻り値になる
In
def bool_return():
    try:
        return True
    finally:
        return False

print(bool_return())

def f():
    try:
        print("try")
        return "try の戻り値"
    finally:
        print("finally（return の直前に実行される）")

print(f())
Out 
False
try
finally（return の直前に実行される）
try の戻り値
