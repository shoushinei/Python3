8.3例外の処理

In
while True:
    try:
        x = int(input("Please enter a number: "))
        break
    except ValueError:
        print("Oops!  That was no valid number.  Try again...")
try 文の流れ
1try 節を実行例外が起きなければ except 節は飛ばして、try 文は終わる。
2例外が起きたらtry 節の残りは飛ばす。例外の型が except の名前と一致すれば、その except 節を実行し、try 文の後ろから続ける。
3一致しなければ外側の try 文に渡す。どこでも処理されなければ処理されない例外となり、メッセージを出して止まる。
  • except 節はいくつ書いてもよいですが、実行されるのは最大1つだけです。
  • except 節が処理するのは、対応する try 節で起きた例外だけです。同じ try 文の別の except 節の中で起きた例外は処理しません。
  • 1つの except 節で複数の例外を処理するには、タプルで書きます：except (RuntimeError, TypeError, NameError):
基底クラスでも捕まえられる

except 節のクラスは、同じクラスか、その基底クラスの例外と一致します（逆は一致しません）。

In
class B(Exception):
    pass
class C(B):
    pass
class D(C):
    pass

for cls in [B, C, D]:
    try:
        raise cls()
    except D:
        print("D")
    except C:
        print("C")
    except B:
        print("B")
Out 
B
C
D

注意：except の順番

except 節は上から順に調べられ、最初に一致したものだけが実行されます。基底クラスを先に書くと、派生クラスの except 節には決して届きません。

Javaと比べると

Javaの try-catch と同じ考え方です。Javaでは、基底クラスの catch を先に書くとコンパイルエラー（到達不能）になりますが、Pythonではエラーにならず、そのまま実行されて後ろが無視される点が違います。

例外オブジェクトと args
In
try:
    raise Exception('spam', 'eggs')
except Exception as inst:
    print(type(inst))      # 例外のインスタンスの型
    print(inst.args)       # 引数は .args にタプルで入る
    print(inst)            # __str__ により args が表示される
    x, y = inst.args       # アンパックもできる
    print('x =', x)
    print('y =', y)
Out 
<class 'Exception'>
('spam', 'eggs')
('spam', 'eggs')
x = spam
y = eggs

except 例外名 as 変数: と書くと、例外のインスタンスが変数に入ります。例外を作ったときの引数は args 属性にタプルで入っています。

else 節
In
for arg in ['ok.txt', 'missing.txt']:
    if arg == 'ok.txt':
        with open(arg, 'w') as f:
            f.write('line1\nline2\n')
    try:
        f = open(arg, 'r')
    except OSError:
        print('cannot open', arg)
    else:
        print(arg, 'has', len(f.readlines()), 'lines')
        f.close()
Out 
ok.txt has 2 lines
cannot open missing.txt
  • else 節は、すべての except 節より後ろに書きます。try 節で例外が起きなかったときだけ実行されます。
  • try 節にコードを追加するより、else 節に書く方がよいとされています。保護したいコード以外で起きた例外を、うっかり捕まえてしまうのを防げるからです。
  • try 節の中で直接起きた例外だけでなく、try 節の中で呼んだ関数の中で起きた例外も処理されます。
In
def this_fails():
    x = 1 / 0

try:
    this_fails()
except ZeroDivisionError as err:
    print('Handling run-time error:', err)
Out 
Handling run-time error: division by zero

最後の except 節では例外名を省略でき（except:）、どんな例外でも捕まえます。本当のエラーを隠してしまうので、使うときは十分注意します。メッセージを表示してから、raise で同じ例外をもう一度送出する使い方もあります。
