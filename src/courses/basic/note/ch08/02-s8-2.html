8.2例外

文法が正しくても、実行中にエラーが起きることがあります。実行中に検出されたエラーを例外と呼びます。例外は、処理すれば致命的ではありません。

In
for code in ["10 * (1/0)", "4 + spam*3", "'2' + 2"]:
    try:
        eval(code)
    except Exception as e:
        print(type(e).__name__ + ":", e)
Out 
ZeroDivisionError: division by zero
NameError: name 'spam' is not defined
TypeError: can only concatenate str (not "int") to str
  • エラーメッセージの最後の行に、例外の型（ZeroDivisionError・NameError・TypeError など）と、その詳細が表示されます。
  • 標準の例外の名前は組み込みの識別子で、予約語（キーワード）ではありません。
  • メッセージの前の部分は、例外が起きた場所をトレースバック（呼び出しの履歴）の形で示します。
