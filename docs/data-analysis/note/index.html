    1.1データ分析の世界

    データ分析を取り巻く状況と、データサイエンティスト・データ分析エンジニアの役割を説明します。

    1.1.1データ分析を取り巻く状況

    DX（デジタルトランスフォーメーション）やIoT機器が広まったことで、多くの情報がデジタルデータとして蓄積されるようになりました。政府や自治体が機械判読しやすい形で無料公開するオープンデータも増えています。家庭のPCやクラウドサービスでも、大量のデータを手軽に処理できる時代になりました。

    データ分析は、売上予測、行動予測、工場の異常検知、天気予報、画像認識など、幅広い分野で使われています。これらの多くでは機械学習が使われており、データがなければ機械学習は成り立ちません。さらに深層学習（ディープラーニング）は、大量のデータをもとに、物体認識・自然言語処理・翻訳などで成果を上げています。

    1.1.2データ分析とPython

    データ分析におけるPythonの役割

    データ分析の分野では、Pythonはデファクトスタンダード（事実上の標準）になっています。数値・テキスト・画像・音声などのデータをPythonで分析しやすい形に加工し、統計処理や機械学習で予測を行います。

    Pythonの特長
    • 言語の仕様が分かりやすい
    • コンパイル不要の動的なスクリプト言語
    • 豊富な標準ライブラリと外部のパッケージ
    • データ分析以外にも応用範囲が広い
    • オープンソース
    Pythonが得意とする分野

    データ分析のほかに、サーバー系ツール、Webシステムの構築、IoT機器の操作、3Dグラフィックスなどでも使われています。

    注意：得意・不得意を区別する

    Pythonはどの分野でも一番というわけではありません。Webブラウザで動く画面（フロントエンド）はJavaScriptが中心です。速度が必要な低レイヤーの処理はC/C++などが向いています。Python自体の実行速度は速くありません。NumPyなどのライブラリは、中身をC言語で書くことで速さを補っています。

    データ分析に使われるそのほかの言語・ツール

    Pythonのほかに、統計解析向けのR、科学技術計算向けのJuliaがあります。広い意味では、表計算のExcelや、Excelを自動化するVBA（Visual Basic for Applications）もデータ分析の道具です。

    1.1.3データサイエンティストとは

    データを使って課題を解決する専門家をデータサイエンティストと呼びます。主な役割は次のとおりです。

    モデル・アルゴリズムの構築データから予測や分類を行う仕組みを作る
    新たな解法・新技術への取り組み新しい手法を試し、取り入れる
    課題に向き合う実務解決したい課題を理解し、分析を役立てる
    分析結果の評価結果が妥当か、役に立つかを判断する

    どこに重点を置くかは、研究分野と実務とで少し違います。研究分野では新たな解法や新技術への取り組みが重視されます。実務では、解決したい課題に向き合うことが重視されます。

    1.1.4データ分析エンジニアとは

    データ分析エンジニアは、データの収集・加工・保存の仕組みを作ったり、分析のプログラムを実装したりする技術者です。データサイエンティストが分析に集中できる環境を支えます。Python、数学の基礎、ライブラリの使い方は、データ分析エンジニアに欠かせない知識です。この教材の第2〜4章で、それらを順に学びます。

    1.1.5データハンドリング（前処理）の重要性

    集めたデータは、そのままでは分析に使えないことがほとんどです。欠けた値（欠損値）、表記の揺れ、単位の違い、文字のままのカテゴリなどを整える作業を前処理（データハンドリング）と呼びます。

    1.2機械学習の位置づけと流れ

    機械学習とは何か、どんな種類があり、どんな手順で進めるのかを説明します。

    1.2.1機械学習とは

    人間がルールを1つずつ書く代わりに、データからルール（パターン）をコンピュータに学ばせる方法を機械学習と呼びます。人間がルールを書いて判定する方法はルールベースと呼ばれ、機械学習と対比されます。

    例えば迷惑メールの判定で考えます。ルールベースでは「件名に○○を含めば迷惑メール」というルールを人間が考えて書きます。機械学習では、大量の「迷惑メール／普通のメール」の例からコンピュータが判定基準を見つけます。

    1.2.2データからモデルを作る

    機械学習でデータから学習した結果をモデルと呼びます。モデルは「入力を受け取って、予測を返す関数」のようなものです。

    目的変数（ラベル・正解）予測したい値。例：住宅価格、花の品種、迷惑メールかどうか。
    説明変数（特徴量）予測の手がかりにする値。例：部屋の数、築年数、花びらの長さ。

    このとき、目的変数と説明変数（特徴量）という言葉を区別して使います。

    Javaと比べると

    モデルは、引数（説明変数）から戻り値（目的変数の予測）を返すメソッドのようなものです。ただし、メソッドの中身を人間が書くのではなく、データから自動で決まるところが違います。

    1.2.3機械学習のタスク

    種類正解ラベル代表的なタスク例
    教師あり学習あり回帰・分類住宅価格の予測、花の品種の判定
    教師なし学習なしクラスタリング・次元削減顧客のグループ分け、特徴量の要約
    強化学習なし（報酬で学ぶ）行動の最適化ゲームの攻略、ロボットの制御
    教師あり学習：回帰と分類

    教師あり学習は、正解（目的変数）が付いたデータから学ぶ方法です。目的変数の種類によって、回帰と分類の2つに分けられます。

    回帰目的変数が連続値（数量）。例：広告費から売上金額を予測する。
    分類目的変数が離散値（カテゴリ）。例：画像が犬か猫かを判定する。

    ここで、回帰か分類かを決めるのは、説明変数ではなく目的変数の種類です。

    教師なし学習：クラスタリングと次元削減

    教師なし学習は、正解ラベルを使わずに、データそのものの構造を見つける方法です。

    • クラスタリング：似たデータ同士をグループ（クラスタ）にまとめる。k-means や、データの密度にもとづく DBSCAN などがある。
    • 次元削減：情報をなるべく失わずに、特徴量（次元）の数を減らす。主成分分析（PCA）など。
    強化学習

    強化学習は、ある環境の中で行動するエージェントが、試行錯誤しながら得られる報酬が最大になるように行動の仕方を学ぶ方法です。囲碁やゲームのAI、ロボットの制御などで使われます。

    深層学習の位置づけ

    深層学習は、ニューラルネットワークを何層も重ねた手法の名前で、上の3つのような学習の「種類」の名前ではありません。画像分類のような教師あり学習でよく使われますが、教師なし学習や強化学習と組み合わせて使われることもあります。

    1.2.4機械学習の処理の手順

    1データ収集分析に必要なデータを集める。
    2前処理欠損値の処理、カテゴリの数値化、尺度をそろえる正規化など。
    3データの分割学習用とテスト用に分ける。
    4学習アルゴリズムを選び、学習用データでモデルを作る。
    5評価テスト用データで性能を測る。必要に応じて設定を調整して4へ戻る。

    この手順は、第4章の scikit-learn でそのままコードになります。今は「前処理 → 学習 → 評価」の順番を覚えておけば十分です。

    2.1.2venv: Pythonの仮想環境

    プロジェクトごとに、使うパッケージとそのバージョンを分けておく仕組みを仮想環境と呼びます。標準ライブラリの venv で作れて、Windows・macOS・Linuxのどれでも使えます。

    % python3 -m venv env              # env という名前の仮想環境を作る
% source env/bin/activate          # 有効化（macOS / Linux）
(env) % python -V                  # プロンプトの先頭に (env) が付く
Python 3.13.2
(env) % deactivate                 # 無効化

    Windowsでは env\Scripts\activate で有効化します。

    注意：venvで分かれるのはパッケージ

    仮想環境の中のPythonは、venvを実行したPython本体と同じバージョンになります。venvは「パッケージの組み合わせ」を分ける仕組みで、Pythonのバージョン自体を切り替える仕組みではありません。別のバージョンを使いたいときは、そのバージョンのPythonを別にインストールして、そのPythonでvenvを作ります。

    Javaと比べると

    プロジェクトごとに依存ライブラリを分けて管理する、Maven や Gradle の考え方に近いものです。

    2.1.3pipコマンド

    pip は、PyPI（The Python Package Index）に公開されているパッケージをインストールするためのコマンドです。

    (env) % pip install numpy             # インストール
(env) % pip install pandas==2.2.3     # バージョンを指定してインストール
(env) % pip install -U numpy          # 新しいバージョンに更新
(env) % pip list                      # インストール済みのパッケージ一覧
(env) % pip freeze > requirements.txt # 一覧をファイルに書き出す
(env) % pip install -r requirements.txt  # ファイルの一覧をまとめてインストール
(env) % pip uninstall numpy           # アンインストール

    • パッケージ管理と仮想環境の作成には、pip・venv ではなく独自の conda コマンドを使います（例：conda create -n myenv python=3.12）。
    • conda では、仮想環境ごとにPythonのバージョンを指定できます。

    正規表現（re）

    「こういう形の文字列」というパターンで検索・置換する仕組みを正規表現と呼びます。標準ライブラリの re モジュールを使います。

    記号意味例
    .任意の1文字a.c は abc、a1c に一致
    ?直前の文字が0回か1回colou?r は color、colour に一致
    *直前の文字が0回以上ab* は a、ab、abb…
    +直前の文字が1回以上ab+ は ab、abb…
    [abc]カッコ内のどれか1文字gr[ae]y は gray、grey
    [a-z]範囲内の1文字小文字1文字
    (A|B)AまたはB（グループ）(cat|dog)s は cats、dogs
    ^ / $先頭 / 末尾^py は py で始まる
    \d数字1文字\d+ は 2026

    パターンは r'...'（raw文字列）で書きます。\ がPythonのエスケープとして解釈されず、そのまま re に渡ります。

    In
    import re

prog = re.compile(r"\d+")            # パターンを準備（何度も使うときに便利）
m = prog.search("abc123def45")       # 最初に一致した部分を探す
print(m)                             # Matchオブジェクト
print(m[0], m.group())               # 一致した文字列
print(prog.match("abc123"))          # match は先頭から一致するかを調べる
print(prog.findall("abc123def45"))   # 一致した部分をすべてリストで
print(re.sub(r"\d+", "#", "a1b22c")) # 一致した部分を置換
    Out 
    <re.Match object; span=(3, 6), match='123'>
123 123
None
['123', '45']
a#b#c
    • search は、文字列のどこかに一致する部分があれば Match オブジェクトを返します。なければ None を返します。
    • match は、文字列の先頭から一致するかどうかを調べます。
    • Match オブジェクトの [0] または group() で、一致した文字列全体を取り出せます。
    • findall は一致したすべての部分をリストで返し、sub は一致した部分を置換します。
    • re.IGNORECASE を指定すると、大文字と小文字を区別しません。

    複数の記号を組み合わせたパターンは、左から部品に分けて読みます。

    部品意味
    colocolo（そのまま）
    u?u があってもなくてもよい
    rr（必須）
    (s|ed|ful)?s / ed / ful のどれか。なくてもよい
    In
    import re

prog = re.compile(r"colou?r(s|ed|ful)?", re.IGNORECASE)
for s in ["color", "Colours", "a COLORFUL day", "coloured pen", "colr"]:
    ret = prog.search(s)
    if ret is None:
        print(s, "→ 一致なし")
    else:
        print(s, "→", ret[0])
    Out 
    color → color
Colours → Colours
a COLORFUL day → COLORFUL
coloured pen → coloured
colr → 一致なし

    colr は、必須の o が足りないのでどこにも一致せず、None になります。a COLORFUL day は、search が途中の位置からでも探すことと、IGNORECASE で大文字も一致することから、COLORFUL の部分が見つかります。

    3.1.3関数の基本

    1次関数・2次関数

    3.3基礎解析 1問

    微分と積分の意味、簡単な計算、偏微分を説明します。機械学習の「学習」の仕組みを理解する土台です。

    3.3.1微分と積分の意味

    微分 ＝ 傾き関数のある点での傾き（変化の割合）を求める。
    積分 ＝ 面積グラフと x 軸に囲まれた部分の面積を求める。微分の逆の計算。

    微分した関数を f′(x) や df/dx と書きます。積分には、範囲を決めない不定積分と、範囲を決めた定積分があります。

    3.3.2簡単な関数の微分と積分

    微分の公式：(xn)′ = n xn−1　（定数を微分すると0）
    積分の公式：∫ xn dx = 1n + 1 xn+1 + C　（C は積分定数）
    • 微分の例：f(x) = 4x³ + 5x のとき f′(x) = 12x² + 5
    • 積分の例：∫ 9x² dx = 9 × x³/3 + C = 3x³ + C
    • 定積分の例：∫02 3x² dx = [x³]02 = 8 − 0 = 8
    POINT：検算のコツ

    積分した結果を微分すると、元の関数に戻ります。3x³ を微分すると 9x² に戻るので、上の積分は正しいと確かめられます。係数の割り算（÷(n+1)）を忘れていないかを、この方法で確認しましょう。

    3.3.3微分と関数の値

    グラフが谷の底や山の頂上になる点では、傾き（微分の値）が0になります。機械学習では、予測の誤差を関数で表し、誤差が最小になる点を探します。そのため、微分して傾きが0になる点を探すことが、学習の基本的な考え方になります。

    例：f(x) = x² − 6x + 10 を微分すると f′(x) = 2x − 6 です。これが0になる x = 3 で、f(x) は最小値 1 をとります。

    3.3.4偏微分

    変数が2つ以上ある関数（多変数関数）で、1つの変数だけに注目し、ほかの変数を定数とみなして微分するのが偏微分です。記号は ∂（ラウンド）を使い、どの変数で微分したかを明示します。

    f(x, y) = 2x² + xy のとき　∂f/∂x = 4x + y　　∂f/∂y = x

    3.4.1統計の基礎

    代表値

    データ全体の特徴を1つの値で表したものを代表値と呼びます。次の7人のテストの点数で考えます。

    45, 60, 60, 70, 75, 80, 100
    代表値意味上のデータの場合
    最小値 / 最大値最も小さい値 / 最も大きい値45 / 100
    平均値（mean）合計 ÷ 個数（算術平均）490 ÷ 7 = 70
    中央値（median）小さい順に並べて真ん中の値。個数が偶数なら、真ん中の2つの平均70
    最頻値（mode）最も多く出てくる値60

    分位数

    • 標準偏差：分散の平方根。元のデータと単位がそろうので、散らばりを直感的に表せます。
    分散 σ² = 1n Σi=1n (xi − μ)²　　標準偏差 σ = √σ²

    3.4.4確率

    • サイコロを振るような行為を試行、「偶数の目が出る」のような結果のまとまりを事象と呼びます。
    • 事象 A の確率 P(A) は、起こりうるすべての場合のうち A が起こる割合です。
    • 条件付き確率 P(A|B)：「Bが起きた」と分かっているときに、Aが起きる確率です。

    例：6面体のサイコロで「偶数の目が出た」と教えられたとき、それが6である確率は 1/3 です。候補が2・4・6の3つに絞られるからです。何も知らないときの確率 1/6 とは違う値になります。

    条件付き確率はベイズの定理の基本になっています。

    P(A|B) = P(B|A) P(A)P(B)

    3.4.5確率分布

    • 確率変数：サイコロの出目のように、確率的に値が決まる変数です。
    • 確率分布：確率変数の各値に、どれだけの確率が割り当てられているかを表したものです。
    • 期待値：「値 × その値が出る確率」の合計で、平均的に期待できる値を表します。
    E[X] = Σ xi P(xi)

    n 面体のサイコロ（1〜n の目が同じ確率）の期待値は (1 + 2 + … + n) / n = (n + 1) / 2 です。6面体なら 3.5、8面体なら 4.5 です。

    確率変数を引数にとって、その確率（または確率の密度）を返す関数には2種類あります。

    確率質量関数確率変数が離散的（とびとびの値）な場合。各値の確率をそのまま返す。例：サイコロの目、コインの表の回数。

    • iloc に文字列を渡したり、範囲外の番号を指定したりするとエラーになります。df["列名"] は列の取り出しで、行と列を同時には指定できません。

    4.4.2分類

    分類とは

    分類は、データがどのクラスに属するかを予測するタスクです。正解（クラスのラベル）が分かっている既知のデータを教師として学習する、教師あり学習の典型的なタスクです。

    分類モデル構築の流れ
    1データの分割手元のデータを学習データとテストデータに分ける。
    2学習学習データで分類モデルを作る（fit）。
    3予測と評価テストデータで予測（predict）し、未知のデータへの性能（汎化能力）を評価する。

    分割には、sklearn.model_selection モジュールの train_test_split 関数を使います。ここでは scikit-learn に付属する Irisデータセットを使います。150件のアヤメについて、がく（sepal）と花びら（petal）の長さと幅の4つの特徴量と、3種類の品種が記録されています。

    In
    from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split

iris = load_iris()
X, y = iris.data, iris.target
print(X.shape, y.shape)          # 150件 × 4特徴量
print(iris.feature_names)
print(iris.target_names)         # 3つの品種
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=0)
print(X_train.shape, X_test.shape)   # 8:2 に分割

    • test_size=0.2 で、テスト用が2割、学習用が8割になります（0.3 なら3割と7割）。
    • random_state は、分割をランダムに行うときの乱数のシードです。固定すると毎回同じ分割になります。
    • 分割と学習・評価を何度も繰り返して評価を平均する方法を、交差検証と呼びます（→ 4.4.5）。
    Javaと比べると

    学習データとテストデータを分けるのは、単体テストで「実装に使ったデータとは別のデータで確かめる」のと同じ考え方です。学習に使ったデータで評価すると、答えを知っている問題で採点するようなもので、本当の実力（汎化能力）が分かりません。

    サポートベクタマシン
    • クラスを分ける境界（決定境界）を、マージン（境界と、境界に最も近いデータとの距離）が最大になるように決める手法です。境界に最も近いデータをサポートベクタと呼びます。
    • マージンを大きくとると、境界が各クラスのデータから離れます。そのため、データが多少変わっても誤分類しにくい、汎化能力の高いモデルになります。
    • 直線や平面で分けられないデータも、カーネル法で高次元の空間に写すことで線形分離できるようになります。
    • 分類だけでなく、回帰や外れ値検出にも使えます。
    覚え方

    マージン ＝ 境界線の両側の「安全地帯」。安全地帯が広いほど、新しいデータが多少ずれても誤分類しにくいので、マージンは最大化します。安全地帯の端にいて境界を「支えている（support）」データがサポートベクタです。

    In
    from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.svm import SVC

X, y = load_iris(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=0)
svc = SVC(kernel="rbf")       # kernel="linear" で線形のSVM
svc.fit(X_train, y_train)     # 学習
y_pred = svc.predict(X_test)  # 予測
print(y_pred[:10])
print("正解率", svc.score(X_test, y_test))
    Out 
    [2 1 0 2 0 2 0 1 1 1]
正解率 1.0

    この手法をサポートベクタマシン（SVM）と呼びます。

    決定木
    • 「花びらの幅は0.8cm以下か？」のような質問を繰り返して、データを分割していく手法です。結果が木のような形になります。
    • 木というデータ構造は、頂点であるノードと、ノード同士を結ぶエッジでできています。一番上のノードをルート、最下部にあって子ノードを持たないノードをリーフ（葉）と呼びます。
    • どこで分割するかは、分割によってどれだけ得をするかを表す情報利得で決めます。情報利得 ＝ 親ノードの不純度 − 子ノードの不純度です。不純度はノード内のクラスの混ざり具合で、ジニ不純度やエントロピーで測ります。
    • 主なハイパーパラメータは木の深さ max_depth です。深すぎると学習データに合わせすぎてしまいます（過学習）。

    4.4.3回帰

    回帰は、連続値の目的変数を予測するタスクです。最も基本的なのが、説明変数と目的変数の関係を直線（平面）で表す線形回帰（LinearRegression）です。

    単回帰説明変数が1つ。y = a x + b
    重回帰説明変数が2つ以上。y = a1x1 + a2x2 + … + b

    説明変数の数で単回帰と重回帰を区別します。学習によって、係数（coef_）と切片（intercept_）が決まります。

    覚え方

    単 ＝ 説明変数が1つ（単独）、重 ＝ 説明変数が重なる（複数）。目的変数はどちらも1つです。coef_ は coefficient（係数）、intercept_ は切片（y軸と交わる点）の略です。末尾の _ は「学習して決まった値」の印です。

    In

    4.4.4次元削減

    次元削減は、データが持つ情報をできるだけ損なわずに、説明変数（特徴量）の数を減らすタスクです。計算量を減らしたり、2次元・3次元に落としてグラフで確認できるようにしたりするために使います。

    代表的な手法が主成分分析（PCA）です。

    • データの分散が最も大きくなる方向を探して新しい軸（第一主成分）とします。次に、それと直交する方向で分散が大きい軸を第二主成分とし、以下同様に続けます。
    • 元の次元以下の次元にデータを変換します。情報の多い主成分だけを残すことで、次元を減らせます。
    • 各主成分が元のデータの分散（情報）をどれだけ説明するかは、寄与率（explained_variance_ratio_）で確認します。少数の主成分で寄与率の合計が大きければ、少ない次元に削減しても情報はあまり失われません。
    • scikit-learn では、sklearn.decomposition モジュールの PCA クラスを使います。
    覚え方

    分散 ＝ 情報量と考えます。データが大きくばらつく向きほど、データの違いをよく表している（情報が多い）ので、分散が大きい方向を残します。PCA ＝ Principal Component Analysis（主成分分析）、モジュール名の decomposition ＝ 分解（データを成分に分解する）です。

    In

    4.4.5モデルの評価

    混同行列

    分類モデルの予測結果は、混同行列にまとめて評価します。ここでは「正例（陽性）か負例（陰性）か」の2クラスで考えます。

    予測：正例予測：負例
    実際：正例TP（真陽性：正しく正例と予測）FN（偽陰性：見逃し）
    実際：負例FP（偽陽性：誤検出）TN（真陰性：正しく負例と予測）
    評価指標
    指標式意味・重視する場面
    正解率（accuracy）(TP+TN) / (TP+FP+FN+TN)正例・負例を問わず、予測が当たった割合
    適合率（precision）TP / (TP+FP)正例と予測したもののうち、本当に正例だった割合。正例と予測するときに、なるべく間違えたくない（誤検出を減らしたい）場合に重視する
    再現率（recall）TP / (TP+FN)本当の正例のうち、正例と予測できた割合。見逃しを減らしたい場合（病気の検査など）に重視する
    F値（F1）2 × 適合率 × 再現率 / (適合率 + 再現率)適合率と再現率の調和平均

    適合率と再現率は、一般にトレードオフの関係にあります。片方を高くすると、もう片方は低くなりやすいので、両方のバランスを見る F値を使います。

    予測:正予測:負実際:正TPFN実際:負FPTN
    適合率 ＝ TP /（TP + FP）
    「正と予測した列」の中で見る
    予測:正予測:負実際:正TPFN実際:負FPTN
    再現率 ＝ TP /（TP + FN）
    「実際に正の行」の中で見る
    予測:正予測:負実際:正TPFN実際:負FPTN
    正解率 ＝（TP + TN）/ 全体
    対角線（当たり）÷ 全部
    覚え方
    • TP / FP などの読み方：後ろの P / N が「予測」、前の T / F が「当たったか」。FP ＝ 正（P）と予測したが外れ（F）＝ 誤検出、FN ＝ 負（N）と予測したが外れ ＝ 見逃し。
    • 適合率（precision ＝ 精密さ）：予測の側から見る。「正と言ったものは本当に正か」。迷惑メールフィルタで、普通のメールを誤って捨てたくないときに重視する。
    • 再現率（recall ＝ 思い出す、取りこぼさない）：実際の側から見る。「本当の正をどれだけ拾えたか」。病気の見逃しを避けたいときに重視する。
    注意：分類と回帰で指標が違う

    正解率・適合率・再現率・F値は、混同行列から計算する分類モデルの指標です。回帰モデルは、平均二乗誤差（MSE）や決定係数（R²）など、予測値と実際の値の差で評価します。

    4.4.6ハイパーパラメータの最適化

    学習によって決まる値（回帰の係数など）をパラメータと呼びます。一方、決定木の深さ max_depth やSVMの C のように、学習の前に人が決める値をハイパーパラメータと呼びます。

    候補の値の組み合わせをすべて試して、最も評価が良いものを選ぶ方法をグリッドサーチと呼びます。scikit-learn では GridSearchCV を使い、各候補を交差検証で評価します。候補を無作為に選んで試す RandomizedSearchCV もあります。

    In
    from sklearn.datasets import load_wine
from sklearn.model_selection import GridSearchCV, train_test_split
from sklearn.svm import SVC

X, y = load_wine(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=0)
param_grid = {"C": [0.1, 1, 10], "kernel": ["linear", "rbf"]}   # 3 × 2 = 6通りを試す
gs = GridSearchCV(SVC(), param_grid=param_grid, cv=5)          # 5分割交差検証で評価
gs.fit(X_train, y_train)
print(gs.best_params_)            # 最も良かった組み合わせ
print(round(gs.best_score_, 3))   # そのときの交差検証の平均スコア
print(round(gs.score(X_test, y_test), 3))   # 最良の設定で学習し直したモデルのテスト正解率

    • 最適値は、必ず param_grid で与えた候補の中から選ばれます。
    • cv=5 なら5分割、cv=10 なら10分割の交差検証です。
    • 最適化した後の predict は、最良のハイパーパラメータで学習し直したモデルで予測します。
    覚え方

    GridSearchCV ＝ Grid（格子）＋ Search（探索）＋ CV（Cross Validation ＝ 交差検証）。候補を縦横の格子に並べて全部の交点を試し、それぞれを交差検証で評価する、と名前がそのまま中身を説明しています。best_params_ が最良の組み合わせ、best_score_ がそのときのスコアです。

    結果の再現性

    決定木やランダムフォレストのように、アルゴリズム自体に乱数を使うモデルがあります。train_test_split の random_state だけを固定しても、モデル側の random_state を固定しなければ、実行するたびに結果（選ばれる最適値など）が変わることがあります。

    In

grid = {"max_depth": [2, 3, 4, 5, 6]}
free = []
for i in range(8):           # モデルの random_state を固定しない
    gs = GridSearchCV(DecisionTreeClassifier(), grid, cv=5).fit(X_train, y_train)
    free.append(gs.best_params_["max_depth"])
fixed = []
for i in range(8):           # モデルの random_state を固定する
    gs = GridSearchCV(DecisionTreeClassifier(random_state=0), grid, cv=5).fit(X_train, y_train)
    fixed.append(gs.best_params_["max_depth"])
print("固定しない:", free)
print("固定する  :", fixed)

    固定しない方は、実行するたびに並びが変わる可能性があります。「▶ 実行」を何度か押して確かめてみましょう。

    4.4.7クラスタリング

    クラスタリングは、ある基準でデータ同士の類似性（距離など）を計算し、似たデータをクラスタ（グループ）にまとめるタスクです。教師なし学習の典型的なタスクです。

    階層的クラスタリング
    凝集型まず似ているデータ同士をまとめて小さなクラスタを作り、似ているクラスタ同士をさらにまとめる。最終的にすべてが1つのクラスタになるまで繰り返す。一般的によく使われるのはこちら。
    分割型最初にすべてのデータが1つのクラスタに属すると考え、順にクラスタを分割していく。計算量が多くなるため、凝集型ほどは使われない。

    階層的クラスタリングは、凝集型と分割型に分かれます。まとめていく過程は、デンドログラム（樹形図）で表せます。

    覚え方

    凝集型 ＝ ボトムアップ（1件ずつの小さなまとまりから、だんだん集まって1つになる）。分割型 ＝ トップダウン（全体の1つから、だんだん割っていく）。全体から割り方を考える分割型の方が計算が重く、一般には凝集型がよく使われます。scikit-learn のクラス名も AgglomerativeClustering（agglomerative ＝ 凝集する）です。

    クラスタの数 k は、人が事前に決めるハイパーパラメータです。k を変えながら、クラスタ内の距離の合計（inertia_）が下がりにくくなる点を探して k を決める方法を、エルボー法と呼びます。

    覚え方

    k-means ＝ k 個の mean（平均）。クラスタ中心を「所属するデータの平均の位置」に動かし続ける手法なので、この名前です。グラフが肘（elbow）のように折れ曲がる点で k を決めるのがエルボー法です。

    このほか、データの密度にもとづいてクラスタを作る DBSCAN もあります。DBSCANは、クラスタの数を事前に決める必要がありません。

    POINT
    • 前処理：エンコーディング（Label / One-hot）、正規化（StandardScaler＝平均0・標準偏差1、MinMaxScaler＝0〜1）。
    • 分類：既知のラベルで学習する。SVM はマージン最大化とカーネル法、決定木は情報利得、ランダムフォレストはブートストラップ＋多数決。
    • 回帰：説明変数1つなら単回帰、2つ以上なら重回帰。次元削減：PCA は分散が大きい方向を主成分にする（decomposition.PCA）。
    • 評価：適合率・再現率・F値・正解率は分類の指標。グリッドサーチは GridSearchCV で、交差検証で評価する。
    • クラスタリング：教師なし学習。凝集型がよく使われる。k-means は cluster.KMeans。
