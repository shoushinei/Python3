基礎試験 本番形式模試

本番と同じ40問・60分の模擬試験です。問題数は公式の章別出題率どおりに配分しています。1問は短めで、チュートリアルの細かい知識を知らないと落とす問題を中心にしました。

40問題数
60試験時間（分）
700合格点 / 1000
4・5択（混在）
  • すべて単一選択です。4択と5択の問題が混ざっています。
  • 「見直し」マークを付けておくと、右の問題一覧でオレンジの点が付きます。
  • 時間切れになると自動で採点します。途中でページを閉じても、続きから再開できます。
  • 提出すると、得点と章ごとの正答率を表示します。横の問題一覧から問題を選び、選択肢ごとの解説と論点を読んで振り返れます。
  • 選択肢の並びは受験のたびに入れ替わります。問題の順番は変わりません。

受験記録

提出した回の得点・選んだ答え・見直しマーク・振り返りメモが保存されます。「結果を開く」で、その回の ○× と解説をいつでも見直せます。

記録はこのブラウザにだけ保存されます。別の端末の記録は、そちらで「記録を書き出す」で作った JSON ファイルを、ここで「記録を読み込む」と今の記録に追加できます（今ある記録は消えません）。紙やスクリーンショットの ○× しか残っていない回は「結果を手で入力する」で記録にできます。
