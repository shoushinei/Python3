このサイトについて

注意事項

  • 個人が作成した非公式の学習教材です。試験の実施団体や出版社とは関係ありません。
  • 内容の正確さや、試験の合格を保証するものではありません。
  • 試験の形式や出題範囲は変わることがあります。受験の前に、実施団体の案内を確認してください。

学習の記録

  • 読了した章、覚えた用語、模試の受験記録は、お使いのブラウザ（localStorage）にだけ保存します。サーバーには送りません。
  • 別のブラウザや端末には引き継がれません。ブラウザのデータを消すと、記録も消えます。

外部のサービス

  • 教材の「▶ 実行」を押すと、ブラウザの中で Python を動かすための Pyodide を jsDelivr から読み込みます。コードはお使いの端末の中で実行されます。
  • 文字の表示に Google Fonts を使っています。
  • 外部の対策サイトは、それぞれ別の運営者によるものです。内容や料金は各サイトで確認してください。

誤りの報告

内容の誤りに気づいたら、GitHub の Issues から教えてください。
